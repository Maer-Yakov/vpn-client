# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Использование фольклора в вокальном развитии детей дошкольного возраста
**Тема:** короткий жанр + мягкий голос + ритм/жест + игра по возрасту  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Фольклор в вокальном развитии дошкольников  
**Подзаголовок:** Живая речь, ритм и мягкий голос — не «музей»  

**На слайде:**
- дошкольный возраст  
- итог: жанр → мягкий голос → ритм/жест → игра  

**Картинка:** педагог с детьми в круге; потешка/платочек; иконки жанр / голос / ритм / игра.  
**Схема-формула:**
```
короткий жанр → мягкий голос → ритм / жест → игра по возрасту
```
**Мелко:** Ветлугина · Радынова · Метлов · Науменко · «Ладушки» · Мельников

---

### Слайд 2. Живой фольклор или «просто текст»?
**Заголовок:** Чем отличается фольклорная работа

**Таблица:**

| Это | Не это |
|---|---|
| короткий живой образец | длинная «народная» ария |
| мягкий игровой показ | крик «по-народному» |
| посильный жест | сложная постановка |
| повтор и игра | заучивание большого текста |

**Картинка:** две двери — «Сухой текст» и «Живой фольклор».  
**Крупно:** громкость — не признак народности.

**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Жанры и значение
→ Разминка
```

**Картинка:** бланк «мини-фрагмент: фольклор».

---

### Слайд 4. Жанры фольклора
**Заголовок:** Что берёт воспитатель

**Таблица:**

| Жанр | Задача |
|---|---|
| Пестушка | контакт, мягкая речь |
| Потешка | ритм речи, игра |
| Колыбельная | мягкий звук, спокойствие |
| Закличка | интонация зова |
| Игровая песня | пение + правило |
| Хороводная | совместность (коротко) |

**Схема:**
```
жанр → задача → возраст → длина → жест
```
**Картинка:** карточки жанров вокруг круга детей.  
**Вывод:** жанр выбираем под задачу, не «все сразу».

---

### Слайд 5. Значение для детей
**Заголовок:** Зачем фольклор голосу и развитию

**Таблица:**

| Сфера | Что даёт |
|---|---|
| Вокальная | естественная интонация |
| Ритмическая | слово + движение |
| Речевая | артикуляция, словарь |
| Эмоциональная | безопасность, радость |
| Культурная | традиция, образы |
| Социальная | контакт в круге |

**Картинка:** шесть мягких иконок вокруг ребёнка с педагогом.  
**Фраза:** фольклор развивает голос через речь, ритм и игру.

---

### Слайд 6. Практическая разминка
**Заголовок:** 1–2 минуты фольклорного входа

**Таблица:**

| Упражнение | Задача |
|---|---|
| Плечи / кисти | снять зажим |
| Зевота-улыбка | свобода лица |
| Шёпот → мягкий голос | без форса |
| Эхо-потешка | интонация |
| Жест-подпись | 1 жест |
| Стоп | мгновенно тихо |

**Схема:**
```
тело → лицо → мягкий звук → слово → жест → стоп
```
**Картинка:** круг разминки с потешкой.  
**Правило:** одна задача · мягко · коротко.

---

### Слайд 7. Певческие и ритмические упражнения
**Заголовок:** Голос и ритм на фольклоре

**Таблица:**

| Певческое | Ритмическое |
|---|---|
| мягкие гласные в потешке | хлопки на сильные слова |
| фраза «из речи в пение» | шаг на месте |
| эхо в характере | передай ритм |
| тихий зов | ложки / погремушка дозированно |
| повтор с опорой | стоп на паузе |

**Схема связки:**
```
вход-потешка → эхо → жест/ритм → игровая фраза → стоп
```
**Картинка:** две колонки карточек — пение / ритм.

---

### Слайд 8. Репертуар от рождения до 7 лет
**Заголовок:** Что брать по возрасту

**Таблица:**

| Возраст | Приоритет | Форма |
|---|---|---|
| 0–1 | пестушки, колыбельные | 10–30 сек |
| 1–1,5 | пестушки, простые потешки | повтор 1 фразы |
| 1,5–3 | потешки, короткие игровые | 20–40 сек |
| 3–5 | заклички, игровые | 30–60 сек |
| 5–7 | игровые, короткие хороводные | 40–90 сек |

**Схема:**
```
чем младше — тем короче и ближе контакт
```
**Картинка:** пять возрастных мини-сцен с фольклором.

---

### Слайд 9. Критерии отбора
**Заголовок:** Беру / не беру

**Таблица:**

| Беру ✓ | Не беру ✕ |
|---|---|
| короткий понятный текст | длинный архаичный без опоры |
| ясный ритм / повтор | сложная мелодия «для хора» |
| мягкий игровой характер | агрессивный / пугающий образ |
| можно показать жестом | нужна сложная постановка |
| подходит возрасту | «народность» ради галочки |

**Картинка:** светофор / две стопки карточек.  
**Фраза:** сначала посильность — потом «красота традиции».

### Слайд 10. Карточка подбора
**Заголовок:** Как заполнять репертуарную карточку

**Таблица-карточка:**

| Поле | Смотрим |
|---|---|
| Возраст | 0–1 … 5–7 |
| Жанр | пестушка / потешка / … |
| Цель | голос / речь / ритм / игра |
| Длина | секунды / куплеты |
| Жест / опора | 1 действие или предмет |
| Риск + стоп | крик, перегруз, сложность |

**Схема этапов фрагмента:**
```
возраст → жанр → вход → показ → проба → стоп
```
**Картинка:** бланк карточки рядом с текстами потешек.

---

### Слайд 11. Работа в группах
**Заголовок:** Фрагмент 60–90 секунд

**Структура:**
```
возраст и цель
→ вход (1 фраза)
→ мягкий показ
→ проба
→ стоп
→ «зачем этот жанр»
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Жанр и возраст верны? | |
| Образец короткий? | |
| Голос мягкий? | |
| Есть жест / ритм / игра? | |
| Есть стоп и цель? | |

**Картинка:** студенты в круге показывают фольклорный фрагмент; наблюдатели с бланком.  
**Фраза:** хороший фрагмент — короткий, живой и мягкий.

```
Короткий жанр

```

**Таблица ДЗ:**

| Задание | Содержание |
