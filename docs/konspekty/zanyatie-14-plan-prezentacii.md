### Слайд 2. Проблема плохого конспекта
**Заголовок:** Красивые упражнения без логики — ещё не занятие

**Таблица сравнения:**

| Набор «интересных штук» | Методическое занятие |
|---|---|
| всё яркое подряд | у каждого блока своя задача |
| пик нагрузки в начале или в конце | нарастание и спад |
| много нового сразу | одно учебное ядро |
| конец на возбуждении | обязательный релакс |
| возраст «примерно» | возраст узнаваем в каркасе |

**Крупно:**  
`Структура защищает ребёнка от перегруза и педагога от хаоса`

**Картинка:** две стопки карточек — хаотичная гора vs аккуратная лента из 6 цветных этапов.  
**Схема:** хаос ✗ → порядок ✓

### Слайд 5. Структура занятия — главная схема
**Заголовок:** Шесть блоков одного пути

**Большая схема-лента:**
```
1. Вход / настройка
2. Музыкальная разминка
3. Основная двигательная часть
4. Танцевальный блок
5. Музыкальная игра
6. Завершение и расслабление
```

**Таблица долей времени (занятие в детском саду):**

| Блок | 2–3 года | 4–5 лет | 6–7 лет |
|---|---|---|---|
| Вход + разминка | 3–4 мин | 3–4 мин | 3–5 мин |
| Основная часть | 4–5 мин | 5–7 мин | 6–8 мин |
| Танец | 3–4 мин | 5–6 мин | 6–8 мин |
| Игра | 3–4 мин | 3–4 мин | 2–4 мин |
| Релакс | 1–2 мин | 1–2 мин | 1–2 мин |

**Картинка:** цветные карточки этапов в ряд; стрелка «нельзя ломать физиологию».  
**Крупно внизу:** нельзя пик в начале; нельзя финал без спада.

### Слайд 6. Музыкальная разминка
**Заголовок:** Включить слух, тело и внимание — коротко и с успехом

**Таблица «да / нет»:**

| В разминке ДА | В разминке НЕТ |
|---|---|
| ходьба и варианты | сложная комбинация |
| пружины, мягкие повороты | длительный бег |
| хлопки / простой ритм | новое трудное «с места» |
| реакция на начало/конец музыки | долгое словесное объяснение |

**Схема цикла:**
```
вход в круг → шаг → пружина → хлопок → стоп с музыкой
```

**Картинка:** дети идут по кругу, педагог показывает простой жест; лица спокойные, уверенные.  
**Фраза:** разминка даёт чувство «у меня получается».

---

### Слайд 7. Основная двигательная часть
**Заголовок:** Сердце обучения: здесь появляется навык

**Схема методики блока:**
```
Показ → Проба → Коррекция 1–2 ошибок → Повтор под музыку → Лёгкое усложнение
```

**Таблица по возрастам:**

| Возраст | Что здесь уместно |
|---|---|
| 2–3 | подражание, один образ, короткие серии |
| 4–5 | элемент + простое соединение |
| 6–7 | последовательность, точность, смена построений |

**Картинка:** крупный план «педагог показывает приставной / переменный шаг — дети пробуют».  
**Схема-дозировка:** 2–3 качественных повтора лучше, чем 8 смазанных.  
**Важно:** после прыжков/бега — обязательно шаг.

---

### Слайд 8. Танцевальный блок
**Заголовок:** Собрать движения в образ и фразу

**Таблица форм блока:**

| Форма | Когда брать |
|---|---|
| 1–2 фигуры нового танца | этап разучивания |
| знакомая пляска + усложнение | закрепление |
| этюд на характер | выразительность |
| хоровод / смена рисунка | пространство и группа |

**Схема порций:**
```
фраза → соединение → повтор → (для старших) маленькая самостоятельность
```

**Картинка:** ленты/платочки в простой комбинации; смена круга на колонну у старших.  
**Крупно:** не 5 новых фигур за раз · одна новая + знакомое.

---

### Слайд 9. Музыкальная игра в структуре занятия
**Заголовок:** Игра — не «вместо обучения», а инструмент этапа

**Схема возможных позиций:**
```
после разминки     → настройка
после обучения     → закрепление   ★ чаще всего
перед финалом      → эмоциональная вершина
НИКОГДА постоянно  → вместо обучения
```

**Таблица выбора игры:**

| Состояние детей | Какая игра |
|---|---|
| устали умственно | реакция / образ |
| перевозбудились | игра с чётким стопом → быстрее к релаксу |
| хорошо включены | игра-мостик к элементу танца |

**Картинка:** карточка «Замри» + иконка уха; рядом перечёркнутые «просто догонялки».  
**Напоминание из з. 13:** у игры обязательна музыкальная задача.

### Слайд 10. Завершение и расслабление
**Заголовок:** Точка занятия обязательна

**Схема спада:**
```
яркая игра / танец
        ↓
спокойный шаг / покачивание
        ↓
дыхание / тихая песенка
        ↓
поклон / «спасибо музыке»
```

**Таблица содержимого финала:**

| Приём | Зачем |
|---|---|
| «шёпот шагов» | снизить возбуждение |
| дыхание с руками | восстановить ритм дыхания |
| короткий вопрос старшим | рефлексия без возбуждения |
| поклон | культурная точка |

**Картинка:** дети медленно идут по кругу под тихую музыку; контраст с кадром «крик и бег на финише» (крестик).  
**Крупно:** не заканчивать галопом и криком «всё!»

### Слайд 11. Дозировка нагрузки — светофор
**Заголовок:** Чередовать интенсивность, сложность, пространство, эмоцию

**Большая таблица параметров:**

| Параметр | Как чередовать |
|---|---|
| Интенсивность | бег/прыжки ↔ шаг/статика |
| Сложность | знакомое ↔ новое |
| Внимание | слуховая задача ↔ свободный образ |
| Пространство | на месте ↔ по залу |
| Эмоция | веселье ↔ спокойствие |

**Светофор:**

| Цвет | Примеры | Мера |
|---|---|---|
| 🟢 Зелёный | шаг, хлопки, спокойный танец | основа занятия |
| 🟡 Жёлтый | подскоки, лёгкий бег, парные кружения | дозованно |
| 🔴 Красный | долгий быстрый бег, трюки, низкие приседания | редко / нельзя |

**Картинка:** светофор + силуэты детей: спокойный шаг / подскок / опасный перегруз.  
**Схема признаков перегруза:** красные лица → хаос → капризы → «ломается» движение → сразу упрощаем.

### Слайд 12. Внимание по возрастам — сравнительная таблица
**Заголовок:** Один приём не работает на все группы

**Большая таблица:**

| Приём | 2–3 года | 4–5 лет | 6–7 лет |
|---|---|---|---|
| Длина отрезка | 1–2 мин | 2–4 мин | 3–5 мин |
| Объяснение | показ > слова | правило в 1–2 фразах | задача + критерий качества |
| Мотивация | образ, предмет | роль, мягкое соревнование | ответственность, инициатива |
| Память | повтор за педагогом | 2–3 элемента | порядок фигур, построения |
| Финал | тихий ритуал | спад + поклон | спад + мини-рефлексия |

**Картинка:** три вертикальные колонки-портрета групп с разными атрибутами (погремушка / лента / схема построений).  
**Общая схема приёмов:** сигнал внимания → показ → один новый акцент → быстрый успех → смена пространства.

### Слайд 13. Каркас для 2–3 лет
**Заголовок:** Младшие: не «укороченные старшие»

**Таблица-каркас 12–15 мин:**

| Мин | Блок | Пример | Муз. задача |
|---|---|---|---|
| 0–2 | Разминка | «Идём как мишки» | начать/закончить с музыкой |
| 2–6 | Основная | зайчики / птички | смена образа по характеру |
| 6–9 | Пляска | движения с платочком | повтор за педагогом |
| 9–12 | Игра | погремушка звучит/спит | реакция на звук |
| 12–14 | Релакс | покачивание | тихая музыка |

**Схема «можно / нельзя»:**
```
✓ показ, образ, предмет, 1 правило
✗ переменный шаг, 6 элементов, гонки по залу, финал без релакса
```

**Картинка:** малыши с платочками; педагог в образе рядом, не «дирижёр издалека».  
**Тест возраста:** если конспект идёт только по словам без показа — он не для 2–3 лет.

### Слайд 14. Каркас для 4–5 лет
**Заголовок:** Средняя группа: правило + соединение элементов

**Таблица-каркас 15–20 мин:**

| Мин | Блок | Содержание | Акцент |
|---|---|---|---|
| 0–3 | Разминка | шаг с носка, пружины, хлопки | слух к фразе |
| 3–8 | Основная | приставной, притопы, повороты | координация |
| 8–13 | Танец | шаг + притоп + поворот с лентой | фраза + образ |
| 13–17 | Игра | «Угадай характер» / «Замри» | внимание |
| 17–19 | Релакс | спокойный круг, поклон | спад |

**Таблица «добавить / ещё рано»:**

| Уже можно | Ещё рано |
|---|---|
| 2–3 элемента в связке | длинная самостоятельная композиция |
| предмет как танцевальное средство | жёсткая идеальная синхронность всего зала |
| короткая оценка качества | сложный галоп по диагонали без страховки |

**Картинка:** дети с лентами в простой комбинации; схема «элемент → 2 фигуры».  
**Проверка:** есть обучение? есть игра с правилом? есть спад?

### Слайд 15. Каркас для 6–7 лет
**Заголовок:** Подготовка к школе: память, точность, рисунок

**Таблица-каркас 20–25 мин:**

| Мин | Блок | Содержание | Школьный акцент |
|---|---|---|---|
| 0–4 | Разминка | переменный шаг на месте, ритм-эхо | самоконтроль |
| 4–10 | Основная | шаг в продвижении, галоп/подскок дозованно | точность + пространство |
| 10–17 | Танец | комбинация + смена построений | память последовательности |
| 17–21 | Игра | «Повтори за мной» / темп | реакция + память |
| 21–24 | Релакс | шаг, дыхание, мини-рефлексия | произвольность спада |

**Схема построений:**
```
круг → колонна → шеренга → диагональ
```

**Картинка:** схема зала с стрелками перестроений; дети начинают/заканчивают вместе.  
**Баланс крупно:** без точности — недооценка возраста; без радости — муштра.

### Слайд 16. Анализ ошибок в конспектах
**Заголовок:** Четыре типовые поломки

**Большая таблица разбора:**

| Конспект | Возраст «заявлен» | Главные ошибки | Эталон правки |
|---|---|---|---|
| А | 2–3 | сразу 5 элементов; 7 мин бега; слова без показа; финал-крик | образ + показ; снизить интенсивность; релакс |
| Б | 4–5 | 6 фигур без обучения; догонялки «под музыку»; разминка длиннее основной; предметы без правила | элемент → 2 фигуры; музыкальная игра; сжать разминку |
| В | 6–7 | только ходьба; нет построений; сложность скачками; наказание за ошибку | память + рисунок; учить порциями; без стыда |

**Схема диагностики:**
```
не тот возраст / не та нагрузка / нет обучения / нет спада
```

**Картинка:** три листа конспектов с красными пометками и зелёными стрелками «как исправить».  
**Фраза:** ошибка почти всегда из этих четырёх.
