### Слайд 5. Понятие музыкально-ритмического развития
**Заголовок:** Слышать музыку — и выражать её в движении

**Определение крупно:**
```
Музыкально-ритмическое развитие —
способность воспринимать музыку
и отвечать на неё движением:
ритм, темп, характер, динамика, форма.
```

**Таблица «что развивается»:**

| Слух | Тело | Психика | Социальность |
|---|---|---|---|
| внимание к звучанию | координация | память | двигаться вместе |
| чувство ритма/темпа | пространство | произвольность | не мешать другим |
| различение характера | выразительный жест | эмоции | договориться о правиле |

**Картинка:** ребёнок останавливается точно с окончанием музыки; педагог улыбается.  
**По Ветлугиной / Бурениной / Теплову:** движения — равноправный вид музыкальной деятельности, а не «добавка».

### Слайд 6. Связь музыки, движения, эмоций и интеллекта
**Заголовок:** Музыка входит не только ухом

**Большая схема:**
```
Музыка
  → слышу (слух)
  → чувствую (эмоция)
  → понимаю / различаю (интеллект)
  → отвечаю движением (тело)
  → запоминаю и повторяю (память / произвольность)
```

**Таблица примеров:**

| Музыка | Эмоция | Движение | Интеллектуальный акцент |
|---|---|---|---|
| Марш | бодрость, собранность | чёткий шаг | ждать долю, держать темп |
| Колыбельная | спокойствие | покачивание | снизить амплитуду |
| Плясовая | радость | притоп, кружение | смена характера |
| Лирическая | нежность | шаг с носка, мягкие руки | плавность без спешки |

**Картинка:** четыре колонки-карточки характеров с пиктограммами движения.  
**Ошибка:** учить «красивый шаг» отдельно от характера.  
**Правильно:** сначала «какая музыка?» → потом «какое движение?»

### Слайд 7. Роль ритма — координация и внимание
**Заголовок:** Ритм упорядочивает тело и слух

**Таблица:**

| Сфера | Что тренирует ритм | Как выглядит у ребёнка |
|---|---|---|
| Координация | согласование рук/ног во времени | шаг + хлопок без «разъезда» |
| Внимание | ждать сигнал, не опережать | стоп с окончанием музыки |
| Переключение | смена темпа/динамики | быстрее → медленнее без хаоса |

**Схема внимания:**
```
сигнал услышан → пауза/ожидание → точный ответ → проверка
```

**Картинка:** дети в позе «замри» в один момент; один ребёнок ещё «доезжает» (как антипример мягко).  

---

### Слайд 8. Роль ритма — память, речь, эмоции
**Заголовок:** Ритм глубже, чем «попасть ногой»

**Большая таблица:**

| Сфера | Что даёт ритмика | Связь с жизнью ребёнка |
|---|---|---|
| Память | порядок хлопков/шагов/фигур | легче учить последовательности |
| Речь | темп, пауза, слоговая организация | поддержка чёткости и плавности |
| Эмоции | выразить характер без слов | снять напряжение через движение |
| Социальность | общее правило и общий рисунок | действовать в группе |

**Схема:**
```
ритм в теле  ↔  ритм в речи  ↔  ритм в внимании
```

**Картинка:** слева хлопки по долям; справа ребёнок проговаривает слоги в том же пульсе (иллюстрация связи, не логопедия).  
**Важно:** ритмика помогает развитию речи, но не заменяет логопеда.

---

### Слайд 9. Ритмика, деятельность, танец, хореография
**Заголовок:** Не путать слова — разная глубина задач

**Большая таблица:**

| Понятие | Суть | В детском саду |
|---|---|---|
| Ритмика | чувство ритма и реакция на музыку | база для всех возрастов |
| Музыкально-двигательная деятельность | ходьба, бег, игры, пляски под музыку | основной формат работы |
| Танец | образная композиция с рисунком | доступные детские пляски |
| Хореография | профессиональная техника | только адаптированные элементы |

**Схема уровней:**
```
Ритмика
  → музыкально-двигательная деятельность
    → детский танец
      → (не цель сада) профессиональная хореография
```

**Картинка:** пирамида из 4 ярусов; верхний «хореография» полупрозрачный / с пометкой «не цель ДОУ».  
**Крупно:** мы растим слышащего и координирующего ребёнка, а не артиста училища.

### Слайд 10. Задачи музыкального руководителя и воспитателя
**Заголовок:** Общая зона ответственности

**Таблица ролей:**

| Задача | Музрук | Воспитатель |
|---|---|---|
| Репертуар и занятие | ведущий | поддерживает интерес |
| Новые движения | показывает, учит | помогает смотреть, закрепляет |
| Наблюдение | на занятии | в течение дня |
| Ребёнку сложно | упрощает материал | рядом без стыда |
| Утренник | ставит номер | организация и эмоциональная опора |

**Схема сотрудничества:**
```
Музрук ←→ Воспитатель
         ↓
      Ребёнок
```

**Картинка:** два педагога на одном занятии: один показывает движение, второй мягко направляет ребёнка в кругу.  
**Фраза:** воспитатель — не зритель у стены.

### Слайд 11. Практический вывод теории
**Заголовок:** Что уносим в зал

**Таблица «запрещено / нужно»:**

| Не так | Так |
|---|---|
| «Просто шагай красиво» | «Какая музыка — такое движение» |
| Стыдить за промах | дать ещё одну спокойную пробу |
| Гнаться за номером | строить реакцию и понимание |
| Делить детей на «музыкальных» | работать с зоной ближайшего развития |

**Схема педагога:**
```
услышать характер → выбрать движение → короткое правило → проба → коррекция → повтор
```

**Картинка:** педагог прикладывает руку к уху, затем показывает жест ногам группы.

### Слайд 12. Практика 1. Движение под разный характер
**Заголовок:** Сначала слышим телом сами

**Таблица характеров:**

| Фрагмент | Качество движения |
|---|---|
| Марш | чёткий шаг, собранный корпус |
| Колыбельная | покачивание / тихий шаг |
| Плясовая | лёгкие притопы, подвижный жест |
| Лирическая | шаг с носка, мягкие руки |

**Схема пробы:**
```
фрагмент → движение → стоп → слово-характер → проверка соответствия
```

**Картинка:** четыре кадра студентов/детей в разных характерах на одном слайде-коллаже.  
**Правила:** не копировать соседа автоматически; после быстрого — спокойный переход.

---

### Слайд 13. Практика 2. Настроение через движение
**Заголовок:** Показать услышанное без длинной речи

**Таблица приёмов:**

| Приём | Как проходит | Зачем |
|---|---|---|
| Живые карточки | подойти к «бодро / спокойно / весело…» и показать жест | связать слово и движение |
| Один отвечает | студент показывает — группа угадывает настроение | проверка точности слуха |
| Диалог характеров | марш → колыбельная без паузы-рассуждения | тренировка переключения |

**Схема:**
```
услышать → выбрать карточку/жест → сверить с эталоном
```

**Картинка:** пол с карточками настроений; дети стоят у разных карточек с разными позами.  
**Для дошкольников:** сначала дать услышать, потом образ, потом одно точное движение.

### Слайд 14. Практика 3. Музыкальная реакция — база ритмики
**Заголовок:** Реакционные пробы, на которых стоит весь курс

**Большая таблица:**

| Упражнение | Правило | Что развивает |
|---|---|---|
| Начало и конец | движемся — музыка есть; стоп — музыка кончилась | внимание, произвольность |
| Тише — громче | амплитуда по динамике | слух + самоконтроль |
| Быстрее — медленнее | не обгонять музыку | темповое чувство |
| Сильная доля | шаг/хлопок только на сильную | ритмическая точность |
| Замри в характере | поза паузы соответствует только что звучавшему | выразительность + память |

**Схема безопасности:**
```
дистанция → устойчивый стоп → после быстрого темпа ходьба
```

**Картинка:** светофор реакции — зелёный «движение», красный «замри».  

---

### Слайд 15. Разбор типичных ошибок на практике
**Заголовок:** Что ломает соответствие «музыка ↔ движение»

**Таблица ошибок:**

| Ошибка | Как выглядит | Правка |
|---|---|---|
| Движение спорит с музыкой | под колыбельную — марш | вернуть слушание до показа |
| Эмоция только на лице | улыбка есть, тело жёсткое | изменить качество шага/плеч |
| Копирование соседа | не слушают фрагмент | закрыть глаза на 5 секунд слуха |
| «Доезд» после стопа | движение после паузы | якорь «и — стоп» |
| Перегруз правилами | путаница | одно условие за пробу |

**Картинка:** два силуэта — «попал в характер» ✓ и «движение из другой музыки» ✗.
