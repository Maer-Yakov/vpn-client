# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Занятие 19. Пение с детьми 3–5 лет
**Тема:** организация певческой деятельности среднего дошкольного возраста (акцент 4–5 лет)  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Пение с детьми 3–5 лет  
**Подзаголовок:** Занятие № 19 · Не сила голоса — условия, показ и посильная песня  

**На слайде:**
- средний дошкольный возраст (акцент 4–5 лет)  
- итог: условия + мягкий показ + фразы + пауза  

**Картинка:** воспитатель в музыкальном зале поёт с детьми 4–5 лет; рядом иконки условия / нота / фраза / платочек.  
**Схема-формула:**
```
условия → мягкий показ → фраза → повтор → пауза
```
**Мелко:** Ветлугина; Метлов; Дзержинская; Радынова; «Ладушки»

---

### Слайд 2. Чем пение в 3–5 лет особенное
**Заголовок:** От подхвата — к организованному разучиванию

**Таблица:**

| 3–4 года | 4–5 лет |
|---|---|
| больше подхват | больше повтор фразы |
| очень короткая песня | короткий куплет возможен |
| взрослый почти всё несёт | дети активнее подпевают |
| образ обязателен | образ + характер песни |

**Картинка:** две двери — «Концерт любой ценой» (закрыта) и «Организованное пение» (открыта).  
**Крупно:** в среднем возрасте важны условия и этапный показ, а не громкость.

### Слайд 3. Цель занятия для студента
**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Значение пения
→ Особенности 4–5 лет
→ Условия организации
→ Репертуар и этапы
→ Упражнения
→ Практика
```

**Мини-таблица:**

| Знает | Умеет |
|---|---|
| особенности 4–5 лет | проверить 2–3 условия |
| этапы разучивания | провести упражнение + 1–2 фразы |
| принципы репертуара | сказать «беру / не беру» |

**Картинка:** бланк «мини-пение 90–110 секунд» как продукт занятия.

### Слайд 4. Значение пения
**Заголовок:** Пение — музыкальное и общее развитие

**Таблица:**

| Сфера | Что развивается |
|---|---|
| Слух | высота, темп, динамика, фраза |
| Голос | мягкий звук, чуть длиннее фраза |
| Речь | словарь, дикция, ритм слова |
| Дыхание | спокойный выдох |
| Эмоции | настроение и характер |
| Общение | петь вместе, слушать других |

**Схема:**
```
слух + голос + речь + эмоция → желание петь организованно
```
**Картинка:** шесть сфер вокруг поющего ребёнка 4–5 лет.  
**Вывод:** пение — не «номер», а развитие ребёнка.

### Слайд 5. Возрастные особенности 4–5 лет
**Заголовок:** Средний возраст: что реально доступно

**Таблица:**

| Особенность | Для педагога |
|---|---|
| Диапазон шире, чем у младших, но всё ещё узкий | без широких скачков |
| Фраза длиннее | 2–4 короткие строки + паузы |
| Интонация точнее при показе | повтор, не жёсткая оценка |
| Внимание устойчивее | куплет возможен, дозировка нужна |
| Любят образ и характер | «как…», жест без перегрузки |
| Риск форсирования | мягкий эталон, стоп при крике |

**Картинка:** лестница «подхват → фраза → характер» с мягкой игрушкой наверху.  
**Крупно:** 4–5 лет — организованное подпевание, не «концертный хор».

---

### Слайд 6. Можно / нельзя для голоса
**Заголовок:** Границы бережности

**Таблица:**

| Можно | Нельзя |
|---|---|
| мягкий естественный звук | крик, давить горлом |
| петь вместе / по фразам | сценическое соло |
| удобная поза, паузы | долгое пение без отдыха |
| посильная песня | шлягер «на вырост» |
| жест как опора | сложный танец вместо пения |

**Картинка:** светофор — зелёный «мягко», жёлтый «пауза», красный «крик ✕».  
**Фраза:** стоп при крике — тоже методика.

---

### Слайд 7. Условия организации пения
**Заголовок:** Даже хорошая песня «не споётся» без условий

**Таблица-условия:**

| Условие | Как |
|---|---|
| Пространство | видно лицо педагога |
| Поза | удобно, без зажима шеи |
| Звук в зале | без лишней громкости |
| Эталон | мягкий выразительный показ |
| Длительность | 5–8 мин с паузами |
| Эмоции | интерес, без страха ошибки |
| Гигиена голоса | стоп при осиплости / крике |

**Схема:**
```
лицо видно → мягкий эталон → короткая доза → пауза → повтор в другой день
```
**Картинка:** чек-лист условий на планшете воспитателя в зале.  
**Вывод:** организация начинается до первой ноты.

---

### Слайд 8. Принципы подбора репертуара
**Заголовок:** Беру / не беру для 3–5 лет

**Критерии:**

| Принцип | Вопрос |
|---|---|
| Диапазон | умещается в голос 4–5 лет? |
| Длина | короткий куплет, есть повтор? |
| Текст | понятный и добрый? |
| Образ | ясно настроение / герой? |
| Цель | зачем эта песня сейчас? |

**Беру / не беру:**

| Беру | Не беру |
|---|---|
| песня средней группы | длинный шлягер |
| понятный образ | «модный» взрослый текст |
| мягкая мелодия | высокий крикливый пик |

**Картинка:** полка «беру» / корзина «не беру».  
**Вывод:** репертуар — педагогическое решение.

### Слайд 9. Методика разучивания песни
**Заголовок:** Этапы: от интереса к характеру

**Схема-дорожка:**
```
интерес → показ → смысл → фразы → соединение → характер → закрепление → стоп
```

**Таблица:**

| Этап | Суть |
|---|---|
| Интерес | образ / вопрос |
| Показ | педагог поёт целиком |
| Смысл | 2–3 вопроса |
| Фразы | короткий повтор |
| Вместе | соединение |
| Характер | тихо / бодрее / «как…» |
| Стоп | отдых голоса |

**Картинка:** дорожка из 7 станций в музыкальном зале.  
**Важно:** не требовать весь куплет с первого раза.

---

### Слайд 10. Певческие упражнения
**Заголовок:** 20–40 секунд — одна задача

**Таблица:**

| Навык | Упражнение |
|---|---|
| Дыхание | платочек / «одуванчик» |
| Мягкая атака | «мм», «ау» |
| Интонация | повтор высоты / попевки |
| Дикция | потешка шёпотом → голосом |
| Динамика | тихо — чуть громче |
| Слух | «услышь конец» |

**Схема дозировки:**
```
одна задача → 20–40 сек → стоп
```
**Картинка:** шесть карточек упражнений на столе.  
**Правило:** упражнение — игра, не вокальный станок.

---

### Слайд 11. Практика и чек-лист студента
**Заголовок:** Мини-фрагмент 90–110 секунд

**Структура:**
```
1–2 условия
→ упражнение 20–30 сек
→ показ 1–2 фраз + повтор
→ можно / нельзя
→ мягкий стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Условия учтены? | |
| Голос мягкий? | |
| Фразы короткие? | |
| Есть пауза? | |
| Нет крика? | |
| Понятно, что это для 3–5 / 4–5? | |

**Картинка:** студенты в паре проводят мини-показ.  
**Фраза:** хороший фрагмент короткий, организованный и мягкий.

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула пения 3–5 лет

**Крупная схема:**
```
Условия
+ мягкий показ
+ посильная песня
+ этапы без спешки
= правильная организация пения
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | значение · 4–5 лет · условия · репертуар · этапы · упражнения |
| 2. Разбор песни | этапы + дозировка + 2 условия |
| 3. Мини-эссе | почему нельзя заменить показ громкой фонограммой |
| 4. Мини-сценарий | упражнение + фраза + характер + стоп |
| 5. Сравнение | 3 отличия 3–4 / 4–5 + 3 общих правила |

**Картинка:** воспитатель мягко ведёт фразу; дети повторяют; платочек «отдыхает».  
**Футер:** Ветлугина; Метлов; Дзержинская; Радынова; «Ладушки»  
**Финальная фраза:** берегите голос — и пение в средней группе начнётся с правильных условий.
