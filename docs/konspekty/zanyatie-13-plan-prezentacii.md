### Слайд 2. Что делает игру музыкально-ритмической
**Заголовок:** Если убрать музыку и ничего не изменится — это уже не та игра

**Таблица сравнения:**

| Обычная подвижная игра | Музыкально-ритмическая игра |
|---|---|
| главное — движение / сюжет | главное — музыкальная задача |
| сигнал часто словесный | сигнал в музыке или через звук |
| можно без мелодии | без музыки правило рассыпается |
| цель: ловкость, внимание | цель: слух, реакция, координация с музыкой |

**Крупно:**  
`Музыкальная задача обязательна`

**Картинка:** две карточки-двери: «Просто бегали» (крестик) и «Услышали — сделали» (галочка).  
**Схема:** ухо → правило → движение.

### Слайд 5. Классификация игр — таблица
**Заголовок:** Какую игру выбрать под задачу

**Большая таблица:**

| Тип игры | Ведущая задача | Пример |
|---|---|---|
| На внимание | ждать сигнал, не опережать | «Замри» |
| На слух / различение | услышать характер, динамику, регистр | «Угадай характер» |
| На реакцию | быстро переключиться | игры на смену темпа |
| На координацию | согласовать руки/ноги/инструмент | шаг + хлопок |
| На память / подражание | повторить последовательность | «Повтори за мной» |
| Сюжетно-образные | действовать в роли под музыку | «Птички в гнёздышко» |
| С инструментами | соединить звук и движение | «Музыкальное эхо» |
| Переход к танцу | вырастить элемент композиции | темп → шаг/галоп |

**Картинка:** картотека из 8 цветных карточек-типов.  
**Схема выбора:** `Цель этапа занятия → тип игры → одно правило`

### Слайд 6. Внимание, слух, координация, реакция — схема
**Заголовок:** Четыре базовые способности

**Схема-квадрат из 4 блоков:**
```
 ВНИМАНИЕ              СЛУХ
 ждать / не раньше     характер, темп, динамика
────────────────────────────────────────
 КООРДИНАЦИЯ           РЕАКЦИЯ
 руки+ноги+инструмент  быстро сменить действие
```

**Таблица «как усложнять»:**

| Было | Стало |
|---|---|
| одно движение | движение + поза на стоп |
| два контраста | три характера |
| только хлопки | хлопки + шаг |
| смена по слову педагога | смена только по музыке |

**Картинка:** ребёнок «замри» + ухо-иконка + молния.  
**Правило крупно:** `Одна новая умственная нагрузка за игру`

### Слайд 7. Инструменты в игре — таблица и схема
**Заголовок:** Инструмент служит музыке, а не заменяет её

**Таблица инструментов:**

| Инструмент | Хорош для | Риск |
|---|---|---|
| Погремушка | начало/конец, младшие | хаотичный шум |
| Бубен | сильная доля, марш | удары по полу |
| Колокольчик | тихий/высокий сигнал | потеря правила |
| Палочки/ложки | ритм-эхо | стук без слушания |

**Схема введения:**
```
Как держать → где «спит» на паузе → одна задача → + движение → убрать на место
```

**Картинка:** корзина инструментов; инструмент у груди на паузе = «спит».  
**Схема-запрет:** крест на хаотичном оркестре без правила.

### Слайд 8. Сюжетные и образные игры — схема
**Заголовок:** Образ усиливает правило, но не съедает его

**Схема построения сюжетной игры:**
```
1. Коротко назвать сюжет
2. Показать 1–2 действия роли
3. Связать действия с музыкой
4. Держать правило внутри сюжета
5. Не читать длинную сказку вместо правила
```

**Таблица примеров:**

| Образ | Музыкальная задача |
|---|---|
| Птички | музыка есть — летим; нет — в гнёздышко |
| Солдаты | марш / стоп по паузе |
| Снежинки | плавно / замереть искринкой |
| Паровозик | смена темпа |

**Картинка:** карточки ролей (птичка, зайчик, солдат) + нота.  
**Крупно:** `Сюжет — упаковка, музыкальная задача — ядро`

### Слайд 9. Переход от игры к танцу — ключевая схема
**Заголовок:** Мостик: игра → элемент → композиция

**Большая схема:**
```
Игра с правилом
→ повторяемое действие
→ действие на музыкальную фразу
→ связка 2–3 действий
→ заготовка танцевальной композиции
```

**Таблица мостиков:**

| Игра | Что вырастает в танце |
|---|---|
| «Замри» | общий старт/финиш, фиксация позы |
| «Повтори за мной» | последовательность элементов |
| «Музыкальное эхо» | ритм хлопков/притопов |
| «Угадай характер» | выразительность частей |
| Игры на темп | смена шага / галопа / подскока |

**Картинка:** мост между площадкой игры и танцевальным кругом.  
**Важно на плашке:** не каждая игра должна стать танцем, но педагог видит потенциал.

### Слайд 10. Практика: «Замри, когда музыка остановится»
**Заголовок:** Игра на внимание и реакцию

**Таблица паспорта игры:**

| Поле | Содержание |
|---|---|
| Тип | внимание + реакция |
| Правило | музыка звучит — движемся; остановилась — замри |
| Дозировка | 4–6 остановок |
| Усложнение | заданная поза на паузе |
| Мостик | конец фразы / общий финиш |

**Схема хода:**
```
Показ стоп-позы → ходьба → образное движение → повторы → разбор
```

**Картинка:** дети в движении / те же дети в позе «замри» — диптих.  
**Схема безопасности:** устойчивая поза на двух ногах, без падений и толчков.

---

### Слайд 11. Практика: «Повтори за мной»
**Заголовок:** Память и подражание порциями

**Схема наращивания:**
```
2 движения → 3 → 4 → под музыку → ведущий-ребёнок
```

**Таблица вариантов:**

| Уровень | Содержание |
|---|---|
| 1 | только руки |
| 2 | руки + шаг |
| 3 | + предмет / инструмент |

**Картинка:** педагог лицом к детям, зеркальный показ; стрелки «увидел → повторил».  
**Схема ошибки:** слишком длинная цепочка сразу — крест; короткие порции — галочка.

---

### Слайд 12. Практика: «Музыкальное эхо»
**Заголовок:** Сначала дослушать — потом ответить

**Схема эха:**
```
Педагог: ТА-ТА-ТА
         ↓
Дети:    ТА-ТА-ТА
```

**Таблица усложнения:**

| Шаг | Форма эха |
|---|---|
| 1 | хлопки 2–4 звука |
| 2 | притопы |
| 3 | хлопок + притоп |
| 4 | ответ инструментами |
| 5 | эхо + 4 шага |

**Картинка:** педагог с бубном / дети отвечают хлопками; волны «эхо».  
**Плашка-правило:** слушать до конца образца.

---

### Слайд 13. Практика: «Угадай характер музыки»
**Заголовок:** Услышал характер — показал движением

**Таблица характеров:**

| Характер | Возможное движение | Карточка-образ |
|---|---|---|
| Спокойно | покачивание, мягкий шаг | облако |
| Весело | лёгкие прыжки/пляска | солнышко |
| Марш | бодрый шаг | барабан |
| Колыбельная | плавно, тихо | месяц |

**Схема хода:** 2 контраста → 3 характера → свободный выбор в рамках характера → эталон педагога → обсуждение.

**Картинка:** карточки эмоций/образов веером.  
**Мостик-схема:** характер музыки → выразительность части танца.

---

### Слайд 14. Практика: игры на изменение темпа
**Заголовок:** Темп меняется — движение меняется

**Схема темпа:**
```
медленно ──► умеренно ──► быстро ──► снова шаг
```

**Таблица вариантов:**

| Вариант | Действие детей |
|---|---|
| Быстрее | шаг чаще / лёгкий бег |
| Медленнее | широкий спокойный шаг |
| Паровозик | постепенное ускорение |
| Темп + инструмент | быстро — колокольчик; медленно — тихий шаг |

**Картинка:** спидометр/метроном + дети на шаге и на беге.  
**Схема безопасности:** после быстрого темпа всегда шаг; в тесном зале менять частоту на месте, а не разгонять пространство.

### Слайд 15. Комплекс из пяти игр — главная проектная таблица
**Заголовок:** Конструктор комплекса на 8–10 минут

**Обязательная таблица структуры:**

| № | Тип слота | Пример игры | Минуты |
|---|---|---|---|
| 1 | внимание / реакция | «Замри» | 1,5 |
| 2 | слух / характер / темп | «Угадай характер» | 2 |
| 3 | память / подражание | «Повтори за мной» | 2 |
| 4 | инструмент или образ | «Музыкальное эхо» | 2 |
| 5 | мостик к танцу | темп → шаг с носка | 2 |

**Схема нарастания:**
```
Простая реакция → различение → память → обогащение → выход в танец
```

**Картинка:** 5 цветных вагончиков «поезда комплекса».  
**Плашка:** возраст + задача каждой игры + безопасность обязательны в бланке.

### Слайд 17. Риски и чек-лист
**Заголовок:** Где игра ломается

**Таблица рисков:**

| Риск | Как выглядит | Что делать |
|---|---|---|
| Перегруз правилами | дети путаются | одно новое условие |
| Игра без музыкальной задачи | можно без музыки | вернуть слуховую цель |
| Хаос с инструментами | шум вместо правила | «спит/звучит», одна задача |
| Сюжет слишком длинный | забыли музыку | 1–2 действия роли |
| Нет мостика в танец | просто повеселились | заложить 5-й слот перехода |

**Чек-лист иконками:**
1. Музыкальная задача ясна  
2. Правило короткое  
3. Дозировка реальная  
4. Стоп и дистанция понятны  
5. Есть мостик к композиции  

**Картинка:** светофор игры — зелёный «правило+музыка», красный «шум и хаос».
