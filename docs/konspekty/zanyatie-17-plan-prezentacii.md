### Слайд 2. Проблема: движения «выпадают» из игры
**Заголовок:** Слушание, пение, дидактика — в игре. А движения?

**Таблица «где уже есть игра»:**

| Раздел занятия | Как живёт игра/наглядность |
|---|---|
| Распевание | образ, театральный этюд |
| Пение | значки за чистоту, дикцию, выразительность |
| Слушание | иллюстрации, рассказ, эмоция |
| Дидактика | фланелеграф, яркий раздаточный материал |
| **Движения** | часто сухой «повтори за мной» |

**Картинка:** четыре весёлых окошка разделов и одно серое — «движения».  
**Крупно:** отсюда страх ошибки, скука и долгая постановка танца.

### Слайд 3. Цена сухого повтора
**Заголовок:** Не техника убивает интерес — страх и непонимание

**Таблица Contrasts:**

| Сухой повтор | Игровое обучение |
|---|---|
| «Поставь ногу сюда» | «Зайчик учит — Прыжок помогает» |
| ошибка = замечание при всех | ошибка внутри сюжета |
| абстрактная «пружинка» | кукла, которую можно потрогать |
| круг «на словах» | звёздочки-домики на полу |
| далёкий результат | туфелька за конкретный успех |

**Схема риска:**
```
не получилось при всех → комплекс → боится следующей пробы → гаснет интерес
```

**Картинка:** слева ребёнок с опущенными плечами после замечания; справа — тот же ребёнок в сюжете с Пружинкой, улыбается.

### Слайд 5. Принцип: что понятно — то выполнимо
**Заголовок:** Игра — не отмена обучения, а путь к навыку

**Большая схема:**
```
Интерес
  → понимание образа
    → проба без страха
      → осознание состава движения
        → перенос в танец
          → радость достижения
```

**Таблица опор:**

| Опора | Смысл |
|---|---|
| Образ | делает абстрактное конкретным |
| Сюжет | снимает страх ошибки |
| Поисковый вопрос | сильнее команды |
| Наглядность | экономит время |
| Достижение | делает успех видимым |

**Картинка:** ребёнок собирает на фланелеграфе кукол и только потом идёт в движение.  
**Крупно:** игра служит навыку, а не заменяет его.

### Слайд 6. Три героя — три «кирпичика» движения
**Заголовок:** Пружинка · Шажок · Прыжок

**Картинка-триптих:**  
1. Девочка Пружинка со спиральными ножками  
2. Мальчик Шажок  
3. Мальчик Прыжок  

**Таблица ролей:**

| Герой | Что даёт понять |
|---|---|
| Пружинка | мягкое полуприседание, «пружина» в ногах |
| Шажок | любые шаги и продвижения |
| Прыжок | прыжки, поскоки, галопные элементы |

**Схема логики автора:**
```
Почти все детские танцевальные движения
= шаги + прыжки на мягкой пружинке
```

**Фраза:** герои — не декорация, а инструмент анализа движения.

### Слайд 7. Таблица «движение = герои»
**Заголовок:** Составляем схему на фланелеграфе

**Большая таблица:**

| Движение | Схема героев |
|---|---|
| Пружинка | Пружинка |
| Приставной шаг | Шажок + Пружинка |
| Боковой галоп | Шажок + Пружинка + Прыжок |
| Поскок | Шажок + Прыжок (+ Пружинка) |
| Ковырялочка без поскока | Пружинка + Шажок |
| Ковырялочка на поскоке | + Прыжок |

**Схема вопроса детям:**
```
«Кто помогает выполнить это движение?» → выставить кукол/символы → попробовать
```

**Картинка:** фланелеграф с тремя куклами под табличкой «Боковой галоп».  
**Для старших:** куклы → условные знаки/символы.

### Слайд 8. Разметка зала и «Волшебная туфелька»
**Заголовок:** Пространство и мотивация тоже могут быть игрой

**Таблица разметки:**

**Крупно:** ребёнок видит свой рост, а не только замечания.

### Слайд 10. Младшая группа — страница поляны
**Заголовок:** Образ ведёт за собой движение

**Таблица маршрута:**

| Образ | Движение | Кто помогает |
|---|---|---|
| Тропинка | спокойный / бодрый шаг | Шажок |
| Бабочки | пружинка | Пружинка |
| Зайчик | прыжки на двух | Прыжок |
| Машина | топотушки | Шажок + Пружинка |
| Лошадка | галопчик | Прыжок (+ другие) |
| Солнышко | носок / пятка | Пружинка |
| Дождик | лёгкий бег → 3 притопа | — |
| Цветочки / жучки | фонарики, кружение | Пружинка |

**Схема приёма коррекции:**
```
Забыли пружинку на пятке → Пружинка «отвернулась»
→ пригласили снова → движение с пружинкой
```

**Картинка:** яркая поляна большого формата; зайчик, машина, солнышко; герои рядом.  
**Крупно:** коррекция через сюжет, не через стыд.

### Слайд 11. Средняя группа — деревня и платочек
**Заголовок:** Мягкость, поскок, народный колорит

**Таблица маршрута:**

| Образ | Движение |
|---|---|
| Кошечка | мягкий шаг |
| Дорожка | бодрый шаг |
| + Прыжок | лёгкие поскоки |
| Лошадка | прямой галоп |
| Берёзка | хороводный шаг |
| Платочек | передача, кружение |
| У берёзки | носок–пятка, притопы, «тарелочки» |

**Схема добавления героя:**
```
Шажок + Пружинка → шаг
+ Прыжок → поскок / динамика
```

**Картинка:** бабушкина деревня, берёзка с платочком, кошечка на крыльце.  
**Методический акцент:** страница готовит к парности и народным элементам.

### Слайд 12. Правая и левая — игровой фокус
**Заголовок:** Ленточки сильнее абстрактной схемы

**Схема опыта:**
```
1. Мальчик и девочка рядом
2. Яркая лента на правой ноге у обоих
3. Видно: правые с одной стороны
4. «Волшебство»: встали лицом друг к другу
5. Ленты оказались с разных сторон
```

**Таблица сравнений для детей:**

| Если начать с одной стороны | Если с разных |
|---|---|
| «барашки на бревне» | каждой ножке свободно |
| «машинки не разъедутся» | удобно и красиво видно |

**Картинка:** два кадра пары — бок о бок и лицом к лицу; ленты отмечены цветом.  
**Крупно:** пространство объясняется зрелищем, не лекцией.

### Слайд 13. Старшая группа — Школа Магистра
**Заголовок:** От образа — к осознанному классу

**Таблица блоков страницы:**

| Блок | Содержание |
|---|---|
| Вход | «ветер-ветерок», стремительный шаг |
| Поскоки | лёгкий и сильный |
| Образный сад | всадники, руки-дыхание |
| Балетный акцент | приставной шаг (Шажок + Пружинка) |
| Народный класс | пружинящий шаг, шаг с притопом, ковырялочка без поскока |
| Финал урока | кружение, ритмические хлопки, приглашение в Город Танцев |

**Схема роли Магистра:**
```
игра сохраняется → появляется «урок» → растёт точность и самоконтроль
```

**Картинка:** Магистр в шапочке с волшебной палочкой; герои — ассистенты у доски движений.

### Слайд 14. Подготовительная — Город Танцев
**Заголовок:** Собираем движения в танец

**Таблица моста «элемент → танец»:**

| Уже знали | Усложнение / сборка |
|---|---|
| Приставной шаг | + Прыжок = боковой галоп |
| Хороводный шаг | руки / точка / переменный |
| Пружинящий шаг | припадание |
| Ковырялочка без поскока | ковырялочка на поскоке |
| Весёлые ножки | метелочка, козлик |
| Руки | большие крылья |
| Хлопки | синкопированные |

**Схема польки (игровое «рецепт»):**
```
Прыжок + Пружинка + два шага Шажка = Полечка
```

**Картинка:** Королева Танцев; выбегают персонажи Полька и Вальс; замок на горизонте.  
**Крупно:** сначала движения, потом бал — не наоборот.

### Слайд 15. Как вести страницу альбома
**Заголовок:** Алгоритм педагога на фрагменте 8–10 минут

**Пошаговая схема:**
```
1. Открыть страницу / назвать место путешествия
2. Вызвать нужного героя
3. Короткий сюжетный мостик
4. Показ + проба
5. Поисковый вопрос / схема на фланелеграфе
6. Повтор в образе
7. Коррекция через сюжет
8. Маленький успех (туфелька/похвала-факт)
9. Мостик к следующему образу или танцу
```

**Таблица «делать / не делать»:**

| Делать | Не делать |
|---|---|
| один новый акцент | валить всю страницу без дозировки |
| герой до движения | термин без образа |
| править сюжетом | стыдить при всех |
| держать музыку | превратить в спектакль без навыка |

**Картинка:** педагог с альбомом и куклой; дети на звёздочках; на доске схема героев.

### Слайд 17. Чек-лист игрового обучения движению
**Заголовок:** Перед тем как считать приём готовым

| № | Вопрос | Да/Нет |
|---|---|---|
| 1 | Есть образ/сюжет, а не только термин? | |
| 2 | Герои реально объясняют состав движения? | |

**Схема баланса:**


**Картинка:** весы: на одной чаше маска/сюжет, на другой — точное движение; посередине улыбающийся ребёнок.
