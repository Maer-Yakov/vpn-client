# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Занятие 18. Пение с детьми от года до 3 лет в детском саду
**Тема:** слушание, ласковый голос, подхват короткой фразы для 1–3 лет  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Пение с детьми от года до 3 лет  
**Подзаголовок:** Занятие № 18 · Не «весь куплет» — слушание и мягкий подхват  

**На слайде:**
- возраст 1–3 года (ясли / первая младшая)  
- итог: ласковый показ + слушание + короткий подхват + пауза  

**Картинка:** воспитатель на коврике поёт малышам с игрушкой; рядом иконки ухо / голос / ладушки / платочек.  
**Схема-формула:**
```
услышал голос взрослого → откликнулся → подхватил звук / слог / конец фразы
```
**Мелко:** Ветлугина; Бабаджан; Дзержинская; Метлов; «Ладушки»

### Слайд 2. Чем пение до 3 лет особенное
**Заголовок:** Слушать и подхватывать — не сдавать номер

**Таблица отличий:**

| 1–3 года | 3–4 года и позже |
|---|---|
| взрослый почти полностью «несёт» мелодию | дети чаще подпевают фразы |
| основа — слушание и звукоподражание | появляется разучивание по фразам |
| попытка 20–60 секунд | песня может быть чуть длиннее |
| очень высокий риск крика при перевозбуждении | риск остаётся, но контроль лучше |

**Картинка:** две двери — «Концертный номер» (закрыта) и «Ласковое пение рядом» (открыта).  
**Крупно:** до 3 лет важнее желание откликаться голосом, чем идеальная нота.

### Слайд 4. Значение пения в развитии ребёнка
**Заголовок:** Пение — мост между речью, слухом и контактом

**Таблица:**

| Сфера | Что развивается |
|---|---|
| Слух | голос взрослого, начало/конец, знакомая мелодия |
| Речь | звукоподражания, слоги, ритм слова |
| Дыхание | более спокойный выдох |
| Эмоции | успокоение, радость, «со мной поют» |
| Общение | зрительный контакт, доверие |
| Память | узнавание короткой потешки |

**Схема:**
```
слух + речь + эмоция → желание быть рядом с поющим взрослым
```
**Картинка:** шесть сфер вокруг малыша, который слушает педагога.  
**Вывод:** пение до 3 лет — не «предмет», а голосовое общение.

### Слайд 5. Возрастные особенности внутри 1–3 лет
**Заголовок:** Один возраст — три ступени

**Таблица:**

| Возраст | Что доступно |
|---|---|
| 1–1,5 года | слушает; улыбается; иногда «а-а»; тянется к игрушке |
| 1,5–2 года | звукоподражания; конец слога; хлопок / кивок |
| 2–3 года | короткие фразы; 1–2 знакомых слова; любит повтор |

**Дополнительно — голос:**

| Особенность | Для педагога |
|---|---|
| узкий диапазон | без широких скачков |
| короткая фраза | взрослый держит мелодию |
| короткое внимание | 20–60 сек + пауза |

**Картинка:** лестница из 3 ступеней с игрушками (котик → петушок → ладушки).  
**Крупно:** не переносить приёмы старшей группы на ясли.

---

### Слайд 6. Можно / нельзя для голоса малыша
**Заголовок:** Светофор бережного пения

**Таблица:**

| Можно | Нельзя |
|---|---|
| мягкий естественный звук взрослого | крик, «давить» горлом |
| слушать и подхватывать рядом | требовать соло «как на сцене» |
| сидеть на коврике / у взрослого | долгое пение строем |
| короткая потешка с повтором | длинный куплетный номер |
| игрушка-образ, жест «ладушки» | сложная хореография при пении |
| пауза и смена | долбить до усталости |

**Картинка:** светофор — зелёный «мягко / коротко», жёлтый «пауза», красный «крик ✕».  
**Фраза:** стоп при крике — тоже педагогика.

### Слайд 7. Задачи обучения пению
**Заголовок:** Семь простых задач до 3 лет

**Лестница задач:**
```
1. Интерес к голосу взрослого
2. Слушание короткой песни / потешки
3. Звукоподражание и мягкое подпевание
4. Связь голоса с образом и жестом
5. Небольшой посильный репертуар
6. Беречь голос (коротко + пауза)
7. Готовить почву к пению после 3 лет
```

**Мини-схема:**
```
интерес → слушание → звук/слог → короткая фраза → мини-репертуар
```
**Картинка:** семь ступенек; наверху мягкая игрушка, не кубок «концерт».  
**Вывод:** меньше техники — больше интереса и мягкого звука.

### Слайд 8. Приёмы и этапы разучивания
**Заголовок:** Как вести пение в 1–3 года

**Таблица приёмов:**

| Приём | Как |
|---|---|
| Выразительный показ | лицом к детям, ласково |
| Подхватывание | взрослый поёт почти всё |
| Игровой образ | «споём котику» |
| Звукоподражание | «мяу», «ку-ку», «кап-кап» |
| Игрушка / ладушки | опора внимания |
| Короткий повтор | 2–3 раза → пауза |

**Этапы (схема-дорожка):**
```
интерес → показ (слушание) → узнавание → подхват → игровое закрепление → стоп
```

**Картинка:** дорожка из 6 станций с игрушкой-котиком.  
**Важно:** 2–5 минут с паузами; не требовать весь текст.

### Слайд 9. Упражнения для певческих навыков
**Заголовок:** Короткие игры голосом (15–30 секунд)

**Таблица:**

| Навык | Упражнение |
|---|---|
| Слушание | игрушка «спит», когда песня кончилась |
| Дыхание | подуть на платочек |
| Мягкий звук | тихое «а-а» / «мм» за педагогом |
| Звукоподражание | «мяу», «гав», «ку-ку» |
| Подхват конца | дети — последний слог |
| Жест + голос | «ладушки» с коротким напевом |

**Схема дозировки:**
```
одна задача → 15–30 сек → стоп / смена
```
**Картинка:** шесть карточек-станций на коврике.  
**Правило:** упражнение — ласковая игра, не вокальный станок.

---

### Слайд 10. Подбор песенного репертуара
**Заголовок:** Беру / не беру для 1–3 лет

**Критерии (таблица-вопросы):**

| Критерий | Вопрос |
|---|---|
| Длина | 20–60 сек активного участия? |
| Повтор | есть повтор слога / фразы? |
| Текст | понятный, добрый, близкий быту? |
| Образ | ясный герой / действие? |
| Мелодия | без широких скачков? |
| Роль взрослого | могу «нести» мелодию сам? |

**Беру / не беру:**

| Беру | Не беру |
|---|---|
| короткая потешка с повтором | длинный шлягер |
| кот, петух, дождик | взрослый / абстрактный текст |
| мягкая мелодия | крикливый высокий пик |
| петь на коврике | «сцена» и строй |

**Картинка:** полка «беру» и корзина «не беру».  
**Вывод:** репертуар — педагогическое решение, не плейлист телефона.

### Слайд 11. Практика и чек-лист студента
**Заголовок:** Мини-фрагмент 80–100 секунд

**Структура тренинга:**
```
интерес / упражнение (15–25 сек)
→ показ фразы + подхват
→ одно «можно» и одно «нельзя»
→ мягкий стоп и похвала
```

**Рубрика / чек-лист:**

| Вопрос | Да / Нет |
|---|---|
| Есть образ / игрушка? | |
| Голос мягкий? | |
| Подхват короткий? | |
| Есть пауза / стоп? | |
| Нет крика и «сцены»? | |
| Понятно, что это для 1–3, а не копия 3–4? | |

**Картинка:** студенты в паре с игрушкой проводят мини-показ на коврике.  
**Фраза:** хороший фрагмент короткий, тёплый и останавливается вовремя.

### Слайд 12. Итог и домашнее задание
**Заголовок:** Формула пения до 3 лет

**Крупная схема:**
```
Ласковый голос педагога
→ Слушание
→ Короткий подхват
→ Пауза
= правильное пение для 1–3 лет
```

**Таблица ДЗ / творческих заданий:**

| Задание | Содержание |
|---|---|
| 1. Таблица на 1 стр. | значение · 1–1,5/1,5–2/2–3 · задачи · этапы · упражнения · репертуар |
| 2. Разбор потешки | этапы + дозировка в секундах |
| 3. Мини-эссе | почему важнее показ и слушание, чем «весь куплет» |
| 4. Режимный момент | мини-сценарий 2 мин (умывание / укладывание / прощание) |

**Картинка:** воспитатель тихо поёт; малыш подхватывает слог; платочек «отдыхает».  
**Футер:** Ветлугина; Бабаджан; Дзержинская; Метлов; «Ладушки»  
**Финальная фраза:** берегите голос малыша — пение начнётся с вашего мягкого «рядом».
