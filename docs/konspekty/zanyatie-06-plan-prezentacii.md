# План презентации (18 слайдов) — РАЗВЁРНУТЫЙ
## Занятие 6. Ритмическое развитие детей от рождения до 1,5 лет
**Тема:** голос, касание, потешка и мягкий контраст как ритм младенца  
**Для студентов-воспитателей · 18–22 минуты**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Ритмическое развитие детей от рождения до 1,5 лет  
**Подзаголовок:** Занятие № 6 · Не танец по правилам — телесный диалог  

**На слайде:**
- ещё нет «занятия ритмикой» в привычном виде  
- итог: голос + касание + короткий повтор + пауза  

**Картинка:** взрослый качает младенца; рядом иконки ухо / сердце / руки / погремушка.  
**Схема-формула:**
```
услышал → почувствовал рядом со взрослым → оживился / успокоился
```
**Мелко:** Бабаджан; Ветлугина; Картушина «Забавы для малышей»

---

### Слайд 2. Чем этот возраст особенный
**Заголовок:** Самый ранний этаж ритмики

**Таблица отличий:**

| 0–1,5 лет | Позже (3–5+) |
|---|---|
| совместное движение | больше самостоятельности |
| голос важнее колонки | запись используется шире |
| нет строя и «стопа по правилу» | появляются игровые правила |
| контакт = главное условие | контакт важен, но уже есть задача |

**Картинка:** две двери — «Номер/строй» (закрыта) и «Тёплый диалог» (открыта).  
**Крупно:** младенец не готовит номер — он учится быть в ритме рядом со взрослым.

### Слайд 3. Цель занятия для студента
**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Понять слух и движение младенца
→ Увидеть реакции на интонации
→ Использовать колыбельные, потешки, пестушки
→ Двигаться вместе со взрослым
→ Держать телесный и эмоциональный контакт
→ Провести мягкие игры и контрасты
```

**Мини-таблица:**

| Знает | Умеет |
|---|---|
| особенности 0–1,5 лет | провести покачивание / ладушки / погремушку |
| границы «можно / нельзя» | остановиться при переутомлении |

**Картинка:** бланк «мягкий ритуал 2–3 минуты» как продукт занятия.

### Слайд 5. Слуховое и двигательное восприятие
**Заголовок:** Звук входит вместе с теплом рук

**Таблица по ориентирам:**

| Период | Слух | Движение |
|---|---|---|
| Первые месяцы | голос, ориентировка на звук | общие реакции тела |
| Ближе к полугоду | интерес к погремушке, интонации | тянется, трясёт, оживляется |
| К 1–1,5 годам | короткие игровые сигналы | подражает простым жестам рядом |

**Схема:**
```
голос / звук → реакция тела → повтор в контакте → привычный отклик
```

**Картинка:** волны голоса взрослого «входят» в младенца на руках.  
**Вывод:** даём сенсорный опыт, а не комбинацию.

---

### Слайд 6. Реакции на музыкальные интонации
**Заголовок:** Интонация — эмоциональное лицо звука

**Таблица:**

| Интонация | Желаемая реакция | Чего избегать |
|---|---|---|
| Мягкая певучая | спокойствие, контакт | громкая запись без тепла голоса |
| Светлая игривая | оживление | длинная серия до перевозбуждения |
| Тихо / чуть громче | внимание | резкие скачки и крик |
| Резкая громкая | вздрагивание, плач | использовать «для веселья» |

**Схема:**
```
сначала лицо и голос → потом предмет → потом запись
```

**Картинка:** три лица-эмодзи интонаций (спокойно / игриво / слишком резко перечёркнуто).

### Слайд 7. Колыбельные, потешки, пестушки
**Заголовок:** Главный «учебник» ритма для младенца

**Большая таблица:**

| Жанр | Ритмическая роль | Как использовать |
|---|---|---|
| Колыбельная | медленный пульс, успокоение | покачивание, тихий голос |
| Потешка | слоговой ритм, повтор | жест рук, ладушки |
| Пестушка | ритм заботы + касание | поглаживание, пальчики |

**Таблица отбора текста:**

| Беру | Не беру |
|---|---|
| добрый короткий образ | страшилки, резкая динамика |
| 2–6 строк на заход | длинный монолог |
| можно остановиться | «дожать до конца любой ценой» |

**Картинка:** три карточки жанров с пиктограммами качания / ладошек / касания.  

---

### Слайд 8. Движение вместе со взрослым
**Заголовок:** Взрослое тело — безопасный метроном

**Таблица форм:**

| Форма | Когда уместно |
|---|---|
| На руках / на коленях | база возраста |
| Лёжа — мягкое ведение рук/ног | младшие месяцы |
| Сидя с опорой | вместе хлопаем, качаемся |
| У опоры / с поддержкой | только при физической готовности |

**Схема принципов:**
```
приглашать, не тащить
→ ритм задаёт взрослый
→ коротко (часто 20–40 сек)
→ плач/отворот = стоп или упрощение
```

**Картинка:** взрослый и младенец на коленях «топ-топ»; рядом запрет «строя».  
**Ошибка:** требовать топать под марш в строю.

---

### Слайд 9. Телесная чувствительность и контакт
**Заголовок:** Без взгляда и тепла ритм не приживается

**Таблица:**

| Есть контакт | Нет контакта |
|---|---|
| осмысленное оживление / успокоение | вздрагивание, отворот, плач |
| повтор приятен | стимул как давление |
| можно чуть усложнить | нужно упростить / остановиться |

**Схема контакта:**
```
взгляд + голос + касание + пауза = эмоциональная безопасность
```

**Картинка:** крупно глаза взрослого и младенца; руки поддерживают.  
**Вывод теории:** ритм 0–1,5 лет = мягкий слух + совместное тело + голос + повтор + безопасность.

---

### Слайд 10. Можно и нельзя в 0–1,5 лет
**Заголовок:** Границы мягкости

| Можно | Нельзя |
|---|---|
| петь, качать, гладить в ритме | трясти, подбрасывать |
| короткие потешки и ладушки | долбить до отказа |
| мягкий контраст тихо/чуть громче | крик, хлопок у уха |
| погремушка с ритуалом «спит» | долгий хаотичный шум |
| остановиться по состоянию ребёнка | «танец по правилам», строй |

**Картинка:** светофор мягкости — зелёный «можно», красный «нельзя».  
**Крупно:** право на паузу — профессиональный навык, не слабость.

### Слайд 11. Обзор практики
**Заголовок:** Пять мягких блоков

**Таблица:**

| Блок | Задача |
|---|---|
| Игры на руках | ритм через тело взрослого |
| Ладушки / пальчики | слог + мелкий жест |
| Покачивания | медленный пульс и смена состояния |
| Погремушки | звук ↔ тишина |
| Сигналы и контрасты | услышать разницу без перегруза |

**Картинка:** пять станций-пузырьков вокруг младенца на руках.  
**Акцент:** в каждой пробе — одна задача и обязательный стоп.

---

### Слайд 12. Практика 1. Игры на руках
**Заголовок:** Покачать — не значит растрясти

**Таблица хода:**

| Шаг | Действие |
|---|---|
| 1 | устойчиво взять, поддержать голову (модель младшего) |
| 2 | тихий напев + мягкое качание |
| 3 | чуть оживлённый напев + лёгкий «топ-топ» без подпрыгивания |
| 4 | стоп: прижать, снизить голос, пауза |

**Схема безопасности:**
```
не трясти → не подбрасывать → читать «плач» модели → стоп
```

**Картинка:** правильная поддержка на руках; рядом перечёркнутое подбрасывание.  

---

### Слайд 13. Практика 2. Ладушки и пальчиковые игры
**Заголовок:** Голос теплее хлопка

**Таблица качества:**

| Хорошо | Плохо |
|---|---|
| голос слышнее хлопка | хлопки глушат слово |
| темп удобен малышу | гонка «успеть всё» |
| 2–3 повтора | долбить до отказа |
| пауза посмотреть в глаза | лицо в сторону / в телефон |

**Схема хода:**
```
потешка → жест на ударных слогах → повтор → взгляд-пауза
```

**Картинка:** ладошки «ладушки» + подпись ударных слогов.  
**Важно:** не требовать идеального попадания ладошек.

---

### Слайд 14. Практика 3. Покачивания под музыку
**Заголовок:** Медленный пульс и мягкий контраст

**Таблица вариантов:**

| Вариант | Содержание |
|---|---|
| На руках | колыбельная |
| На коленях | «кач-кач» |
| Лёжа (модель) | лёгкое ведение без резкости |
| Контраст | 20 сек спокойно → 10 сек чуть бодрее → снова спокойно |

**Схема:**
```
спокойный пульс → короткий контраст → возврат к спокойствию
```

**Картинка:** маятник-качание; «бодрее» ≠ «громко».  

---

### Слайд 15. Практика 4. Погремушка и звуковые контрасты
**Заголовок:** Учить тишине так же, как звуку

**Таблица погремушки:**

| Шаг | Действие |
|---|---|
| 1 | показать лицом и голосом |
| 2 | тихо потрясти в ритме слогов |
| 3 | «погремушка спит» |
| 4 | снова короткий звук → сон |
| 5 | вместе с «малышом» удержать и слегка потрясти |

**Таблица контрастов:**

| Можно | Нельзя |
|---|---|
| мягкий контраст 2 качеств | резкий крик / хлопок у уха |
| 3–5 коротких смен | длинная «дискотека» |
| стоп при переутомлении | «ещё разок» через силу |

**Картинка:** погремушка «звенит / спит»; карточки тихо–чуть громче.

### Слайд 18. Итог + домашнее задание
**Заголовок:** Ритм начинается с тёплого взрослого

**Крупно:**
```
Мягкий голос.
Короткая форма.
Право на паузу.
Тогда ритм младенца растёт правильно.
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица на 1 стр. | слух · двигательный ответ · роль взрослого · 2 примера · можно/нельзя |
| 2. Ритуал 2–3 мин | покачивание + потешка + погремушка с тишиной (8–12 мес.) |
| 3. Мини-эссе | почему контакт важнее идеального жеста |

**Картинка:** взрослый тихо поёт и качает; погремушка «спит» у груди.  
**Футер:** Бабаджан; Ветлугина; Картушина  
**Финальная фраза:** сохраните мягкость — и ритмическое развитие начнётся с правильного этажа.
