# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Работа над музыкальными песнями-сказками с детьми дошкольного возраста
**Тема:** пение + сюжет + образ; кукла на руку — опора, не замена песни  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Музыкальные песни-сказки  
**Подзаголовок:** Короткая, посильная, добрая песенная сказка — не большой спектакль  

**На слайде:**
- дошкольный возраст  
- итог: мягкое пение → ясный образ → 1 кукла/жест → короткий сюжет → пауза  

**Картинка:** педагог с игрушкой на руку тихо напевает; дети слушают / подпевают; иконки пение / сюжет / образ / кукла.  
**Схема-формула:**
```
мягкое пение → ясный образ → 1 кукла / жест → короткий сюжет → пауза
```
**Мелко:** Ветлугина · Радынова · Метлов · «Ладушки» · театрализация в ДОУ

---

### Слайд 2. Чем отличается
**Заголовок:** Песня, игра или песня-сказка?

**Таблица:**

| Форма | Отличие |
|---|---|
| Обычная песня | может быть без сюжета и ролей |
| Игра-песня | правило / роль, не всегда сказка |
| Театральная постановка | длиннее, больше реквизита |
| Песня-сказка | короткая сюжетная песня + образ |

**Картинка:** четыре карточки форм; выделена «песня-сказка».  
**Крупно:** музыка и голос главные; кукла — опора внимания.

### Слайд 4. Виды песен-сказок
**Заголовок:** Шесть рабочих видов

**Таблица:**

| Вид | Суть |
|---|---|
| Один герой | группа «становится» героем |
| Диалогическая | реплики по очереди |
| Цепочная | герои добавляются |
| Событийная | пошёл — встретил — помог |
| Хороводно-сказочная | круг + сюжет |
| Кукольная | ведущий образ — кукла на руку |

**Схема возраста:**
```
1,5–3 — 1 герой · 3–5 — диалог / цепочка · 5–7 — роли и куклы дозированно
```
**Картинка:** шесть карточек видов с простыми силуэтами героев.  
**Вывод:** чем младше — тем короче и проще.

### Слайд 5. Влияние на развитие
**Заголовок:** Музыка · речь · общение

**Таблица:**

| Сфера | Что развивается |
|---|---|
| Музыкальное | характер, фраза, выразительность |
| Речевое | словарь, дикция, диалог |
| Социальное | роли, очередь, эмпатия |
| Эмоциональное | добрый / смелый образ без страха |
| Внимание | порядок событий |

**Схема-риски:**
```
длинный сюжет · гора реквизита · страшный образ · крик «в роли»
```
**Картинка:** мост «пение — речь — игра»; мягкие иконки.  
**Фраза:** песня-сказка — мост, а не спектакль любой ценой.

---

### Слайд 6. Этапы разучивания
**Заголовок:** Как разучивать песню-сказку

**Таблица:**

| Этап | Действие |
|---|---|
| Интерес | показ куклы / вопроса |
| Слушание | сюжет целиком |
| Образы | кто добрый / хитрый |
| Фразы | 1–2 строки |
| Роль | мягкий голос героя |
| Действие | жест / кукла |
| Вместе | короткий прогон |
| Стоп | пауза и похвала |

**Схема-дорожка:**
```
интерес → слушание → образы → фразы → роль → действие → вместе → стоп
```
**Картинка:** дорожка этапов в музыкальном зале.  
**Ошибки:** начинать с костюмов; требовать «актёрской» игры.

### Слайд 7. Творческие упражнения
**Заголовок:** Банк коротких упражнений

**Таблица:**

| Упражнение | Задача |
|---|---|
| Голос героя | фраза «как зайка / медведь» |
| Жест-подпись | 1 жест на героя |
| Эхо-сказки | повтор в характере |
| Кто говорит? | угадать по пению |
| Продолжи историю | 1 жест / слово |
| Тихое волшебство | кульминация тише |
| Очередь ролей | смена каждые 20–30 сек |

**Картинка:** карточки упражнений в круге детей / студентов.  
**Рубрика:** одна задача · мягкий голос · ясный образ · короткий стоп.

### Слайд 8. Анализ музыкальных образов
**Заголовок:** Карточка образа

**Таблица-карточка:**

| Вопрос | Смотрим |
|---|---|
| Кто герой? | имя / роль |
| Характер музыки | спокойно / бодро / ласково / хитро |
| Темп | медленнее / умеренно / живее |
| Динамика | тихо / умеренно |
| Жест | 1–2 действия |
| Речевая краска | мягко / уверенно |
| Роль куклы | помогает увидеть |
| Риск | … |

**Схема контрастов:**
```
зайка — медведь · капелька — ветер · добрый — хитрый
контраст характером и жестом, не силой голоса
```
**Картинка:** бланк анализа рядом с двумя карточками героев.

---

### Слайд 9. Реквизит: можно / нельзя
**Заголовок:** Чемоданчик сказки

**Таблица:**

| Беру ✓ | Не беру ✕ |
|---|---|
| 1–3 понятных предмета | гора костюмов сразу |
| кукла, видимая детям | мелкий «для себя» |
| безопасно, легко надеть | мешает дышать / петь |
| связано с героем | случайный яркий предмет |
| убрать за 5 секунд | сложный монтаж сцены |

**Схема-формула:**
```
сначала песня и образ → потом 1 кукла / 1 деталь → потом (если нужно) ещё один элемент
```
**Картинка:** открытый «чемоданчик» с 1 куклой и 1 платочком; лишнее зачёркнуто.  
**Фраза:** мало · понятно · убрать быстро.

---

### Слайд 10. Игрушки на руку
**Заголовок:** Кукла помогает увидеть героя

**Таблица:**

| Задача куклы | Как |
|---|---|
| Привлечь внимание | появление до пения |
| Показать героя | «поёт» вместе с педагогом |
| Вести диалог | вопрос куклы — ответ детей |
| Сменить роль | передать следующему |
| Закончить | поклон / уход на стоп |

**Техника (минимум):**
```
на уровне лица · крупные редкие движения · мягкий голос · убрать после фрагмента
```
**Картинка:** педагог с бибабо; кукла не закрывает рот; дети смотрят.  
**По возрасту:** младшие — кукла у педагога; старшие — короткие роли по очереди.

### Слайд 11. Мини-лаборатория и рубрика
**Заголовок:** Показ 60–90 секунд

**Структура:**
```
появление куклы
→ 1–2 фразы
→ жест / действие
→ короткий прогон
→ стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Кукла помогает увидеть героя? | |
| Песня слышна? | |
| Нет хаоса реквизита? | |
| Реквизит убирается быстро? | |
| Голос мягкий? | |

**Картинка:** студенты в тройках показывают фрагмент; наблюдатели с бланком.  
**Фраза:** хороший фрагмент короткий, ясный и без «спектакля».

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула песни-сказки

**Крупная схема:**
```
Мягкое пение
+ ясный образ
+ 1 кукла / жест
+ короткий сюжет
+ пауза
= доступная песня-сказка
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | виды · развитие · этапы · реквизит |
| 2. Разбор | герои, возраст, 2 упражнения, ≤3 реквизита |
| 3. Мини-эссе | почему нельзя начинать со спектакля |
| 4. Сценарий | кукла → фразы → роль → стоп (2–2,5 мин) |
| 5. Картотека | 6 позиций с предостережением |

**Картинка:** финальный мягкий показ: педагог, кукла, дети подпевают; реквизит убран в сторону.  
**Футер:** Ветлугина · Радынова · Метлов · «Ладушки» · театрализация в ДОУ  
**Финальная фраза:** сказка начинается с мягкого пения — не с декораций.
