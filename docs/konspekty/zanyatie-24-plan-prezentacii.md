# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Здоровьесберегающие технологии в вокальной работе с детьми дошкольного возраста
**Тема:** мягкое, короткое, посильное пение; без форсирования и крика  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Здоровьесбережение в вокальной работе  
**Подзаголовок:** Естественное, комфортное пение дошкольников — без крика и спешки  

**На слайде:**
- дошкольный возраст  
- итог: мягкий показ → короткая проба → наблюдение → пауза  

**Картинка:** педагог мягко поёт с детьми в музыкальном зале; иконки мягкость / краткость / пауза / наблюдение.  
**Схема-формула:**
```
мягкий показ → короткая проба → наблюдение → пауза → повтор только если легко
```
**Мелко:** Ветлугина · Радынова · Метлов · охрана детского голоса · «Ладушки»

---

### Слайд 2. Зачем это нужно
**Заголовок:** Голос — не «чем громче, тем лучше»

**Таблица:**

| Риск | Что происходит |
|---|---|
| Крик «для выразительности» | напряжение, усталость |
| Длинные повторы | утомление аппарата |
| Неудобный диапазон | зажим, отказ петь |
| Стыд за тихий голос | страх и крик «чтобы угодить» |
| Игнор осиплости | вред здоровью |

**Картинка:** две двери — «Крик и форс» (закрыта) и «Мягкое пение» (открыта).  
**Крупно:** здоровье важнее громкости.

**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**

Особенности детского голоса

**Картинка:** бланк «мини-комплекс здоровьесбережения».

### Слайд 4. Особенности детского голоса
**Заголовок:** Не уменьшенный взрослый голос

**Таблица:**

| Особенность | Смысл для педагога |
|---|---|
| Аппарат формируется | без «взрослого» звука |
| Малый диапазон | посильный репертуар |
| Быстрая утомляемость | короткие фрагменты |
| Легко кричит | следить за мягкостью |
| Копирует эталон | показ решающий |

**Схема возраста:**
```
1,5–3 — подпевание · 3–5 — игровые распевки · 5–7 — чуть точнее, без форса
```
**Картинка:** мягкий эталон педагога и дети, спокойно подпевающие.  
**Вывод:** педагог — организатор безопасного пения, не «тренер голоса».

---

### Слайд 5. Принципы здоровьесбережения
**Заголовок:** Восемь рабочих принципов

**Таблица:**

| Принцип | Практика |
|---|---|
| Мягкость | без жёсткой атаки |
| Краткость | короткие упражнения |
| Посильность | по возрасту |
| Чередование | пение ↔ пауза / игра |
| Пауза | тишина — методика |
| Наблюдение | видеть усталость |
| Климат | без страха ошибки |
| Эталон | спокойный показ |

**Схема-формула:**
```
мягко · коротко · посильно · с паузой · с наблюдением
```
**Картинка:** схема-круг принципов вокруг мягко поющего ребёнка.

---

### Слайд 6. Голосовая гигиена
**Заголовок:** Можно и нельзя

**Таблица:**

| Можно ✓ | Нельзя / осторожно ✕ |
|---|---|
| после лёгкой разминки | при боли / осиплости |
| коротко, с паузами | долгие репетиции |
| мягкая динамика | «кто громче» |
| удобная осанка | зажим / запрокинутая голова |
| остановить при усталости | «ещё раз через силу» |

**Признаки стоп:**
```
хрип · напряжение шеи · кашель · отказ петь · крик вместо пения
```
**Картинка:** карточки «можно / нельзя» и жест «стоп».  
**Фраза:** остановить — тоже забота о голосе.

---

### Слайд 7. Осанка, дыхание, расслабление
**Заголовок:** Тело помогает голосу

**Таблица:**

| Блок | Упражнения |
|---|---|
| Осанка | «нить вверх», плечи вниз |
| Дыхание | «цветок», «свеча», короткая фраза |
| Расслабление | кисти, зевота-улыбка, «кукла» |

**Схема:**
```
осанка → спокойный вдох → мягкий выдох → свободное лицо → звук
```
**Картинка:** круг детей / студентов: плечи опущены, мягкий выдох.  
**Правило:** не строевая стойка — игровая свобода.

---

### Слайд 8. Артикуляция, дикция, слух
**Заголовок:** Ясность без напряжения

**Таблица:**

| Направление | Примеры |
|---|---|
| Артикуляция | мягкие гласные, «окошко» |
| Дикция | слоги, тихая скороговорка + напев |
| Слух | эхо, выше–ниже, 2–3 ступени |

**Схема:**
```
сначала мягко и коротко → потом яснее · никогда громче «для исправления»
```
**Картинка:** эхо-игра руками «выше — ниже»; мягкий эталон.  
**Крупно:** ошибку высоты не исправляют громкостью.

---

### Слайд 9. Банк упражнений гигиены
**Заголовок:** Бережные упражнения

**Таблица:**

| Упражнение | Зачем |
|---|---|
| Тихий «ммм» | мягкий контакт |
| Узкая тихая «сирена» | гибкость без форса |
| «Сдули пылинку» | спокойный выдох |
| «Ля-ля» на 2–3 звуках | разогрев |
| «Говорим — поём» | без скачка громкости |
| Пауза-тишина | отдых |

**Картинка:** карточки упражнений в музыкальном зале.  
**Дозировка:** секунды и короткие повторы, не «тренировка до результата».

---

### Слайд 10. Мини-комплекс 2–2,5 минуты
**Заголовок:** Старт пения без вреда

**Таблица-алгоритм:**

| Шаг | Действие |
|---|---|
| 1 | плечи вниз + «нить вверх» |
| 2 | «цветок» — «свеча» |
| 3 | мягкие слоги |
| 4 | эхо 2–3 звука |
| 5 | пауза → короткая песня |

**Схема:**
```
тело → дыхание → слоги → эхо → пауза → песня
```
**Картинка:** таймер / дорожка из пяти шагов рядом с педагогом.

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула здоровьесберегающего пения

**Крупная схема:**
```
Мягкий показ
+ короткая проба
+ наблюдение
+ пауза
+ повтор только если легко
= безопасное пение
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | особенности · принципы · признаки стоп · банк |
| 2. Разбор песни | риски, разминка 2 мин, пауза |
| 3. Мини-эссе | почему нельзя «исправлять громкостью» |
| 4. Сценарий | осанка → дыхание → распевка → фраза → стоп |
| 5. Картотека | 6 упражнений с дозировкой и «стоп» |

**Картинка:** финальный мягкий хоровой момент; дети спокойны, педагог улыбается.  
**Футер:** Ветлугина · Радынова · Метлов · охрана детского голоса · «Ладушки»  
**Финальная фраза:** голос растёт в радости и свободе, а не в крике и спешке.
