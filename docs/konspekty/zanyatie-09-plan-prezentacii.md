# План презентации (16 слайдов)
## Занятие 9. Танцевальное развитие детей 4–5 лет
**Аудитория:** студенты-воспитатели · **время показа:** 15–18 минут

---

### Слайд 1. Титульный
**Заголовок:** Танцевальное развитие детей 4–5 лет  
**Подзаголовок:** Занятие № 9 · для студентов-воспитателей  
**Картинка:** дети в кругу с платочками / силуэты танцующих дошкольников  
**Мелко:** Буренина «Ритмическая мозаика»; Фирилева, Сайкина «Са-Фи-Дансе»; Каплунова, Новоскольцева «Ладушки»

---

### Слайд 2. Возраст 4–5 лет
**Заголовок:** Средняя группа уже готова к танцу  
**Схема сравнения:**
```
1,5–3 года              4–5 лет
подражание образу  →    танцевальный элемент
короткий повтор    →    короткая комбинация
```
**Картинка:** два ребёнка разного возраста  
**Тезис:** это уже не только «мишки и зайчики», но ещё не сцена

---

### Слайд 3. Цель для воспитателя
**Заголовок:** Чему учимся мы  
**Схема-стрелка:**
```
Навык → Координация → Фраза → Образ → Группа
```
**Список:**
- формировать танцевальные навыки  
- развивать координацию рук и ног  
- учить двигаться по музыкальной фразе  
- развивать выразительность и взаимодействие  

---

### Слайд 4. Карта темы
**Заголовок:** Содержание занятия  
**Схема-солнце / 5 блоков теории + практика:**
1. Танцевальные навыки  
2. Координация рук и ног  
3. Музыкальная фраза  
4. Образ и выразительность  
5. Групповое взаимодействие  

**Практика вокруг:** шаг с носка · приставной · притопы · повороты · ленты/платочки · комбинации  
**Картинка:** иконки элементов вокруг центра «4–5 лет»

---

### Слайд 5. Формирование танцевальных навыков
**Заголовок:** Сначала качество одного движения  
**Схема ступеней:**
```
Образец → Попытка → Уточнение под музыку → Связка → Комбинация
```
**Крупно:**
```
Сначала качество одного движения,
потом красота танца
```
**Картинка:** одна стопа / один элемент крупным планом  
**Ошибка:** учить сразу весь танец «с листа»

---

### Слайд 6. Координация рук и ног
**Заголовок:** Усложняем по уровням  
**Схема лестницы:**
```
1. Только ноги
2. Ноги + руки на поясе / в стороны
3. Ноги + движение рук
4. + предмет
5. + перемещение по залу
```
**Картинка:** пиктограммы «ноги → руки → лента → стрелка по залу»  
**Тезис:** не давать все уровни сразу

---

### Слайд 7. Движение по музыкальной фразе
**Заголовок:** Фраза — рамка танца  
**Схема:**
```
1–8 счёт      9–16 счёт
шаг с носка → притопы
начало вместе → смена вместе → конец вместе
```
**Формулы:**
- «Новая музыка — новое движение»  
- «Фраза кончилась — ножки вместе»  

**Картинка:** нотная фраза / дуга 8+8 с сменой цвета  
**Акцент:** без фразы танец становится хаосом любимых движений

---

### Слайд 8. Образ и эмоциональная выразительность
**Заголовок:** Точный шаг + живой образ  
**Схема-таблица образов:**
| Движение | Образ |
|---|---|
| шаг с носка | идём в гости |
| притопы | весёлые сапожки |
| кружение | снежинки / юла |
| лента | ветерок |

**Крупно:**
```
Не улыбка «по команде»,
а движение в характере музыки
```
**Картинка:** одно и то же движение в двух характерах — мягко / озорно

---

### Слайд 9. Групповое взаимодействие
**Заголовок:** Уметь танцевать вместе  
**Схема правил:**
```
Окошко между друзьями
Не обгонять
Начинаем и заканчиваем вместе
Смотрим, куда идём
```
**Алгоритм:**
```
Рисунок пространства → знакомое движение → смена по фразе → пара/предмет
```
**Картинка:** круг детей с равными интервалами

---

### Слайд 10. Практика: шаг с носка
**Заголовок:** Шаг с носка — основа красивого танца  
**Схема хода:**
```
Показ → Образ → По кругу → 8+8 со сменой → руки
```
**Команды:**
- «Носочек рисует дорожку»  
- «Голова вверх»  
- «Шаг маленький и мягкий»  

**Картинка:** схема стопы «с носка»  
**Ошибки:** шарканье, взгляд в пол, жёсткие колени

---

### Слайд 11. Практика: приставной шаг
**Заголовок:** Приставной шаг  
**Схема:**
```
Шаг в сторону → ножка приставилась
8 счётов вправо → 8 счётов влево
```
**Образ:** «Дверца открылась — и закрылась»  
**Картинка:** следы стоп вбок + стрелки  
**Метод:** сначала на линии, потом в круге

---

### Слайд 12. Практика: притопы
**Заголовок:** Притопы — ритм и акцент  
**Схема фразы:**
```
1–8: шаг с носка
9–16: притопы
конец фразы: ножки вместе, ручки на пояс
```
**Образ:** «Сапожки поздоровались с полом»  
**Картинка:** акцентированная доля / ударные ноты  
**Важно:** активно, но не травмоопасно

---

### Слайд 13. Практика: повороты и кружения
**Заголовок:** Кружение только безопасное  
**Схема:**
```
Медленный поворот → короткое кружение → СТОП
```
**Комбинация-кусок:**
```
8 шаг с носка + 4 кружение + остановка
```
**Красные правила:**
- короткая дозировка  
- дистанция  
- выход в устойчивость  
- без раскрутки до головокружения  

**Картинка:** юла / снежинка + значок «стоп»

---

### Слайд 14. Ленты и платочки
**Заголовок:** Предмет не мешает, а помогает  
**Схема-таблица:**

| Предмет | Сначала | Затем | По фразе |
|---|---|---|---|
| платочек | взмахи на месте | шаг с носка | машем / прячем |
| лента | волны на месте | приставной | убрать в корзину |

**Крупно:**
```
Сначала движение, потом предмет
Один атрибут на фрагмент
```
**Картинка:** платочек и лента; проще начать с платочка

---

### Слайд 15. Несложные комбинации
**Заголовок:** Собираем танец по фразам  
**Схема комбинации А:**
```
1–8   шаг с носка
9–16  притопы
17–24 приставной
25–32 кружение + хлопок
```
**Алгоритм разучивания:**
```
По фразам без музыки → каждая фраза с музыкой → склеить → повторить 1–2 раза
```
**Картинка:** 4 цветных блока-фразы в ряд  
**Тезис:** не добиваться идеальной синхронности любой ценой

---

### Слайд 16. Итог и чек-лист
**Заголовок:** Что должен уметь воспитатель  
**Чек-лист:**
1. Показать шаг с носка, приставной, притопы  
2. Дозировать повороты  
3. Менять движение по фразе  
4. Дать образ, а не только счёт  
5. Держать группу и интервал  
6. Безопасно работать с предметом  

**Крупно:**
```
Танец начинается с точного шага,
слышания фразы и умения быть вместе
```
**Мини-задание:**
```
Соберите 4 фразы:
шаг с носка → притопы → приставной → остановка
```
**Картинка:** галочка / дети кланяются в конце танца  
**Футер:** Буренина; «Са-Фи-Дансе»; «Ладушки»
