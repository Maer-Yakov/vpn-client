# Telegram-бот с доступом к ИИ

Один бот в личных сообщениях: текстовые модели и генерация картинок, оплата тарифов через Telegram Stars. Бесплатный тариф ограничен по дню (сброс в 00:00 UTC). Веб-сервера нет, бот работает через long polling.

## Запуск

Нужен Python 3.11+.

```bash
cd telegram-bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Проверка синтаксиса из корня репозитория и тестов лимитов:

```bash
python -m compileall telegram-bot
cd telegram-bot
pytest
```

## Настройка .env

| Переменная | Зачем |
| --- | --- |
| `BOT_TOKEN` | Токен от BotFather |
| `ADMIN_ID` | Telegram user id администратора |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL` | Текстовые модели. Пустой URL — официальный API OpenAI |
| `BASIC_TEXT_MODEL`, `TOP_TEXT_MODEL` | Базовая и топовая модели, по умолчанию `gpt-4o-mini` и `gpt-4o` |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | Необязательно. Без ключа Claude скрыт |
| `IMAGE_API_KEY`, `IMAGE_BASE_URL`, `IMAGE_MODEL` | Картинки (Images API). Без ключа кнопка картинок отвечает, что генерация недоступна |
| `PRO_PRICE_STARS`, `UNLIMITED_PRICE_STARS` | Цены в Stars, по умолчанию 500 и 1500 |
| `DB_PATH` | Файл SQLite, по умолчанию `bot.db` |

Если ключа провайдера нет, его модели не показываются, бот всё равно запускается.

## Тарифы

- Бесплатный: 10 текстов в день, без картинок, только базовая модель.
- Pro: 500 текстов, 50 картинок, базовая и топовая модели. 30 дней.
- Безлимит: текст без лимита, 300 картинок, все подключённые модели. 30 дней.

Повторная оплата того же тарифа продлевает текущий срок ещё на 30 дней. Один и тот же платёж Telegram учитывается один раз. Если провайдер ответил ошибкой, лимит не списывается.

Картинка возвращается как URL (`http`/`https`) либо как путь к временному PNG. Обработчик сам решает, как отправить фото, и удаляет временный файл.

## Команды

В чате хватает кнопок. Дополнительно: `/start`, `/profile`, `/admin` (только `ADMIN_ID`).

Группы игнорируются. SQL находится только в `db.py`.
