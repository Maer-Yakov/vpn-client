# План презентации (18 слайдов) — РАЗВЁРНУТЫЙ
## Занятие 10. Танцевальное развитие детей 5–6 лет
**Аудитория:** студенты-воспитатели · **время показа:** 18–22 минуты

### Слайд 1. Титульный
**Заголовок:** Танцевальное развитие детей 5–6 лет  
**Подзаголовок:** Занятие № 10 · для студентов — будущих воспитателей  

**На слайде:**
- возраст: старшая группа  
- формат: теория + практика танцевальных навыков  

**Картинка:** дети 5–6 лет в паре на кружении / проход по диагонали зала  

**Мелко внизу:**  
Буренина А. И. «Ритмическая мозаика» · Фирилева Ж. Е., Сайкина Е. Г. «Са-Фи-Дансе» · Ветлугина Н. А. «Методика музыкального воспитания в детском саду»

### Слайд 2. Почему старшая группа — другой уровень
**Заголовок:** 5–6 лет: уже не «поставь элемент», а «собери танец»

**Схема сравнения (две колонки):**

| 4–5 лет | 5–6 лет |
|---|---|
| шаг с носка, приставной, притопы | переменный шаг, галоп, подскоки |
| короткая связка 2–3 элемента | последовательность 4–5 элементов |
| круг, простая комбинация | пары, диагональ, ансамбль |
| смена по фразе с подсказкой | смена по фразе всё более самостоятельно |

**Описание для ведущего:**  
В средней группе педагог в основном ставит качество отдельного движения. В старшей появляется новая нагрузка на память, слух к группе и пространство зала. Если давать старшим только материал 4–5 лет, они скучают; если сразу ставить «номер», появляется хаос. Нужен мост: знакомое → одно новое → связка → ансамбль.

**Картинка:** две ступени лестницы с подписями «элемент» и «последовательность»

---

### Слайд 3. Цель занятия для студента-воспитателя
**Заголовок:** Чему должен научиться воспитатель

**Крупная схема-стрелка:**
```
Усложнить координацию
→ Научить помнить порядок
→ Собрать синхронность
→ Держать музыкальную фразу
→ Добавить выразительность
```

**Развёрнуто пунктами:**
1. Понимать, *что именно* усложняется в 5–6 лет.  
2. Уметь вводить одно новое условие за попытку.  
3. Выстраивать запоминание последовательности без путаницы.  
4. Организовать пары и диагональ безопасно.  
5. Собирать комбинацию по фразам, а не «с листа целиком».

**Картинка:** портфель/чеклист воспитателя

### Слайд 4. Карта всей темы
**Заголовок:** От теории к практике

**Центр схемы:** «Танцевальное развитие 5–6 лет»

**Левая половина — теория:**
1. Усложнение координации  
2. Память последовательности  
3. Синхронность и взаимодействие  
4. Музыкальные фразы  
5. Выразительность и артистизм  

**Правая половина — практика:**
- переменный шаг  
- боковой галоп  
- подскоки  
- кружение в парах  
- диагональ  
- комбинация из нескольких элементов  

**Описание:**  
Теория отвечает на вопрос «почему так учим». Практика — «как провести руками и ногами». Самые сложные места занятия: галоп, парное кружение, диагональный поток и сборка комбинации.

**Картинка:** mind map / два крыла одной темы

### Слайд 5. Усложнение координации — подробно
**Заголовок:** Координация растёт только ступенями

**Это один из сложных блоков — дать развёрнуто.**

**Что усложняется в 5–6 лет:**
- смена направления;  
- чередование разных шагов;  
- руки + ноги одновременно;  
- перемещение по диагонали;  
- быстрые движения (галоп, подскоки);  
- действие в паре.

**Лестница введения (обязательная схема):**
```
1. Знакомый элемент в новом пространстве
2. Новый элемент на месте / по кругу
3. Связка двух знакомых элементов
4. Добавление рук или пары
5. Только потом — полная комбинация
```

**Золотое правило крупно:**
```
Одно новое условие за попытку
```

**Пример ошибки:**  
сразу: переменный шаг + руки + диагональ + синхронный старт всей группы.  
**Как правильно:**  
сначала переменный шаг по кругу → потом тот же шаг по диагонали по одному → потом руки → потом синхронный выход.

**Картинка:** лестница из 5 ступеней; на каждой — одна «галочка» нового условия

---

### Слайд 6. Запоминание последовательности — подробно
**Заголовок:** Как научить детей помнить «что за чем»

**Это сложный методический блок — расписать по шагам.**

**Почему детям трудно:**  
они могут выполнить элемент, но теряют порядок, особенно если педагог каждый раз подсказывает по-разному или меняет последовательность.

**Алгоритм запоминания:**
```
1. Назвать порядок коротко и одинаково
2. Показать комбинацию целиком 1 раз
3. Разобрать по фразам
4. Дать опоры: слова / карточки / номера фраз
5. Повторить в том же порядке на этом и следующем занятии
```

**Примеры опорных фраз:**
- «Сначала шагаем красиво, потом скачем боком, потом подскакиваем, потом кружимся.»  
- «Фраза 1 — переменный. Фраза 2 — галоп. Фраза 3 — подскоки.»

**Чего нельзя на этапе заучивания:**
- менять порядок «для интереса»;  
- добавлять новый элемент в середину готовой цепочки;  
- исправлять сразу и порядок, и руки, и выражение лица.

**Критерий успеха:**  
большинство детей начинает следующее движение по музыке почти без голосовой подсказки.

**Картинка:** 4 карточки-фразы в ряд со стрелками; замок «порядок зафиксирован»

### Слайд 7. Синхронность и взаимодействие — подробно
**Заголовок:** Синхронность — это общий слух, а не строевая подготовка

**Развёрнутое определение на слайде:**  
Синхронность у дошкольников — умение начинать вместе, держать фразу, сохранять интервал и не разрушать рисунок группы.

**Чему именно учить:**
- общий старт и финиш;  
- интервал («окошко»);  
- не обгонять и не толкать;  
- видеть партнёра;  
- ждать своей очереди в диагональном потоке.

**Поэтапная схема:**
```
Хлопки в пульс
→ знакомое движение «все как один»
→ пары на месте
→ перемещение пары
→ диагональ потоком
```

**Речевые формулы:**
- «Смотрим не только на свои ноги — ещё на соседа.»  
- «Если поторопился — дождись следующей фразы.»  
- «В паре руки мягкие.»

**Важная мысль:**  
окрик «ровняйсь!» почти не учит музыкальной синхронности. Учит повтор под ясную фразу и спокойная коррекция.

**Картинка:** круг с равными дугами между детьми + пара в центре

### Слайд 8. Музыкальные фразы — подробно
**Заголовок:** Фраза — каркас всего танца

**Что дать студентам понять:**  
Пока ребёнок не слышит конец фразы, комбинация будет рассыпаться: кто-то сменит движение раньше, кто-то позже.

**Базовая схема комбинации по фразам:**
```
1–8    переменный шаг
9–16   боковой галоп
17–24  подскоки
25–32  кружение в парах
33–40  диагональ / выход
финал  остановка + поклон
```

**Как учить слышать фразу:**
1. Прослушать и хлопнуть только на конец.  
2. На первую фразу идти, на вторую — стоп.  
3. Два контрастных движения на две фразы.  
4. Собрать 3–4 фразы подряд.

**Крупно:**
```
Стык фраз = место смены движения
```

**Картинка:** цветные прямоугольники 8+8+8+8; на стыках — молния «смена»

---

### Слайд 9. Выразительность и артистизм
**Заголовок:** Краски после чистого навыка

**Схема:**
```
Услышал характер музыки
→ выбрал качество движения
→ показал телом
→ только потом добавил мимику/поклон
```

**Примеры характеров:** легко · гордо · шутливо · плавно · дружно  

**Развёрнутый акцент:**  
По Ветлугиной выразительность растёт из восприятия музыки. Если галоп ещё тяжёлый и опасный, рано требовать «улыбку для сцены». Сначала устойчивость и лёгкость, затем краски.

**Приём на занятии:**  
один и тот же переменный шаг показать в двух характерах — «важно» и «озорно» — и спросить детей: какой подходит к музыке?

**Картинка:** одна фигура в двух настроениях

---

### Слайд 10. Практика: переменный шаг — с описанием техники
**Заголовок:** Переменный шаг

**Зачем нужен:**  
это «взрослый» шаг старшей группы для переходов, круга и диагонали; без него комбинации выглядят беднее и менее ритмично.

**Как ставить (пошагово):**
1. Показ лицом к детям в медленном темпе.  
2. Проход по прямой линии без музыки.  
3. То же под музыку умеренного темпа.  
4. По кругу.  
5. Связка: 8 переменный + 8 шаг с носка.  
6. Добавить руки на пояс / лёгкое движение рук.

**На что смотреть:**
- осанка;  
- не превращается ли шаг в бег;  
- не сбивается ли на приставке;  
- не смотрят ли в пол.

**Команды:**
- «Спинка высокая.»  
- «Не спешим, слышим музыку.»  
- «Шаг чёткий и мягкий.»

**Методический запрет:**  
не выводить переменный шаг сразу на диагональ всей группой.

**Картинка:** схема следов переменного шага + стрелка «сначала линия, потом круг»

---

### Слайд 11. Практика: боковой галоп — сложный блок
**Заголовок:** Боковой галоп: техника + безопасность

**Почему это сложно:**  
быстрый темп, боковое перемещение, риск столкновений и перевозбуждения.

**Техника коротко:**
- движение боком;  
- лёгкий галоп/приставление;  
- корпус вверх;  
- направление заранее задано.

**Рабочая дозировка на слайде:**
```
8 счётов галоп вправо
→ 8 счётов шаг + дыхание
→ 8 счётов галоп влево
→ 8 счётов шаг
```

**Правила безопасности (красным списком):**
1. Только короткие серии.  
2. Дистанция больше, чем на обычном шаге.  
3. Не давать галоп врассыпную на первом этапе.  
4. После галопа всегда шаг, не прыжки и не кружение.  
5. При потере контроля группы — сразу стоп-сигнал и ходьба.

**Образ:** «Лошадки бегут боком по дорожке» / «Лёгкие ножки»

**Что должен проговорить воспитатель до старта:**  
куда галопируем, сколько примерно счётов, как останавливаемся, как обходим пространство.

**Картинка:** боковые следы + «стоп» + значок дыхания

---

### Слайд 12. Практика: подскоки
**Заголовок:** Подскоки в музыкальной фразе

**Отличие от галопа:**  
подскоки чаще идут с продвижением вперёд/по кругу; важны лёгкость и мягкое приземление.

**Схема:**
```
Подскоки на месте
→ подскоки по кругу
→ 8 подскоков + 8 шага с носка
→ дыхание
```

**Ошибки и коррекция:**
- тяжёлое приземление → «пружинка в коленках»;  
- слишком высоко → «не высоко, а легко»;  
- ускорение сверх музыки → вернуться к хлопкам пульса;  
- хаос рук → сначала руки на пояс.

**Дозировка:** 1–2 короткие серии, не устраивать «кто дольше».

**Картинка:** лёгкая дуга подскока и мягкое приземление

---

### Слайд 13. Кружение в парах — самый рискованный блок
**Заголовок:** Кружение в парах: сначала договор, потом движение

**Почему это самый сложный практический кусок:**  
здесь сразу встречаются взаимодействие, равновесие, эмоции и риск травмы/головокружения.

**Чек-лист ДО старта (вынести крупно):**
```
1. Кто с кем
2. Какой захват рук
3. Сколько счётов кружимся
4. Какой сигнал стоп
5. Что делаем после остановки
```

**Порядок обучения:**
1. Стоя в паре — только мягко покачать руки под музыку.  
2. Малый круг шагом.  
3. Короткое кружение на 4–8 счётов.  
4. Остановка, взгляд на ориентир, шаг на месте.  
5. Лишь затем встраивать во фразу комбинации.

**Жёсткие «нельзя»:**
- сильная раскрутка;  
- кружение до головокружения;  
- выкручивание кистей;  
- сразу всем парам в тесном зале;  
- переход из галопа в кружение без шаговой паузы.

**Если зал тесный:** пары кружатся волнами — одна часть группы двигается, другая наблюдает/хлопает пульс.

**Образ:** «Два листочка закружились и тихо легли.»

**Картинка:** пара детей + список правил в рамке «ДО СТАРТА» + знак стоп

---

### Слайд 14. Диагональ — организация потока
**Заголовок:** Диагональ: пространство важнее красоты шага

**Схема зала:**
```
У1 -------------------- У2
  \                    /
   \      ЦЕНТР      /
    \                /
У4 -------------------- У3

Диагональ: У1 → У3
Возврат: по периметру шагом
```

**Порядок освоения:**
1. Показать углы-ориентиры.  
2. Пройти диагональ шагом с носка по одному.  
3. Переменный шаг по диагонали.  
4. Короткий галоп или подскоки — только потоком по 2–3 человека.  
5. Не скапливаться в углу финиша.

**Главное организационное правило крупно:**
```
Следующая пара (или тройка) выходит только тогда,
когда предыдущая прошла середину диагонали
```

**Что проговорить детям:**
- «Глаза на угол.»  
- «Держим свою дорожку.»  
- «Дошли — идём шагом вдоль стены, не толпимся.»

**Почему это сложно:**  
дети любят выбежать сразу всей толпой. Без правила потока диагональ превращается в столкновение.

**Картинка:** конусы в углах, стрелка диагонали, пунктир «зона ожидания»

---

### Слайд 15. Сборка комбинации — подробно
**Заголовок:** Как собрать несколько элементов в один танец

**Пример комбинации на слайде:**
```
Фраза 1 (1–8):   переменный шаг по кругу
Фраза 2 (9–16):  боковой галоп
Фраза 3 (17–24): подскоки
Фраза 4 (25–32): кружение в парах
Фраза 5 (33–40): диагональ волной
Финал:          общая остановка и поклон
```

**Алгоритм разучивания (не пропускать шаги):**
```
1. Назвать последовательность одинаковыми словами
2. Прогон каждой фразы отдельно
3. Склеить 1–2
4. Склеить 3–4
5. Собрать целиком 1–2 раза
6. Добавить выразительность окончания
```

**Порядок коррекции ошибок — это важно:**
1. Сначала порядок элементов.  
2. Потом синхронность старта/финиша.  
3. И только потом руки, лицо, «красота».

**Типичный провал студента-ведущего:**  
останавливает весь танец из-за одной неточной руки, и группа теряет последовательность.  
**Лучше:** короткая подсказка голосом/жестом и довести фразу до конца, затем точечный разбор.

**Картинка:** 5 цветных блоков + финишный флаг; стрелки «склейки»

### Слайд 16. Мини-разбор рисков занятия
**Заголовок:** Где воспитатель чаще всего теряет контроль

**Таблица рисков:**

| Место | Риск | Что сделать заранее |
|---|---|---|
| Боковой галоп | столкновения, возбуждение | короткие серии, шаг после |
| Подскоки | жёсткое приземление | пружина, дозировка |
| Кружение в парах | головокружение, травма рук | договор до старта, коротко |
| Диагональ | выбег толпой | правило середины |
| Комбинация | потеря порядка | одинаковые названия фраз |

**Крупный вывод:**  
самые красивые места танца — они же самые аварийные. Сложность обязательно пакуется в правила.

**Картинка:** светофор — жёлтый на галопе/парах/диагонали

### Слайд 17. Чек-лист воспитателя на занятии
**Заголовок:** Перед тем как включить музыку

**Чек-лист:**
1. Названа последовательность.  
2. Понятен рисунок зала.  
3. Проговорены стоп-сигнал и дистанция.  
4. Быстрые элементы нарезаны короткими сериями.  
5. После галопа/подскоков есть шаг.  
6. Пары назначены до кружения.  
7. Диагональ идёт потоком.  
8. Корректируем по очереди: порядок → ансамбль → краски.

**Картинка:** список с галочками

### Слайд 18. Итог + мини-задание
**Заголовок:** Итог занятия 10

**Крупно:**
```
Сложность без хаоса.
Ансамбль без окрика.
Выразительность без напряжения.
```

**Что уносит студент:**
- лестницу усложнения координации;  
- алгоритм памяти последовательности;  
- правила галопа, пар и диагонали;  
- сборку комбинации по фразам.

**Мини-задание группе:**
```
Соберите 4 фразы и проговорите правила безопасности:
1) переменный шаг
2) боковой галоп
3) подскоки
4) остановка / поклон
```

**Картинка:** общий поклон детей  
**Футер:** Буренина; «Са-Фи-Дансе»; Ветлугина
