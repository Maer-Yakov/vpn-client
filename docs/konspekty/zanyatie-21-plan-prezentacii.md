# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Музыкальные игры и песни с движением
**Тема:** значение, различия трёх форм, подбор материала, этапы подготовки и проведения  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Музыкальные игры и песни с движением  
**Подзаголовок:** Не хаос под трек — слух, образ, жест и мягкий голос  

**На слайде:**
- пение + движение + правило  
- итог: услышать → показать → повторить → стоп  

**Картинка:** воспитатель в кругу с детьми ведёт игру-песню (мягкий жест + пение) в музыкальном зале; иконки слух / жест / роль / стоп.  
**Схема-формула:**
```
услышать → показать → повторить движением → не кричать → стоп
```
**Мелко:** Ветлугина · Радынова · Буренина · «Ладушки» · «Музыка и движение»

---

### Слайд 2. Зачем эта тема
**Заголовок:** Мост между «просто поём» и «просто двигаемся»

**Таблица:**

| Без игры-песни | С игрой / песней с движением |
|---|---|
| пение «сидя и скучно» | образ и действие |
| движение без слуха | ответ на музыку |
| длинные объяснения | короткий показ |
| риск крика и беготни | правило + пауза |

**Картинка:** две двери — «Хаос под трек» (закрыта) и «Игра со слуховой задачей» (открыта).  
**Крупно:** если убрать музыку и смысл не меняется — это уже не музыкальная игра.

### Слайд 4. Значение
**Заголовок:** Что развивают музыкальные игры и песни с движением

**Таблица:**

| Сфера | Что развивается |
|---|---|
| Слух | начало / конец, темп, характер |
| Голос | подпевание, мягкий эталон в движении |
| Ритм | шаг, хлопок, жест «в музыку» |
| Координация | слово + движение + слушание |
| Внимание | правило, сигнал, роль |
| Общение | круг, пара, «вместе» |

**Схема:**
```
слух + голос + жест + правило → радостное организованное действие
```
**Картинка:** шесть сфер вокруг детей в кругу.  
**Вывод:** это не «развлечение на остаток занятия».

---

### Слайд 5. Три формы
**Заголовок:** Музыкальная игра · игра-песня · песня с движением

**Таблица:**

| Форма | Ведущая опора | Можно убрать пение? |
|---|---|---|
| Музыкальная игра | правило + сигнал | часто да |
| Игра-песня | текст = сценарий | почти нет |
| Песня с движением | фраза + жест | частично |

**Схема:**
```
игра учит слышать
→ игра-песня — жить в образе текста
→ песня с движением — соединять фразу и жест
```
**Картинка:** три карточки / три станции в зале с разными опорами.  
**Крупно:** одна семья — разные ведущие задачи.

---

### Слайд 6. Можно / нельзя
**Заголовок:** Светофор безопасной игры

**Таблица:**

| Можно | Нельзя |
|---|---|
| мягкий голос + ясный жест | крик поверх музыки |
| короткое правило | длинная лекция до игры |
| повтор и пауза | бег без стопа |
| посильное движение | сложная «эстрада» |
| смена роли дозированно | толчки в кругу |

**Картинка:** светофор — зелёный «мягко», жёлтый «пауза», красный «крик + беготня ✕».  
**Фраза:** стоп — тоже методика.

---

### Слайд 7. Подбор материала
**Заголовок:** Беру / не беру

**Критерии:**

| Критерий | Вопрос |
|---|---|
| Образ | понятен детям? |
| Фразы | короткие, с повтором? |
| Движение | посильно возрасту? |
| Задача | есть слуховая / певческая цель? |
| Безопасность | есть место для стопа? |

**Беру / не беру:**

| Беру ✓ | Не беру ✕ |
|---|---|
| ясный образ и повтор | длинный взрослый текст |
| 2–4 простых движения | сложная хореография |
| мягкий эталон педагога | «просто весёлый трек» |

**Картинка:** полка «беру» / корзина «не беру».  
**Вывод:** материал — педагогическое решение.

---

### Слайд 8. Этапы подготовки и проведения
**Заголовок:** Как готовить и как вести

**Подготовка:**

| Шаг | Суть |
|---|---|
| Цель | слух / речь / ритм / общение |
| Форма | игра / игра-песня / песня с движением |
| Возраст | упростить или усложнить |
| Пространство | круг, линии, «домики» |
| Показ | голос + жест |
| Дозировка | повторы и пауза |

**Проведение (дорожка):**
```
интерес → показ → правило → проба → вместе → характер → вариация → стоп
```
**Картинка:** дорожка из 8 станций в музыкальном зале.  
**Важно:** 7–12 минут с паузами, не марафон.

---

### Слайд 9. Упражнения-настройки
**Заголовок:** 20–40 секунд — одна задача

**Таблица:**

| Упражнение | Задача |
|---|---|
| Эхо-жест | повтор фразы + жеста |
| Стоп-игра | реакция на паузу / сигнал |
| Тихо — бодро | характер |
| Кто ведущий | внимание к показу |
| Голос не кричит | мягкий эталон |

**Схема:**
```
одна задача → короткий повтор → стоп
```
**Картинка:** пять карточек упражнений.  
**Правило:** настройка, не цирк.

---

### Слайд 10. Банк материала
**Заголовок:** Игры-песни и песни с движением

**Таблица:**

| Тип | Примеры / логика |
|---|---|
| Игры-песни | «Каравай»; «Заинька»; «Где ты, зайка?»; «Мы на луг ходили» |
| Песни с движением | жесты про дождик, солнышко, птичек, животных |
| Музыкальные игры | тихо/громко; дождь/солнышко; характер → образ |

**Мини-схема возраста:**
```
1,5–3 — короткий показ взрослого
3–5 — роль и 2–3 жеста
5–7 — структура, круг/пара, смена ролей
```
**Картинка:** картотека / полка с тремя полками форм.  
**Вывод:** конкретный репертуар — из программы группы.

### Слайд 11. Практика и чек-лист
**Заголовок:** Мини-фрагмент 90–120 секунд

**Структура:**
```
назвать форму
→ упражнение / образ 15–20 сек
→ показ 1–2 фраз + движение
→ повтор
→ можно / нельзя
→ мягкий стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Форма названа верно? | |
| Голос мягкий? | |
| Движение к фразе / правилу? | |
| Есть повтор и пауза? | |
| Пространство безопасно? | |
| Понятен возраст? | |

**Картинка:** студенты проводят мини-показ в кругу.  
**Фраза:** хороший фрагмент короткий, ясный и без крика.

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула игры и песни с движением

**Крупная схема:**
```
Услышать
+ показать мягко
+ повторить движением
+ не кричать
+ вовремя остановиться
= правильная музыкальная игра
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | значение · 3 формы · подбор · этапы · упражнения |
| 2. Разбор 2 материалов | игра-песня + песня с движением |
| 3. Мини-эссе | почему нельзя «просто побегать под трек» |
| 4. Мини-сценарий | настройка + показ + повтор + стоп |
| 5. Картотека | 2+2+2 материала с целью и риском |

**Картинка:** круг детей с воспитателем; мягкий жест; платочек / стоп.  
**Футер:** Ветлугина · Радынова · Буренина · «Ладушки» · «Музыка и движение»  
**Финальная фраза:** игра начинается с вашего спокойного показа — голосом и телом.
