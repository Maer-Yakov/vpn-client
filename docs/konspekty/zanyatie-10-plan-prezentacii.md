# План презентации (16 слайдов)
## Занятие 10. Танцевальное развитие детей 5–6 лет
**Аудитория:** студенты-воспитатели · **время показа:** 15–18 минут

---

### Слайд 1. Титульный
**Заголовок:** Танцевальное развитие детей 5–6 лет  
**Подзаголовок:** Занятие № 10 · для студентов-воспитателей  
**Картинка:** старшие дошкольники в паре / проход по диагонали  
**Мелко:** Буренина; Фирилева, Сайкина «Са-Фи-Дансе»; Ветлугина

---

### Слайд 2. Чем 5–6 лет отличаются от 4–5
**Заголовок:** Старшая группа танцует «умнее и дружнее»  
**Схема сравнения:**
```
4–5 лет                      5–6 лет
элемент + короткая связка →  последовательность
круг / простая комбинация →  ансамбль, пары, диагональ
```
**Картинка:** два уровня сложности — короткая цепочка и длиннее  
**Тезис:** усложнение ≠ перегруз

---

### Слайд 3. Цель для воспитателя
**Заголовок:** Чему учимся мы  
**Схема-стрелка:**
```
Координация → Память порядка → Синхронность → Фраза → Выразительность
```
**Список:**
- усложнять координацию дозированно  
- учить запоминать последовательность  
- собирать синхронную группу  
- работать фразами  
- развивать артистизм без штампов  

---

### Слайд 4. Карта темы
**Заголовок:** Содержание занятия  
**Схема-солнце:**
1. Усложнение координации  
2. Запоминание последовательности  
3. Синхронность и взаимодействие  
4. Музыкальные фразы  
5. Выразительность и артистизм  

**Практика вокруг:** переменный шаг · боковой галоп · подскоки · кружение в парах · диагональ · комбинация  
**Картинка:** иконки элементов вокруг центра «5–6 лет»

---

### Слайд 5. Усложнение координации
**Заголовок:** Одно новое условие за попытку  
**Схема ступеней:**
```
Знакомый элемент в новом пространстве
→ новый элемент
→ связка двух
→ руки / пара
→ полная комбинация
```
**Крупно:**
```
Одно новое условие за попытку
```
**Картинка:** лестница сложности  
**Ошибка:** сразу шаг + руки + диагональ + синхронный старт

---

### Слайд 6. Запоминание последовательности
**Заголовок:** Что за чем — и всегда в том же порядке  
**Схема:**
```
Показать целиком → разобрать по фразам → закрепить названия → повторить
```
**Приёмы:**
- короткие названия порядка  
- карточки-схемы  
- 1-я / 2-я / 3-я фраза  
- одинаковая точка старта  

**Картинка:** карточки 1–2–3–4 в ряд  
**Крупно:** на этапе заучивания порядок не меняем «для разнообразия»

---

### Слайд 7. Синхронность и взаимодействие
**Заголовок:** Не «ровняйсь!», а общий слух  
**Схема:**
```
Общий пульс → все как один → пары → диагональ потоком
```
**Правила:**
- смотри на соседа  
- не обгоняй хаосом  
- в паре руки мягкие  
- начинаем и заканчиваем вместе  

**Картинка:** круг/пары с равными интервалами  
**Тезис:** синхронность растёт через музыку и повтор

---

### Слайд 8. Работа с музыкальными фразами
**Заголовок:** Стык фраз = смена движения  
**Схема:**
```
1–8 переменный шаг
9–16 боковой галоп
17–24 подскоки
25–32 кружение / диагональ
```
**Приёмы:** хлопки на конец фразы · контраст частей · общий финал  
**Картинка:** цветные блоки-фразы  
**Акцент:** признак музыкальности — смена по форме, а не только копирование педагога

---

### Слайд 9. Выразительность и артистизм
**Заголовок:** Сначала навык, потом краски  
**Схема:**
```
Услышал характер → выбрал качество движения → показал телом
```
**Примеры:** легко · гордо · шутливо · плавно · дружно  
**Крупно:**
```
Артистизм дошкольника —
не штамп улыбки, а характер музыки в теле
```
**Картинка:** одно движение в двух характерах  
**По Ветлугиной:** выразительность из восприятия музыки

---

### Слайд 10. Практика: переменный шаг
**Заголовок:** Переменный шаг  
**Схема хода:**
```
Показ → линия → круг → 8+8 со шагом с носка → руки
```
**Команды:** «Спинка высокая» · «Не спешим» · «Шаг чёткий, мягкий»  
**Картинка:** схема следов переменного шага  
**Важно:** не начинать сразу с диагонали

---

### Слайд 11. Практика: боковой галоп
**Заголовок:** Боковой галоп — легко и коротко  
**Схема:**
```
Вправо 8 → шаг 8 → влево 8 → шаг 8
```
**Красные правила:**
- короткие серии  
- большая дистанция  
- после галопа — шаг и дыхание  
- не врассыпную на первом этапе  

**Картинка:** боковое перемещение «лошадки»  
**Образ:** лёгкие ножки, весёлая музыка

---

### Слайд 12. Практика: подскоки
**Заголовок:** Подскоки в фразе  
**Схема:**
```
8 подскоков → 8 шага с носка → дыхание
```
**Ошибки:** тяжёлое приземление · лишняя высота · ускорение сверх музыки  
**Картинка:** лёгкая дуга подскока  
**Команда:** «Легко, как мячики»

---

### Слайд 13. Практика: кружение в парах
**Заголовок:** Пара — это ответственность  
**Схема до старта:**
```
Кто с кем → какой захват → сколько счётов → сигнал стоп
```
**Ход:** качнуть руки → малый круг шагом → короткое кружение → остановка  
**Красный блок:**
- без сильной раскрутки  
- коротко  
- при головокружении — стоп  
- в тесном зале — по очереди  

**Картинка:** два ребёнка за руки + значок «стоп»  
**Образ:** «Два листочка закружились и тихо остановились»

---

### Слайд 14. Практика: движения по диагонали
**Заголовок:** Диагональ потоком  
**Схема зала:**
```
У1 --------------- У2
 \                 /
  \    ЦЕНТР     /
   \           /
У4 --------------- У3
диагональ У1 → У3
```
**Правило крупно:**
```
Следующая пара выходит,
когда предыдущая прошла середину
```
**Картинка:** конусы в углах, стрелка диагонали  
**Проходы:** шаг с носка → переменный → короткий галоп/подскок

---

### Слайд 15. Комбинация из нескольких элементов
**Заголовок:** Собираем последовательность  
**Схема комбинации:**
```
1–8   переменный шаг
9–16  боковой галоп
17–24 подскоки
25–32 кружение в парах
33–40 диагональ волной
финал поклон
```
**Алгоритм:**
```
Назвать порядок → по фразам → склеить → 1–2 раза целиком → краски финала
```
**Картинка:** 5 цветных блоков + финиш  
**Порядок коррекции:** сначала порядок → потом синхронность → потом выразительность

---

### Слайд 16. Итог и чек-лист
**Заголовок:** Что должен уметь воспитатель  
**Чек-лист:**
1. Дозировать усложнение координации  
2. Дать запоминаемую последовательность  
3. Собрать синхронный старт и финиш  
4. Менять элементы по фразам  
5. Безопасно провести галоп, подскоки, пары, диагональ  
6. Добавить выразительность после чистого навыка  

**Крупно:**
```
Сложность без хаоса.
Выразительность без напряжения.
```
**Мини-задание:**
```
Соберите 4 фразы:
переменный шаг → галоп → подскоки → остановка
```
**Картинка:** галочка / общий поклон группы  
**Футер:** Буренина; «Са-Фи-Дансе»; Ветлугина
