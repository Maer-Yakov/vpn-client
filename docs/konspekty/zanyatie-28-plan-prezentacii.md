# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Развитие вокально-слуховой координации у детей дошкольного возраста
**Тема:** сначала слышим — потом поём · короткий эталон · мягкое эхо  
**Для студентов колледжа · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Вокально-слуховая координация дошкольников  
**Подзаголовок:** Услышать звук — мягко воспроизвести голосом  

**На слайде:**
- дошкольный возраст  
- итог: слушать → жест / эхо → короткая мелодия  

**Картинка:** педагог поёт короткий эталон; дети слушают с поднятой рукой «выше/ниже»; иконки ухо / жест / голос.  
**Схема-формула:**
```
слушать → показать / повторить коротко → мягкий голос → стоп
```
**Мелко:** Ветлугина · Радынова · Метлов · «Ладушки» · Орлова / Бекина

---

### Слайд 2. Что это и зачем
**Заголовок:** Понятие вокально-слуховой координации

**Таблица:**

| Понятие | Определение |
|---|---|
| Вокально-слуховая координация | слышать звук и согласовать с ним голос |
| Слуховое внимание | сосредоточиться на эталоне до ответа |
| Воспроизведение | мягкое повторение услышанного |
| Чистота интонации | попадание без форса и крика |

**Сравнение:**

| Без координации | С координацией |
|---|---|
| кричит «рядом» | слушает и подстраивается |
| сразу подпевает | есть этап показа и эха |
| страх ошибки | повтор как игра |

**Картинка:** мост «услышал → спел».  
**Крупно:** сначала уши — потом голос.

### Слайд 4. Возраст и этапы
**Заголовок:** Как растёт навык

**Таблица возраста:**

| Возраст | Реалистично | Акцент |
|---|---|---|
| 1,5–3 | жест, эхо 1–2 звука | контакт, мягкий показ |
| 3–5 | фразы, сравнение звуков | игра, повтор |
| 5–7 | чуть длиннее, короткая a cappella | самостоятельность дозированно |

**Этапы:**
```
слушать → жест → эхо → с песней → короткая проверка без инструмента
```

**Картинка:** пять ступенек навыка.  
**Правило:** не перепрыгивать слушание.

---

### Слайд 5. Типичные трудности
**Заголовок:** Что мешает и что помогает

**Таблица:**

| Трудность | Помогает |
|---|---|
| «Говорит» вместо пения | мягкий показ, жест вверх |
| Поёт ниже / выше | повтор эталона, короче фраза |
| Кричит | «тише и яснее» |
| Стесняется | пара с педагогом, жест без голоса |
| Путает высоко/низко | игры сравнения |
| Теряется без инструмента | короткие a cappella пробы |

**Не путать:**

| Это | Не это |
|---|---|
| короткая работа слуха | длинный хоровой экзамен |
| мягкое попадание | громкость = успех |
| упрощение фразы | стыд за ошибку |

**Картинка:** карточки трудностей и «мягких» ответов педагога.

---

### Слайд 6. «Высоко — низко»
**Заголовок:** Упражнение на слуховое внимание

**Таблица шагов:**

| Шаг | Действие |
|---|---|
| 1 | эталон: высокий или низкий звук |
| 2 | рука вверх / вниз |
| 3 | шёпот: «высоко» / «низко» |
| 4 | по желанию — мягкий один звук |

**Усложнение:** вверх–вниз · средний звук · глаза закрыты + жест.

**Схема:**
```
тишина → звук → жест → (голос)
```
**Картинка:** дети показывают высоту рукой; педагог у инструмента.  
**Инструкция:** «Сначала только уши. Потом рука.»

---

### Слайд 7. «Одинаково или по-разному»
**Заголовок:** Сравнение звуков и коротких фраз

**Таблица шагов:**

| Шаг | Действие |
|---|---|
| 1 | пара звуков / коротких фраз |
| 2 | карточки «=» / «≠» или хлопок / тишина |
| 3 | слово: «одинаково» / «по-разному» |
| 4 | при «одинаково» — мягкое эхо |

**Картинка:** две карточки сравнения; дети слушают до ответа.  
**Фраза:** голосом — только по сигналу «эхо».  
**Вывод:** сравнение тренирует внимание раньше длинного пения.

---

### Слайд 8. Чистота интонации
**Заголовок:** Эталон → жест → эхо

**Таблица:**

| Этап | Содержание |
|---|---|
| Эталон | 2–3 звука мягко |
| Жест | направление мелодии рукой |
| Эхо вместе | тихо всей группой |
| Подгруппы | по очереди |
| По желанию | короткая фраза одному |
| Стоп | похвала за мягкость |

**Схема:**
```
эталон → жест → эхо → (упростить) → стоп
```

**Критерии успеха:** направление мелодии · мягкий голос · повтор после слушания · без стыда.

**Картинка:** педагог рисует мелодию рукой; дети повторяют тихо.

---

### Слайд 9. Двигательная пауза
**Заголовок:** Хлопки и голосовые сигналы

**Таблица сигналов:**

| Сигнал педагога | Ответ детей |
|---|---|
| 1 хлопок | 1 хлопок |
| 2 хлопка | 2 хлопка |
| высокий «ау» | тихий высокий / рука вверх |
| низкий «ум» | тихий низкий / рука вниз |
| жест «стоп» | тишина |

**Светофор звука:** зелёный — эхо · жёлтый — только жест · красный — тишина.

**Картинка:** круг детей; педагог даёт сигнал; без бега и крика.  
**Правило:** 1–2 минуты · одна инструкция · стоп обязателен.

---

### Слайд 10. С инструментом и a cappella
**Заголовок:** Опора и короткая проверка

**Таблица:**

| Форма | Зачем | Дозировка |
|---|---|---|
| С инструментом | опора высоты | короткая фраза |
| A cappella | проверка слуха | 1–2 фразы после опоры |
| Снова с инструментом | возврат уверенности | финал без экзамена |

**Порядок:**
```
слушать с инструментом → петь с опорой → 1 фраза без → вернуть опору → стоп
```

| Возраст | A cappella |
|---|---|
| 1,5–3 | почти нет |
| 3–5 | 1 короткая фраза |
| 5–7 | 1–2 фразы |

**Картинка:** две зоны — «с опорой» / «коротко без».  
**Крупно:** a cappella — проверка, не испытание.

---

### Слайд 11. Мини-комплекс в группах
**Заголовок:** Слушание · подражание · воспроизведение

**Структура бланка:**
```
возраст и цель
→ 1. слушание (30–40 сек)
→ 2. подражание: жест / эхо (30–40 сек)
→ 3. короткая мелодия 2–4 звука (40–60 сек)
→ стоп и поддержка
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Есть слушание до пения? | |
| Есть жест / эхо? | |
| Есть короткая мелодия? | |
| Инструкции доступны? | |
| Форма игровая? | |
| Есть поддержка и стоп? | |

**Картинка:** студенты заполняют бланк; наблюдатели с рубрикой.  
**Фраза:** хороший комплекс слышен: уши → рука/эхо → короткая мелодия.

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула координации

**Крупная схема:**
```
Слушать
+ показать / повторить коротко
+ мягкий голос
+ опора ↔ короткая a cappella
+ поддержка без стыда
= рост вокально-слуховой координации
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица этапов | действие · риск · стоп |
| 2. Картотека | 6 упражнений по блокам |
| 3. Мини-эссе | громкость ≠ чистая интонация |
| 4. Сценарий | 2–3 мин мини-комплекс |
| 5. Сравнение | ситуация → упражнение → почему |

**Картинка:** финальный круг: тихий эталон и мягкое эхо.  
**Футер:** Ветлугина · Радынова · Метлов · «Ладушки» · Орлова / Бекина  
**Финальная фраза:** чистая интонация растёт из тихого слушания.
