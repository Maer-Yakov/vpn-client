# План презентации (18 слайдов) — РАЗВЁРНУТЫЙ
## Занятие 12. Основы классического и народного танца для дошкольников
**Аудитория:** студенты-воспитатели · **время показа:** 18–22 минуты  
**В каждом слайде:** что писать крупно + какая картинка/схема нужна

---

### Слайд 1. Титульный
**Заголовок:** Основы классического и народного танца для дошкольников  
**Подзаголовок:** Занятие № 12 · для студентов-воспитателей  

**На слайде:**
- не профессиональная хореография  
- а детская танцевальная подготовка  

**Картинка:** коллаж из двух половин — девочка с мягкой «классической» осанкой и дети в русском хороводе с платочком.  
**Схема-логотип в углу:** две ветви от одного ствола — «Классика» и «Народный танец».  
**Мелко:** Устинова «Русские танцы» · Буренина · Ветлугина

---

### Слайд 2. Главная граница темы
**Заголовок:** Не уменьшенный балет и не взрослый ансамбль

**Схема сравнения на весь слайд:**

```
 ПРОФЕССИОНАЛЬНАЯ ХОРЕОГРАФИЯ     │  ТАНЦЕВАЛЬНАЯ ПОДГОТОВКА В ДОО
──────────────────────────────────┼────────────────────────────────
 техника и сцена                  │  развитие и здоровье
 ежедневный экзерсис              │  короткие доступные серии
 канон и отбор                    │  адаптация для всей группы
 трюк и амплитуда                 │  игра, образ, повтор
```

**Крупно внизу:**  
`Доступно? Безопасно? Музыкально? Развивает?`

**Картинка:** слева станок/пуанты (зачёркнуты мягко как «не цель ДОО»), справа дети в кругу.  
**Иконки-вопросы** по четырём критериям выбора элемента.

---

### Слайд 3. Цель для воспитателя
**Заголовок:** Чему учимся на занятии 12

**Схема-стрелка:**
```
Отличить ДОО от профобучения
→ Поставить корпус доступно
→ Дать мягкие положения рук и ног
→ Отобрать народно-игровые элементы
→ Собрать простой русский хоровод
```

**Картинка:** портфель воспитателя + два значка «классика» и «народный».  
**Мини-схема:** фильтр «эффект утренника» → проходит только через «безопасность».

---

### Слайд 4. Карта темы
**Заголовок:** Классика + народность в дошкольной мере

**Схема-солнце / mind map:**

**Центр:** «Дошкольный танец»

**Левый лепесток — классика:**
- постановка корпуса  
- положения рук и ног  
- поклон / реверанс  

**Правый лепесток — народный танец:**
- притопы, хлопушки  
- ковырялочка  
- хоровод  
- безопасные заменители трюков  

**Картинка:** русский платочек и мягкая «балетная» рука как символы двух источников.  
**Схема внизу:** красный крест на «форсаж выворотности / глубокие присядки».

---

### Слайд 5. Отличие подготовки от профобучения — подробно
**Заголовок:** Подмена целей — главная методическая ошибка

**Схема «две цели»:**
```
Цель профобучения          Цель ДОО
сценическое мастерство  →  общее развитие ребёнка
```

**Развёрнутые тезисы:**
1. В ДОО нет отбора «по данным».  
2. Нет ежедневного станка как нормы.  
3. Нет боли как критерия «работы».  
4. Есть место каждому ребёнку группы.  
5. Номер утренника не важнее здоровья.

**Картинка-комикс из 2 кадров:**  
1) педагог тянет ногу ребёнка через боль — зачёркнуто;  
2) педагог показывает мягкую позу и улыбается — галочка.

**Схема-фильтр:**
```
Элемент красив?
→ доступен всем?
→ безопасен?
→ музыкален?
→ развивает?
→ ДА: берём / НЕТ: упрощаем или исключаем
```

### Слайд 6. Классическая постановка корпуса — со схемой
**Заголовок:** Классика для дошкольника начинается с осанки

**Схема тела (обязательно нарисовать):**
```
        ●  макушка вверх
        |
     плечи вниз и раскрыты
        |
     спина тянется вверх
   (без провала в пояснице)
        |
     живот мягко подобран
        |
     вес на двух ногах
```

**Образы:** «Бутон на высокой ножке» · «Гордый принц / принцесса»

**Как учить:** короткая фиксация 3–5 сек → перенос в шаг → перенос в поклон.

**Картинка:** ребёнок в спокойной красивой стойке; стрелки коррекции «плечи вниз / макушка вверх».  
**Антипример мелкой врезкой:** сутулая стойка с красным крестом.

---

### Слайд 7. Положения рук и ног — схема позиций
**Заголовок:** Адаптированный словарь рук и ног

**Схема ног (ряд пиктограмм):**
```
[ноги вместе]   [носки чуть врозь]   [шаг в сторону и сбор]
   базовая           мягко              без форсажа
```

**Схема рук (ряд пиктограмм):**
```
вниз → на пояс/юбочку → «корзинка» → в стороны округло → вверх мягко
```

**Крупные правила:**
- руки округлые;  
- плечи не поднимать;  
- кисти живые, но не ломаются;  
- выворотность не форсировать.

**Картинка:** 5 карточек положений рук как «веер».  
**Схема-запрет:** балетная первая позиция с надписью «не любой ценой».

---

### Слайд 8. Поклоны и реверансы — пошаговая схема
**Заголовок:** Красивое приветствие и красивый финал

**Две колонки со схемами:**

**Поклон**
```
осанка вверх
→ руки спокойно
→ лёгкий наклон
→ возврат
```

**Реверанс (адаптировано)**
```
осанка вверх
→ нога мягко назад/в сторону
→ лёгкое приседание
→ наклон головы
→ подъём
```

**Ошибки на схеме с крестами:** резкий глубокий наклон; колени внутрь; сутулость; спешка.

**Картинка:** мальчик и девочка в момент поклона/реверанса на празднике.  
**Мини-схема применения:** выход шагом → поклон = начало; конец танца → поклон = финал.

---

### Слайд 9. Народно-игровые и народно-сценические движения
**Заголовок:** Что берём в детский сад из народного танца

**Схема двух корзин:**

```
   ИГРОВЫЕ (приоритет)              СЦЕНИЧЕСКИЕ (редко / упрощать)
   ------------------               ------------------------------
   притопы                          трюковые дроби
   хлопки                           сложные хлопушки
   хороводный шаг                   глубокие присядки
   платочек, змейка                 силовые мужские выходы
   простые повороты                 эффект ради эффекта
```

**Критерий выбора — схема-ромб:**
```
Образ понятен? → Можно всем? → Не ломает суставы? → Можно без форсажа?
```

**Картинка:** слева дети с платочками в кругу; справа «взрослый» эффектный трюк в полупрозрачном запрете.

---

### Слайд 10. Русский народный танец как источник репертуара
**Заголовок:** Откуда брать детский материал

**Схема источников:**
```
Русский народный танец
   ├── хороводный слой  → круг, центр-край, змейка, ведущий
   ├── игровой слой     → притопы, хлопки, ковырялочка упрощённо
   └── плясовой слой    → только безопасные короткие элементы
```

**Что особенно хорошо для детей:** хоровод; смена ведущего; змейка; притопы; простые хлопки; игровые связки.

**Картинка:** народный орнамент / хоровод на поляне / платочек.  
**Схема-цитата визуально:** «Не весь словарь Устиновой, а детский отбор».

---

### Слайд 11. Практика: позиции рук и ног
**Заголовок:** Размечаем тело понятно и мягко

**Схема занятия-блока:**
```
Стойка → носки чуть врозь → руки вниз
→ на пояс → корзинка → в стороны → вверх
→ возврат вниз на 4 счёта
```

**Картинка-инфографика:** силуэт ребёнка с пронумерованными положениями 1–5.  
**Схема рядом:** «плечи вниз» как отдельный контрольный пункт с лупой.  
**Команды на плашках:** «Макушка вверх» · «Ручки-обручики» · «Без насилия в носочках»

---

### Слайд 12. Практика: притопы и хлопушки
**Заголовок:** Ритм народа без травмы

**Схема связки:**
```
4 притопа → 4 хлопка → повтор под фразу
```

**Две мини-схемы:**
1. Притоп одной / поочерёдно / с шагом / на сильную долю.  
2. Хлопушки только доступные: ладоши; мягко по бёдрам; без трюков.

**Картинка:** стопы крупно + ладони в хлопке.  
**Красная схема-запрет:** удар «на силу», хлопок по лицу/голове, длинные жёсткие серии.

---

### Слайд 13. Ковырялочка — подробная схема элемента
**Заголовок:** Ковырялочка в дошкольной форме

**Пошаговая схема (обязательно):**
```
1. Опорная нога спокойная
2. Рабочая нога слегка сгибается
3. Носок/пятка «ковыряет» около опорной
4. Корпус не прыгает
5. Смена ноги
```

**Схема ритма:**
```
Правая-правая → Левая-левая → поочерёдно под музыку
```

**Ошибки со схематичными крестами:**
- прыгает всё тело;  
- ломается опорное колено;  
- слишком быстро;  
- работает только одна нога.

**Картинка:** крупный план ног в момент ковырялочки + стрелка «опорная спокойная».  
Если группа слабая — врезка-заменитель: «носок около носка + лёгкий притоп».

---

### Слайд 14. Присядки и трюки — схема решения «можно / нельзя»
**Заголовок:** Эффект утренника не дороже здоровья

**Это один из самых важных слайдов — со схемой принятия решения.**

**Светофор элементов:**
```
🟢 Можно всем:
лёгкая пружинка-полуприсед, игровой низкий шаг, притоп

🟡 Только коротко и единично при готовности:
очень мягкий облегчённый вариант без глубины и боли

🔴 Нельзя в ДОО:
глубокие присядки, силовые трюки, растяжка через боль,
прыжок в жёсткий глубокий присед
```

**Схема замены:**
```
«Хочу присядку для эффекта»
→ Что она даёт ребёнку?
→ Можно ли заменить образом + пружинкой?
→ Если нет безопасной формы — ИСКЛЮЧАЕМ
```

**Картинка:** три карточки светофора; перечёркнутая глубокая присядка; рядом безопасная «пружинка-привет».

---

### Слайд 15. Русский хоровод — схема рисунков
**Заголовок:** Хоровод учит общему дыханию группы

**Схема зала / рисунков:**
```
1) КРУГ
2) К центру ⟷ назад
3) ЗМЕЙКА за ведущим
4) Снова КРУГ
5) ОБЩИЙ ПОКЛОН
```

**Схема комбинации:**
```
Хороводный шаг
→ 4 притопа
→ ковырялочка коротко
→ змейка
→ круг
→ поклон
```

**Картинка:** хоровод за руки; отдельная врезка «змейка» пунктиром по залу.  
**Схема ролей:** ведущий с платочком → смена ведущего.  
**Характер на плашке:** величавый / радостно-спокойный, без суеты.

---

### Слайд 16. Целая логика занятия в одной схеме
**Заголовок:** Как собрать классику и народность в одном фрагменте

**Большая горизонтальная схема:**
```
Осанка и руки/ноги
→ поклон
→ притопы + хлопки
→ ковырялочка
→ хоровод со сменой рисунка
→ финальный поклон
```

**Над схемой два источника:**
`Классика` даёт собранность · `Народный танец` даёт характер  

**Картинка:** лента времени занятия с иконками на каждом шаге.  
**Врезка:** «Если нужно сократить — убираем трюк, не убираем осанку и хоровод».

---

### Слайд 17. Чек-лист и риски
**Заголовок:** Перед тем как ставить «народный» или «классический» номер

**Чек-лист с иконками:**
1. Это подготовка, не профобучение?  
2. Корпус поставлен мягко?  
3. Руки/ноги без форсажа?  
4. Народный элемент игровой и доступный?  
5. Есть безопасный заменитель трюка?  
6. В хороводе понятны рисунок и ведущий?  
7. Финал через поклон, а не через опасный эффект?

**Таблица-схема рисков:**

| Элемент | Риск | Решение |
|---|---|---|
| Выворотность | травма суставов | только мягкая форма |
| Глубокая присядка | колени/спина | исключить / пружинка |
| Трюковые хлопушки | кисти, перевозбуждение | упростить до хлопков |
| Ковырялочка быстро | потеря опоры | замедлить, чистить по одной ноге |
| Хоровод без правил | стягивание круга | интервал + ведущий |

**Картинка:** светофор + аптечка как метафора осторожности педагога.

### Слайд 18. Итог + мини-задание
**Заголовок:** Итог занятия 12

**Крупно:**
```
Классика — осанка и собранность.
Народный танец — характер и общее движение.
Воспитатель выбирает полезное и безопасное,
а не самое эффектное.
```

**Мини-задание со схемой ответа:**
```
Соберите 5 минут:
1) корпус + руки
2) поклон
3) притопы
4) ковырялочка упрощённо
5) круг-хоровод + финальный поклон

И отдельно напишите: какой трюк вы сознательно НЕ берёте и чем заменяете.
```

**Картинка:** финальный поклон детей в хороводе; слева маленькая классическая стойка, справа платочек.  
**Футер:** Устинова; Буренина; Ветлугина
