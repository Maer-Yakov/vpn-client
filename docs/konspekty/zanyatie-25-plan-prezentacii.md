# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Работа над художественным образом песни и воспитание артистизма у дошкольников
**Тема:** понятный образ + мягкая выразительность; без крика и «спектакля любой ценой»  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Художественный образ песни и артистизм  
**Подзаголовок:** Естественная выразительность дошкольника — голос, лицо, один жест  

**На слайде:**
- дошкольный возраст  
- итог: настроение → мягкий голос → лицо → 1 жест → короткая игра  

**Картинка:** педагог мягко поёт с ясным образом; дети отвечают мимикой/жестом; иконки образ / голос / мимика / жест.  
**Схема-формула:**
```
смысл и настроение → мягкий голос → лицо → 1 жест → короткая игра
```
**Мелко:** Ветлугина · Радынова · Метлов · «Ладушки» · театрализация в ДОУ

---

### Слайд 2. Образ или «просто текст»?
**Заголовок:** Чем отличается выразительное пение

**Таблица:**

| Это | Не это |
|---|---|
| мягкая выразительность | крик «для эмоций» |
| 1–2 ясных средства | гора жестов сразу |
| игра и образ | взрослый театр |
| проживание настроения | штампы без понимания |

**Картинка:** две двери — «Плоское пение» и «Песня в образе».  
**Крупно:** артистизм — не громкость и не гримаса.

---

### Слайд 3. Цель для студента
**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Образ и артистизм
→ Компоненты образа
→ Эмоция · мимика · жест · голос
→ Анализ песни
→ Игры на артистизм
→ Микропреподавание
```

**Мини-таблица:**

| Знает | Умеет |
|---|---|
| компоненты образа | заполнить карточку анализа |
| связку средств | показать фразу с 1 жестом |
| банк игр | провести фрагмент 90–120 сек |

**Картинка:** бланк «мини-фрагмент: образ песни».

---

### Слайд 4. Компоненты художественного образа
**Заголовок:** Из чего складывается образ песни

**Таблица:**

| Компонент | Вопрос |
|---|---|
| Герой | кто говорит? |
| Настроение | какое чувство? |
| Музыка | как звучит? |
| Текст | о чём? |
| Голос | как поём? |
| Мимика / жест | что видно? |
| Игровой приём | чем помочь? |

**Схема:**
```
смысл → настроение → музыка → голос → лицо → 1 жест → игра
```
**Картинка:** «солнышко» компонентов вокруг короткой песни.  
**Вывод:** не брать все компоненты сразу.

---

### Слайд 5. По возрасту
**Заголовок:** Какой артистизм посилен

**Таблица:**

| Возраст | Акцент | Форма |
|---|---|---|
| 1,5–3 | настроение + показ педагога | подпевание |
| 3–5 | герой + 1 жест + мимика | короткие игры |
| 5–7 | смена настроений дозированно | мини-роли 20–40 сек |

**Схема:**
```
чем младше — тем яснее одно настроение и короче показ
```
**Картинка:** три возрастные мини-сцены в музыкальном зале.  
**Фраза:** дошкольник — не актёр взрослого театра.

---

### Слайд 6. Эмоция · мимика · жест · голос
**Заголовок:** Связка средств выразительности

**Таблица:**

| Средство | Помогает | Риск |
|---|---|---|
| Эмоция | смысл настроения | наигранность |
| Мимика | видно чувство | гримасы |
| Жест | подпись героя | хаос движений |
| Голос | главный носитель | крик «для эмоций» |

**Схема-формула:**
```
сначала настроение → потом мягкий голос → потом лицо → потом 1 жест
```
**Картинка:** четыре карточки средств; голос выделен как главный.  
**Крупно:** образ не исправляют громкостью.

### Слайд 7. Практическая разминка
**Заголовок:** 1–2 минуты до выразительности

**Таблица:**

| Упражнение | Задача |
|---|---|
| Плечи вниз / кисти | снять зажим |
| Зевота-улыбка | свобода лица |
| Мягкие гласные | артикуляция |
| Эхо настроения | характер без крика |
| Жест-подпись | 1 жест |
| Стоп | мгновенно мягко |

**Схема:**
```
тело → лицо → мягкий звук → настроение → стоп
```
**Картинка:** круг разминки с карточками настроений.  
**Правило:** одна задача · мягко · коротко.

---

### Слайд 8. Анализ образа песни
**Заголовок:** Карточка анализа

**Таблица-карточка:**

| Вопрос | Смотрим |
|---|---|
| О чём / кто герой? | ситуация, роль |
| Настроение | радость / нежность / шутка… |
| Характер музыки | плавно / бодро / ласково |
| Голос | мягко / живее / тише |
| Мимика + 1 жест | опора видимости |
| Игровой приём | карточка / роль / платочек |
| Риск | крик, перегруз, сложность |

**Схема этапов:**
```
вход → слушание → разбор → фраза → средства → прогон → стоп
```
**Картинка:** бланк анализа рядом с текстом песни и карточкой героя.

---

### Слайд 9. Игры и упражнения на артистизм
**Заголовок:** Банк коротких приёмов

**Таблица:**

| Игра | Задача |
|---|---|
| Угадай настроение | слух к характеру |
| Жест-герой | 1 жест на персонажа |
| Эхо в характере | мягкая выразительность |
| Кто поёт? | угадать героя |
| Тихий спектакль | характер, не громкость |
| Передай образ | очередь 20–30 сек |

**Картинка:** карточки игр в круге детей / студентов.  
**Рубрика:** одна задача · мягкий эталон · короткий стоп.

---

### Слайд 10. Можно / нельзя
**Заголовок:** Границы артистизма в ДОУ

**Таблица:**

| Можно ✓ | Нельзя ✕ |
|---|---|
| 1 ясное настроение | крик «для эмоций» |
| 1 жест-подпись | гора жестов сразу |
| мягкий эталон | начинать с костюмов |
| короткий прогон | длинный «спектакль» |
| похвала за ясность | стыд за «неартистов» |

**Картинка:** светофор / карточки можно–нельзя.  
**Фраза:** выразительность без переигрывания.

### Слайд 11. Микропреподавание
**Заголовок:** Фрагмент 90–120 секунд

**Структура:**
```
возраст и цель
→ вход в образ
→ мягкий показ
→ проба (фраза + 1 средство)
→ короткий прогон
→ стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Настроение / герой понятны? | |
| Голос мягкий? | |
| Есть 1 жест / мимика? | |
| Приём помогает, не мешает? | |
| Фрагмент короткий? | |
| Есть стоп? | |

**Картинка:** студенты в группе показывают фрагмент; наблюдатели с бланком.  
**Фраза:** хороший фрагмент ясный, мягкий и короткий.

---

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула работы над образом

**Крупная схема:**
```
Понятное настроение
+ мягкий голос
+ лицо
+ 1 жест
+ короткая игра
= доступный артистизм
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | компоненты · средства · этапы · банк |
| 2. Разбор песни | карточка анализа + 2 упражнения |
| 3. Мини-эссе | почему нельзя криком воспитывать артистизм |
| 4. Сценарий | вход → показ → жест → прогон → стоп |
| 5. Картотека | 6 позиций с предостережением |

**Картинка:** финальный мягкий показ образа; дети спокойно выражают настроение.  
**Футер:** Ветлугина · Радынова · Метлов · «Ладушки» · театрализация в ДОУ  
**Финальная фраза:** не сцена ради сцены — а понятная, добрая выразительность.
