### Слайд 1. Титульный
**Заголовок:** Основы музыкальной грамоты для педагога по ритмике  
**Подзаголовок:** Занятие № 3 · Рабочий алфавит слуха и движения  

**На слайде:**
- не сольфеджио для музыкантов — минимум воспитателя  
- итог: услышать → назвать → ответить телом  

**Картинка:** раскрытая тетрадь с нотами + следы ног и ладони (хлопок).  
**Схема-формула:**
```
услышал элемент → назвал → хлопнул / шагнул
```
**Мелко:** Метлов; Кононова; Ветлугина

### Слайд 2. Зачем грамота воспитателю
**Заголовок:** Без слуха движение становится случайным

**Таблица рисков:**

| Если педагог не слышит | Что происходит в зале |
|---|---|
| Пульс | дети «плывут», шаг мимо музыки |
| Сильную долю | нет общей опоры группы |
| Темп | слишком быстро/медленно для возраста |
| Характер | марш телом под колыбельную |
| Паузу / край фразы | «доезд» после тишины |

**Картинка:** два кадра — «шаг попал в долю» ✓ и «красиво, но мимо музыки» ✗.  
**Крупно:** грамота нужна, чтобы движение совпало с музыкой, а не только выглядело оживлённо.

### Слайд 5. Что такое музыкальный ритм
**Заголовок:** Не «просто биение» — организованное время

**Определение крупно:**
```
Музыкальный ритм —
организованная последовательность звуков и пауз во времени.
```

**Таблица трёх частей ритма:**

| Часть | Суть | Как проверить телом |
|---|---|---|
| Пульс | ровные удары | ровный шаг/хлопок |
| Рисунок | разные длительности | та — ти-ти — та |
| Акцент | сильная доля | громче / яснее на «раз» |

**Схема:**
```
пульс + рисунок + акцент = ритм, который слышим телом
```

**Картинка:** сердце-метроном + волна длительностей + стрелка акцента.  
**Опоры:** Метлов — живое восприятие; Ветлугина — метроритм в движениях; Кононова — закрепление через игру.

### Слайд 6. Темп: медленный, умеренный, быстрый
**Заголовок:** Скорость долей — отдельная задача слуха

**Большая таблица:**

| Темп | Ощущение | Движение-ориентир |
|---|---|---|
| Медленный | спокойно, тянется | мягкий шаг, покачивание |
| Умеренный | удобно идти | обычный шаг |
| Быстрый | хочется ускориться | лёгкий бег/подскок только по возрасту |

**Таблица ловушек:**

| Путают | На самом деле |
|---|---|
| тихо = медленно | тихо может быть быстро |
| громко = быстро | громко может быть умеренно |
| весело = быстро | характер ≠ автоматический темп |

**Картинка:** три спидометра / три дорожки шагов разной частоты.  
**Правило:** сначала контраст темпов, потом нюансы.

---

### Слайд 7. Сильная и слабая доля
**Заголовок:** Где опора группы

**Определения:**
- **Доля** — единица пульса  
- **Сильная** — более «тяжёлая», с акцентом  
- **Слабая** — более лёгкая, ведёт к следующей сильной  

**Таблица зачем:**

| Если есть сильная доля | Если всё одинаково |
|---|---|
| общая опора шага | группа «долбит» без формы |
| яснее марш/вальс/полька | характер смазывается |
| легче учить стоп и вход | труднее синхронизировать детей |

**Схема для зала:**
```
Сильная — нога уверенно; слабая — вес легче
```

**Картинка:** тактовая сетка «РАЗ-два-три-четыре»; «РАЗ» выделен крупно и цветом.  
**Проба:** хлопок громче только на «раз».

---

### Слайд 8. Размеры 2/4, 3/4, 4/4
**Заголовок:** Сколько долей до следующей опоры

**Большая таблица:**

| Размер | Ощущение | Характер-пример | Движение-ключ |
|---|---|---|---|
| 2/4 | раз-два | марш, полька | чёткий шаг / притоп |
| 3/4 | раз-два-три | вальс | мягкое покачивание |
| 4/4 | раз-два-три-четыре | марш, песня | устойчивый шаг |

**Схема слышания размера:**
```
найти сильную → посчитать доли до следующей сильной → проверить телом
```

**Картинка:** три карточки размеров с группировкой точек/шагов (2 / 3 / 4).  
**Для детей:** не обязательно говорить «три четверти» — «считаем до трёх», «качаемся на вальс».

### Слайд 9. Длительности
**Заголовок:** Длиннее и короче в одном пульсе

**Таблица:**

| Длительность | Отношение | Телом |
|---|---|---|
| Целая | 4 доли (в 4/4) | долгий жест / протяжное ощущение |
| Половинная | 2 доли | шаг шире по времени |
| Четвертная | 1 доля | обычный шаг/хлопок |
| Восьмая | 1/2 доли | короткие «та-та» |

**Схема:**
```
целая = 2 половинных = 4 четвертных = 8 восьмых
```

**Картинка:** лесенка нотных длительностей рядом с лесенкой хлопков разной длины.  
**Для дошкольников:** четверть = «шаг»; восьмые = «быстрые ручки/ножки»; длинные = «дольше держим».

---

### Слайд 10. Пауза и музыкальная фраза
**Заголовок:** Тишина и «предложение» музыки тоже управляют движением

**Таблица:**

| Понятие | Что это | В движении |
|---|---|---|
| Пауза | организованная тишина | стоп, замирание, «музыка спит» |
| Фраза | законченный смысловой отрезок | вход → развитие → точка |

**Схема:**
```
начало фразы → движение
край фразы → точка / смена
пауза → тишина в теле (не хаос)
```

**Картинка:** волна фразы с точкой на конце; рядом пустой такт с жестом «тишина».  
**Ошибка:** продолжать движение в паузе по инерции.  
**Правильно:** пауза — тоже задание.

---

### Слайд 11. Характер музыки
**Заголовок:** Марш, полька, вальс, колыбельная

**Большая таблица:**

| Характер | Что слышим | Движение |
|---|---|---|
| Марш | чёткость, бодрость | собранный шаг, ясная сильная доля |
| Полька | лёгкость, прыгучесть | лёгкий притоп / подскок по возрасту |
| Вальс | плавность, тройной пульс | покачивание, мягкий жест |
| Колыбельная | спокойствие, медленный темп | тихий шаг, малая амплитуда |

**Схема педагога:**
```
услышать характер → одно точное движение → короткое слово-ярлык
```

**Картинка:** четыре карточки-персонажа характеров с пиктограммами шага.  
**Вывод теории:** грамота = пульс, доля, темп, размер, длительности, пауза, фраза, характер.

### Слайд 12. Практика 1. Отхлопывание рисунков
**Заголовок:** Руки проверяют слух

**Таблица рисунков:**

| Рисунок | Как звучит | На что смотреть |
|---|---|---|
| Ровные четверти | та-та-та-та | ровность пульса |
| Та — ти-ти — та | четверть + две восьмые + четверть | не ускорять восьмые |
| Та — (пауза) — та — та | с тишиной | не «проглотить» паузу |

**Схема пары:**
```
один показывает 4 доли → второй повторяет → сверка
```

**Картинка:** ладони + нотная строка простых рисунков; жест «тишина» раскрытыми ладонями.  
**Правило:** сначала слушать целиком, потом повторять.

---

### Слайд 13. Практика 2. Шаги под пульс
**Заголовок:** Нога должна попасть в долю

**Таблица:**

| Задача | Как делать | Ошибка |
|---|---|---|
| Умеренный пульс | шаг на каждую четверть | бежать раньше музыки |
| Медленный | тянуть долю, не «тащить бессмысленно» | застыть и потерять пульс |
| Быстрее умеренного | шаг легче, без бега | разогнаться до хаоса |
| Сильная доля | яснее ставить ногу на «раз» | долбить все доли одинаково |

**Схема безопасности:**
```
дистанция → после ускорения спокойная ходьба
```

**Картинка:** следы ног на линии долей; сильная доля отмечена крупнее.  

---

### Слайд 14. Практика 3. Темп на слух + «Повтори ритм»
**Заголовок:** Две игры на различение и память

**Таблица темпа:**

| Шаг | Действие |
|---|---|
| 1 | фрагмент 8–12 сек |
| 2 | жест/карточка: медленно / умеренно / быстро |
| 3 | одно движение в этом темпе |

**Таблица «Повтори ритм» (по Кононовой):**

| Вариант | Содержание |
|---|---|
| Педагог → группа | эхо 4 долей |
| С паузой | тишина обязательна в рисунке |
| Шагом на месте | тот же рисунок ногами |

**Картинка:** карточки темпа + дети хлопают эхо за педагогом.  
**Ловушка:** тихо, но быстро — не перепутать с медленным.

### Слайд 15. Практика 4. Фраза → движение
**Заголовок:** Перевести музыкальное «предложение» в жест

**Таблица перевода:**

| Характер | Фраза в движении | Точка |
|---|---|---|
| Марш | 4–8 собранных шагов | стоп в позе |
| Вальс | покачивание на 2–4 тройки | спокойная точка |
| Полька | короткие лёгкие притопы | «замри с улыбкой» |
| Колыбельная | одно длинное покачивание | «сон» |

**Таблица услышали → делаем:**

| Услышали | Делаем |
|---|---|
| Начало фразы | вход |
| Развитие | держим характер |
| Конец | точка / смена |
| Пауза | тишина в теле |

**Картинка:** четыре мини-сцены характеров с дугой фразы над каждой.
