**Заголовок:** Танцевальное развитие детей 6–7 лет

**На слайде:**

**Картинка:** дети в шеренге / колонне на празднике, общий финал

### Слайд 2. Почему это уже подготовка к школе
**Заголовок:** Через танец растим школьные качества

**Схема:**
```
Произвольность     — действую по правилу
Память             — помню порядок
Точность           — делаю вместе и аккуратно
Доведение до конца — не бросаю на середине
```

**Описание для ведущего:**  
В 6–7 лет танец нужен не только «для утренника». Он тренирует то, что понадобится в школе: услышать инструкцию, удержать план, начать вместе, остановиться вовремя, быть частью группы. По Ветлугиной и Кенеман музыкальное воспитание готовит к более организованной деятельности.

**Картинка:** мост «детский сад → школа» через ноту и шаг

---

### Слайд 3. Отличие от 5–6 лет
**Заголовок:** Что меняется в подготовительной группе

| 5–6 лет | 6–7 лет |
|---|---|
| осваиваем последовательность | усложняем и помним дольше |
| педагог ведёт почти всё время | появляется более самостоятельное исполнение |
| круг, пары, диагональ | колонна, шеренга, круг, диагональ и их смена |
| точность формируется | точность и согласованность уже требуем заметнее |
| полька/вальс ещё осторожно | доступные элементы польки и вальса вводим увереннее |

**Крупно:**  
`Педагог постепенно отдаёт ответственность детям, но не бросает группу`

**Картинка:** две ступени — «с поддержкой» и «почти самостоятельно»

### Слайд 4. Цель для студента-воспитателя
**Заголовок:** Чему учимся мы

```
Развить произвольность и самоконтроль
→ Укрепить музыкальную память
→ Добиться точности и согласованности
→ Собрать сложную последовательность
→ Вывести на композицию с самостоятельной опорой детей
```

**Пункты:**
1. Понимать школьный смысл танцевальных задач.  
2. Усложнять переменный шаг, галоп, подскоки дозированно.  
3. Вводить элементы польки и вальса через характер музыки.  
4. Учить смене построений.  
5. Проводить композицию с уменьшением подсказок.

### Слайд 6. Произвольность и самоконтроль — подробно
**Заголовок:** Сначала правило, потом музыка

**Определения на слайде:**
- **Произвольность** — действую по правилу и удерживаю цель  
- **Самоконтроль** — вовремя начал, не сорвался, вовремя остановился  

**Как выглядит у детей 6–7 лет:**
- дольше держат внимание;  
- понимают предварительные правила;  
- могут исправиться после короткой подсказки;  
- всё ещё нуждаются в поддержке и ясной структуре.

**Приёмы:**
1. Проговорить правило до музыки.  
2. Дать короткий ориентир: «После галопа — шаг.»  
3. Сигнал самопроверки: «Проверь окошко / свою колонну.»  
4. Хвалить за сдержанность и точность, не только за амплитуду.  
5. Давать мини-роль: ведущий колонны, хранитель интервала.

**Крупно:**
```
Сначала правило → потом музыка → потом оценка точности
```

**Ошибка:** воспитывать самоконтроль окриком.  
**Картинка:** светофор правила / значок «стоп вовремя»

---

### Слайд 7. Музыкальная память — подробно
**Заголовок:** Память танца = порядок + фраза + характер

**Что запоминает ребёнок 6–7 лет:**
- последовательность элементов;  
- смену построений;  
- момент смены по фразе;  
- характер части: полька / вальс / марш.

**Алгоритм развития памяти:**
```
1. Один и тот же текст порядка
2. Опоры: карточки, жесты, точки зала
3. Повтор без ломки структуры
4. Проба с уменьшенной подсказкой
5. Возврат к той же композиции на следующем занятии
```

**Связь со школой:**  
это тренировка рабочей памяти и действия по инструкции — близко к «откройте, найдите, начните вместе».

**Критерий успеха:**  
дети сами подхватывают следующее движение на стыке фраз и помнят, где стоять после перестроения.

**Картинка:** карточки порядка + нотная фраза

---

### Слайд 8. Точность и согласованность — подробно
**Заголовок:** Точность без муштры

**Что уже можно требовать в 6–7 лет:**
- одинаковый старт;  
- сходная амплитуда;  
- чистое направление;  
- согласованность рук и ног;  
- общий финиш.

**Как добиваться:**
1. Медленный показ трудного места.  
2. Чистка одного элемента.  
3. Показ ребёнка-образца.  
4. Короткая синхронная фраза.  
5. Самопроверка: «Посмотри на соседа справа.»

**Важная мысль:**  
согласованность = точность + слух к группе. Ребёнок учится быть частью целого, а не солистом любой ценой.

**Крупно:**  
`Красивы, когда слышим друг друга`

**Картинка:** шеренга с равными интервалами

---

### Слайд 9. Сложные последовательности и композиция
**Заголовок:** От цепочки элементов к целому танцу

**Сложная последовательность может включать:**
- 5–7 элементов;  
- смену характера шага;  
- смену построения;  
- короткий парный/синхронный фрагмент;  
- переход почти без словесной дирижёрии.

**Алгоритм усложнения:**
```
Знакомая основа
→ одно усложнение в элементе
→ одно новое построение
→ сборка по фразам
→ снятие части подсказок
```

**Композиция:** начало → развитие → смена рисунка → завершение.  
**Самостоятельное исполнение:** группа ведёт знакомую форму, педагог страхует.

**Нельзя:** увеличивать сразу длину, новизну и скорость.

---

### Слайд 10. Практика: переменный шаг с усложнением
**Заголовок:** Переменный шаг: уровни усложнения

**Лестница:**
```
1. Чистый переменный шаг по кругу
2. Руки на поясе / в стороны
3. Лёгкое движение рук
4. Смена направления по фразе
5. Переход круг → колонна переменным шагом
```

**Как вести:**
- сначала точность ног;  
- одно усложнение за попытку;  
- 8+8: простой / усложнённый вариант;  
- самопроверка осанки и интервала.

**Команды:**
- «Сначала ножки точно — потом украшение руками.»  
- «Услышали фразу — сменили направление.»  
- «Проверь спину и окошко.»

**Картинка:** ступени усложнения одного шага

---

### Слайд 11. Галоп и подскоки — с акцентом на самоконтроль
**Заголовок:** Быстро — но под контролем

**Схема чередования:**
```
8 галоп → 8 подскоки → 8 шаг + дыхание
```

**Правила:**
- короткие серии;  
- увеличенная дистанция;  
- не сразу в кружение после галопа;  
- общий старт и общий стоп важнее скорости;  
- стоп-сигнал известен заранее.

**Школьный акцент крупно:**
```
Умение вовремя остановиться —
это и есть самоконтроль
```

**Картинка:** быстрые ноты + знак «шаг/дыхание»

---

### Слайд 12. Элементы польки и вальса — подробно
**Заголовок:** Два характера — две координации

**Полька (доступный дошкольный вариант):**
- лёгкий польковый шаг / подскок в характере польки;  
- короткие проходы по кругу или диагонали;  
- характер весёлый, озорной, лёгкий.

**Вальс (доступный вариант):**
- мягкое покачивание / вальсообразное переступание;  
- плавные руки;  
- короткое медленное кружение;  
- характер мягкий, непрерывный.

**Методика введения:**
1. Дать послушать контраст.  
2. Спросить: «Где озорно? Где мягко?»  
3. Отдельно полька.  
4. Отдельно вальс.  
5. Фраза польки + фраза вальса.

**Крупно:**  
`Не бальный канон, а характер и доступная координация`

**Картинка:** две иконки — полька/вальс разными цветами

---

### Слайд 13. Синхронные движения
**Заголовок:** Ансамбль готовит к школе не меньше, чем элемент

**Цепочка упражнений:**
```
Хлопки в долю
→ руки в шеренге синхронно
→ общий старт переменного шага
→ «замри вместе» на конец фразы
→ прогон без голосового счёта
```

**Что разбираем после:**
- где разъехались;  
- кто ушёл в солирование;  
- какая подсказка выровняла группу.

**Формула:**  
«Мы красивы, когда слышим друг друга.»

**Картинка:** шеренга на общем жесте

---

### Слайд 14. Построения — сложный организационный блок
**Заголовок:** Колонна · Шеренга · Круг · Диагональ

**Схема четырёх рисунков:**
```
Круг        — точка сбора и финала
Колонна     — друг за другом за ведущим
Шеренга     — плечом к плечу по ориентиру
Диагональ   — поток с правилом середины
```

**Алгоритм смены построения:**
```
1. Назвать, куда идём
2. Показать ориентир
3. Дать сигнал начала
4. Проверить интервал
5. Зафиксировать новую форму на 2–4 счёта
```

**Команды:**
- «В колонну за Машей.»  
- «В шеренгу к ленте.»  
- «На диагональ — парами, не толпой.»  
- «Снова в круг — окошки ровные.»

**Связь со школой:**  
спокойное перестроение = навык организации.

**Почему сложно:** дети путают названия построений и бегут раньше сигнала. Поэтому каждое построение сначала показать отдельно, затем менять по фразе.

**Картинка:** 4 мини-схемы зала в одном слайде

---

### Слайд 15. Композиция со сменой рисунка — подробно
**Заголовок:** Как собрать и «отпустить» танец

**Пример композиции:**
```
1–8   круг: переменный шаг с усложнением рук
9–16  боковой галоп
17–24 подскоки / элемент польки
25–32 шеренга + синхронные руки
33–40 вальсообразное кружение коротко
41–48 диагональ потоком
финал круг + поклон
```

**Этапы работы:**
```
1. Разучить элементы
2. Собрать по фразам
3. Встроить смены построений
4. Прогон с полной поддержкой
5. Прогон с частичной поддержкой
6. Самостоятельный прогон: педагог только страхует
```

**Что педагог оставляет всегда:**
- взгляд на безопасность;  
- стоп при риске;  
- поддержку;  
- короткий разбор после.

**Критерии успеха самостоятельности:**
- порядок в целом сохранён;  
- построения понятны;  
- нет опасных столкновений;  
- финал общий;  
- дети доводят танец до конца.

**Картинка:** партитура фраз + смена фигурок построений

### Слайд 16. Где теряют контроль в подготовительной группе
**Заголовок:** Риски занятия 11

| Место | Риск | Что сделать |
|---|---|---|
| Усложнение шага | потеря точности | одно усложнение за раз |
| Галоп/подскоки | возбуждение | короткие серии + шаг |
| Полька/вальс | смешение характеров | сначала слушать контраст |
| Смена построений | хаос в зале | ориентир + фиксация формы |
| Самостоятельный прогон | паника / столкновения | сначала частичная поддержка |

**Крупно:**  
`Самостоятельность готовится постепенно — это не брошенность`

---

### Слайд 17. Чек-лист воспитателя
**Заголовок:** Перед музыкой и перед «самостоятельным» прогоном

1. Правило самоконтроля проговорено.  
2. Текст последовательности один и тот же.  
3. Построения названы и показаны.  
4. Быстрые элементы дозированы.  
5. Есть план уменьшения подсказок.  
6. Педагог знает, где останется страховкой.  
7. Критерии разбора понятны: память / точность / вместе / до конца.

**Картинка:** чеклист с галочками
