### Слайд 1. Титульный
**Заголовок:** Музыкально-ритмическое развитие детей 3–4 лет  
**Подзаголовок:** Занятие № 8 · для студентов-воспитателей  
**Картинка:** полноэкранно — младшая группа в кругу с платочками; педагог в круге вместе с детьми, не «над строем»  
**Мелко внизу:** Буренина «Ритмическая мозаика»; Каплунова, Новоскольцева «Ладушки»; Фирилева, Сайкина «Са-Фи-Дансе»

---

### Слайд 2. Возраст 3–4 лет
**Заголовок:** Младшая группа — мост между возрастами  
**Таблица сравнения:**

| 1,5–3 года | 3–4 года | 5–6 лет |
|---|---|---|
| почти только подражание | подражание + первые признаки осознанности | более длинные комбинации |
| 1 элемент уверенно | 1–2 элемента, иногда 3 | 3–4 элемента по фразе |
| яркий образ обязателен | образ + слышание характера | образ + рисунок + выразительность |
| реакция на край музыки | край музыки + смена характера | смена по фразе и рисунку |

**Картинка:** три силуэта детей разного возраста на одной линии  
**Крупный тезис:**
```
Уже не только «повтори за мной»,
ещё не танец «на утренник»
```

---

### Слайд 3. Цель для воспитателя
**Заголовок:** Чему учимся мы  
**Схема-стрелка:**
```
Слышать → Двигаться осознанно → Ориентироваться в зале →
Менять движение по музыке → Держать первые правила танца
```
**Список под схемой:**
- сформировать понимание возраста 3–4 лет  
- научить показывать просто и крупно  
- провести практику: пружинка, хлопки/притопы, кружение, хоровод, предмет, пара  
- соблюдать дозировку и безопасность  

**Картинка:** пиктограмма «ухо → тело → круг детей»

### Слайд 4. Карта темы
**Заголовок:** Содержание занятия  
**Схема:** центр «3–4 года», вокруг 5 блоков теории:

1. Осознанное движение  
2. Подражание и образ  
3. Пространственная ориентировка  
4. Смена по характеру музыки  
5. Первые элементы танцевальной культуры  

**Практика снизу отдельной лентой:**
```
Пружинка → Хлопки/притопы → Кружение → Хоровод → Предметы → Пара
```
**Картинка:** иконки к каждому блоку (ухо, зеркало, круг, две ноты контраста, мягкие руки)

---

### Слайд 5. Осознанное движение
**Заголовок:** Что значит «осознанно» в 3–4 года  
**Схема-цепочка:**
```
Услышал → Понял характер → Сделал простое движение → Остановился вместе
```
**Таблица «это / это ещё не»:**

| Это уже осознанность | Это ещё не осознанность |
|---|---|
| начал вместе с музыкой | красивая поза «как у артистов» |
| пошёл в характере | длинная комбинация из 5 элементов |
| остановился на конце | идеальная синхронность всей группы |
| сменил движение на явный контраст | анализ формы произведения |

**Картинка:** ребёнок замирает на паузе музыки; педагог показывает жест «стоп»  
**Крупно:**
```
Сначала связь «услышал — сделал»,
потом усложнение формы
```

---

### Слайд 6. Подражание и образ
**Заголовок:** Два пути — один результат  
**Двухколоночная схема:**

| Подражание | Образ |
|---|---|
| копирует показ взрослого | входит в роль |
| хлопок, притоп, пружинка, шаг | зайчики, мишки, листочки, птички |
| даёт ясный образец техники | удерживает внимание и снижает напряжение |

**Правила показа (иконки + короткие подписи):**
1. Крупно и лицом к детям  
2. 1–2 новых элемента  
3. Сначала образ одним словом  
4. Хвалить попытку  

**Картинка:** слева педагог показывает хлопок; справа дети-«зайчики» с «ушками»  
**Формула:**
```
Показ + образ = понятное движение
```

### Слайд 7. Пространственная ориентировка
**Заголовок:** Своё место · Круг · Стоп  
**Схема зала:**
```
        ○ ○ ○ ○
      ○         ○
     ○    ●      ○     ● = педагог в круге
      ○         ○
        ○ ○ ○ ○
    «Между нами — окошко»
```
**Таблица «доступно / рано»:**

| Доступно в 3–4 | Пока рано |
|---|---|
| своё место | сложные перестроения |
| круг за педагогом | длинные диагонали |
| остановка на месте | быстрые смены круг–колонна–шеренга |
| кружение на месте | точный интервал «как в хореографии» |

**Алгоритм:**
```
Ориентир → пройти без музыки → под музыку → стоп
```
**Картинка:** мягкие ориентиры на полу + круг детей

---

### Слайд 8. Смена движений по характеру музыки
**Заголовок:** Музыка изменилась → движение изменилось  
**Контрастная таблица:**

| Характер музыки | Движение детей | Команда воспитателя |
|---|---|---|
| спокойная | качаемся / пружинка «спит» | «Музыка спокойная» |
| весёлая / плясовая | хлопаем / топаем / пружиним | «Музыка весёлая» |
| музыка есть | двигаемся | «Пошли вместе» |
| музыки нет | стоп, руки/ножки спокойно | «Музыка закончилась» |

**Схема одной смены:**
```
Фраза А (спокойно) → Фраза Б (весело) → СТОП
         одна понятная смена за подход
```
**Картинка:** две половины слайда разного цвета — мягкие волны / чёткие акценты  
**Тезис:** одна явная смена лучше трёх незаметных

---

### Слайд 9. Первые элементы танцевальной культуры
**Заголовок:** Привычки, из которых вырастает танец  
**Чек-лист крупными пиктограммами:**
1. Начать вместе  
2. Закончить вместе  
3. Смотреть в круг / на партнёра  
4. Мягкие руки  
5. Не толкаться и не обгонять  
6. Убрать атрибут  
7. Радоваться вместе, не соревноваться  

**Схема «культура / не культура»:**

| Культура | Не культура |
|---|---|
| закончили на конце музыки | продолжаем «по инерции» |
| мягко держим руки | тянем соседа |
| своё место | толкучка у педагога |
| общий ритм радости | «кто первый / кто выше» |

**Картинка:** круг детей с мягкими руками и равными интервалами

---

### Слайд 10. Практика: пружинка
**Заголовок:** Пружинка — база плясового шага  
**Схема тела:**
```
Корпус прямой
Колени мягко вниз-вверх
Пятки не бьют пол
```
**Ход упражнения:**
```
Показ → вместе без музыки → под плясовую →
спокойная музыка (пружинка «спит») → СТОП → повтор 2 раза
```
**Таблица ошибок:**

| Ошибка | Коррекция |
|---|---|
| «деревянные» колени | «Пружинки в коленках» |
| пятки бьют пол | «Как на песочке / на подушке» |
| корпус падает вперёд | «Спинка высокая» |

**Картинка:** крупные колени-пружинки + мягкий мячик как образ  
**Дозировка:** 20–30 секунд активной серии

---

### Слайд 11. Практика: хлопки и притопы
**Заголовок:** Сначала по одному, потом связка  
**Таблица этапов:**

| Этап | Действие | Время | Музыка |
|---|---|---|---|
| 1 | только хлопки | 15–20 сек | чёткая |
| 2 | только притопы | 15–20 сек | чёткая |
| 3 | топ — топ — хлоп | медленно, затем с музыкой | плясовая |
| 4 | стоп на конце | — | тишина / конец фразы |

**Схема связки:**
```
Топ → Топ → Хлоп → (повтор) → СТОП
```
**Картинка:** ладони + след стопы как две иконки, стрелка между ними  
**Метод:** если дети теряются — вернуться к одному элементу

---

### Слайд 12. Практика: кружение на месте
**Заголовок:** Кружение короткое и безопасное  
**Схема:**
```
На своём месте → 1–2 коротких оборота → СТОП →
3–4 спокойных шага / покачивание
```
**Таблица безопасности:**

| Можно | Нельзя |
|---|---|
| кружение на месте | соревнование «кто дольше» |
| короткая дозировка | кружение сразу после бега |
| дистанция «окошко» | тесный круг без интервала |
| выход в устойчивость | раскрутка до головокружения |

**Картинка:** снежинка / листочек / юла + крупный значок «стоп»  
**Акцент:** после кружения обязательно собрать равновесие

---

### Слайд 13. Практика: хоровод
**Заголовок:** Хоровод учит совместности, а не «фигуре»  
**Алгоритм:**
```
1. Круг без рук
2. Стоп на конце фразы
3. Мягкие руки
4. Короткий шаг под музыку (20–40 сек)
5. Спокойно разомкнуть круг
```
**Команды на слайде крупно:**
- «Встали в круг»  
- «Окошко между нами»  
- «Ручки мягкие»  
- «Пошли вместе»  
- «Музыка закончилась — стоп»  

**Таблица ошибок:**

| Ошибка | Что делать |
|---|---|
| круг схлопнулся | вернуть на ориентиры |
| кто-то бежит и тащит | снизить темп, напомнить шаг |
| смотрят только в пол | «Глазки ко мне / к соседу» |

**Картинка:** педагог внутри круга, равные интервалы, мягкие руки

---

### Слайд 14. Танцевальные игры с предметами
**Заголовок:** Один атрибут — одна задача  
**Сравнительная таблица:**

| Предмет | Задача | Смена характера | Риск | Старт |
|---|---|---|---|---|
| платочек | машем / прячем | весело машем → спокойно качаем | низкий | лучший первый |
| погремушка | звук в долю | плясовая гремит → спокойная тихо | удары, перевозбуждение | второй |
| ленточка | взмахи на месте | волны / вниз | захлёст, запутывание | по выбору |

**Правила крупно:**
```
2 атрибута на занятие · ~2 минуты каждый
Услышал конец — убрал
Сначала показать, как держать
```
**Картинка:** три предмета в ряд; платочек выделен как «начать отсюда»  
**Разбор-вопрос на слайде:** какой предмет лучше учит смене характера?

---

### Слайд 15. Простые парные композиции
**Заголовок:** Учим по частям, не всей цепочкой  
**Ступени разучивания:**
```
1. Встретились лицом к лицу
2. Покачали руками / платочками
3. Топ-топ / пружинка на месте
4. Кружение каждого на своём месте
5. Стоп: присели / кивок / хлопок партнёру
```
**На сегодняшнем практикуме достаточно:**
```
Встреча → покачивание или топ-топ → СТОП
```
**Таблица про кружение в паре:**

| Базовый вариант | Не базовый |
|---|---|
| кружение на месте по одному | «лодочка» за руки |
| нет тяги через суставы | риск травмы кисти/локтя/плеча при рывке |
| можно сразу всей группе | только позже и с правилом «мягкие руки + сразу стоп» |

**Картинка:** две пары — одна кружится на месте; вторая с мягким контактом через платочек  
**Альтернативы без захвата рук:** платочек между ладонями · хлопки напротив · движение рядом

---

### Слайд 16. Безопасность младшей группы
**Заголовок:** Ясность важнее сложности  
**Красный чек-лист:**
1. Дистанция «окошко»  
2. Короткие серии 20–40 сек  
3. Понятный стоп-сигнал  
4. Мягкие руки в круге и паре  
5. Безопасный атрибут  
6. Кружение без соревнования  
7. После возбуждения — спокойный шаг/покачивание  
8. Педагог видит всех  

**Схема «стоп перегрузки»:**
```
одышка · жалобы · потеря точности · толкотня · крик
                 ↓
        упростить или остановить
```
**Картинка:** спокойный круг + знак паузы  
**Крупно:**
```
Безопасное движение = красивое движение
```

### Слайд 17. Алгоритм упражнения
**Заголовок:** Рабочий шаблон для 3–4 лет  
**Пошаговая схема:**
```
Показ → Образ / короткая команда → Вместе →
Музыка → (одна смена характера) → Стоп → Повтор → Пауза
```
**Таблица фраз воспитателя:**

| Момент | Фраза |
|---|---|
| показ | «Смотрите на меня» |
| образ | «Мы зайчики / листочки» |
| старт | «Музыка заиграла — пошли» |
| смена | «Музыка весёлая — хлопаем» |
| конец | «Музыка закончилась — ножки спокойно» |
| пространство | «Между нами окошко» |

**Картинка:** горизонтальная лента из 7 цветных шагов-алгоритма

### Слайд 18. Итог и домашнее задание
**Заголовок:** Что должен уметь воспитатель  
**Чек-лист умений:**
1. Объяснить особенности 3–4 лет  
2. Показать пружинку, хлопки/притопы, кружение на месте  
3. Провести короткий хоровод с мягкими руками  
4. Дать один предмет со сменой характера и ритуалом убрать  
5. Собрать пару из 2–3 действий  
6. Назвать 5 правил безопасности  

**Домашнее задание — структура 8–10 минут:**
```
Приветствие → Пружинка → Хлопки/притопы →
Кружение или хоровод → Один предмет → Простая пара → Спокойный финал
```
**В конспекте обязательно:** возраст, цель, характер музыки, команды старта/смены/стопа, дозировка в секундах, атрибуты, 5 правил безопасности, 2 ошибки + коррекция  
**Картинка:** блокнот студента + маленькие иконки всех 6 практических блоков  
**Крупный финал:**
```
В 3–4 года побеждает ясная осознанность:
не только подражать, но и слышать характер музыки
```

## Требования к оформлению

1. **Один слайд — одна мысль.**  
2. **Текст:** заголовок + короткая схема/таблица + 1 тезис.  
3. **На каждом слайде** — либо схема/таблица, либо картинка; на ключевых — оба.  
4. **Картинки:** реальные/иллюстративные сцены младшей группы, пиктограммы движения, планы круга; без emoji-кластеров и «стикеров».  
5. **Цвет:** спокойная учебная палитра; контрасты на слайде 8 читать сразу.  
6. **Не включать:** длинные цитаты, полный сценарий педагога, простыни текста без иерархии.  
7. **Итоговый файл сборки:** `.pptx` для PowerPoint.
