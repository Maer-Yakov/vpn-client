# Занятие 7. Музыкально-ритмическое развитие детей от 1,5 до 3 лет

Материалы для студентов педагогических колледжей (специальность «Дошкольное образование»).

## Файлы

| Файл | Назначение |
|---|---|
| `Scenariy_zanyatiya_7_Muzykalno_ritmicheskoe_razvitie_1_5_3.pdf` | Сценарий **для педагога** (без картинок, прямое обращение к студентам) |
| `konspekt.md` | Текстовый конспект |
| `generate_scenario_pdf.py` | Скрипт пересборки сценария |
| `font_paths.py` | Поиск кириллических шрифтов |

## Хронометраж (90 мин)

1. Организационный момент — 10 мин  
2. Теоретический блок — 35 мин  
3. Музыкально-двигательная пауза — 10 мин  
4. Практический блок — 30 мин  
5. Рефлексия и итог — 5 мин
