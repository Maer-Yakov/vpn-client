### Слайд 2. Что ломает детскую постановку
**Заголовок:** Красиво для взрослых ≠ посильного для детей

**Таблица сравнения:**

| «Эффект для видео» | Методическая постановка |

### Слайд 5. Выбор музыки с учётом возраста
**Заголовок:** Сначала услышать — потом ставить

**Большая таблица:**

| Критерий | 3–4 года | 4–5 лет | 5–7 лет |
|---|---|---|---|
| Длительность | 1–1,5 мин | 1,5–2 мин | 2–2,5 (редко 3) |
| Форма | ясная, повторная | контраст 2–3 частей | 3–4 части, репризы |
| Темп | умеренный | умеренный / чуть быстрее | возможен контраст |
| Образ | один яркий | 1–2 образа | развитие образа |
| Текст | простой, если нужен | ясный | можно инструментал |

**Таблица «избегать»:**

| Нет | Почему |
|---|---|
| длинный трек «для красоты» | дети устают и путаются |
| взрослая эстрада | чужой образ |
| фразы без границ | нельзя попасть движением |

**Картинка:** педагог с таймером и партитурой-схемой; дети слушают до первого шага.  
**Тест:** прохлопал форму с 1 раза? если нет — музыка сложна.

### Слайд 6. Построение танца по музыкальным фразам
**Заголовок:** Одна фраза — одно ясное действие

**Алгоритм-схема:**
```
1. Прослушать целиком
2. Отметить вступление / части / коду
3. Разрезать на фразы
4. Дать задаче каждой фразе
5. Повтор музыки = повтор/вариация движения
```

**Схема формы:**
```
Вступление → A → A1/B → C → Реприза → Финал
```

**Таблица ошибок:**

| Ошибка | Правка |
|---|---|
| 5 движений на короткую фразу | 1 действие или связка из 2 |
| смена рисунка внутри фразы без сигнала | граница только на смене музыки |
| у младших вариации без повтора | почти всегда повтор = то же движение |

**Картинка:** нотная лента, разрезанная цветными маркерами на блоки A/B/C; под каждым блоком пиктограмма движения.  
**Крупно:** ставим по слышимым фразам, не «по тактам в голове».

### Слайд 7. Подбор движений
**Заголовок:** Из освоенного багажа + максимум 1 новое

**Таблица «характер → движение»:**

| Характер музыки | Опорные движения |
|---|---|
| Лирическая | шаг с носка, покачивание, плавные руки |
| Маршевая | чёткий шаг, хлопки, остановки |
| Плясовая | притопы, приставной, кружение, подскок дозованно |
| Образная / игровая | имитация образа + простое продвижение |
| Народно-игровая | упрощённые притопы, хороводный шаг |

**Схема ядра:**
```
ЯДРО (повторяется) + УКРАШЕНИЕ (жест/поворот) + ЗАПАСНОЙ упрощённый вариант
```

**Картинка:** карточки движений рядом с карточками характеров музыки; стрелки соответствия.  
**Принцип:** руки и ноги не спорят без подготовки; трюки ради аплодисментов — вне детского сада.

### Слайд 8. Пространственные рисунки
**Заголовок:** Рисунок читает зритель и организует детей

**Таблица базовых рисунков:**

| Рисунок | Когда удобен | Риск |
|---|---|---|
| Круг / два круга | хоровод, общий образ | сужение круга |
| Колонна / две колонны | выход, марш | столкновение встречных |
| Шеренга | показ лицу залу | «дыры» в линии |
| Диагональ | старшие, динамика | край сцены |
| Пары / тройки | взаимодействие | поиск партнёра в панике |
| «Лучи» из центра | праздничный акцент | давка в центре |

**Схема безопасности:**
```
кто куда → встречный поток → предмет в руке → край сцены/ковра
```

**Правила смены:** на границе музыки · есть ориентир · сначала пройти шагом · не 6 перестроений за 1,5 мин.  
**Картинка:** вид сверху — план зала с кругом, колонной, диагональю разными цветами.

### Слайд 9. Работа с предметами
**Заголовок:** Предмет усиливает образ, но повышает сложность

**Таблица предметов:**

| Предмет | Образ | Риск | Страховка |
|---|---|---|---|
| Платочек | лирика, народная игра | падения, спор за цвет | запасные, «свой» |
| Лента | ветер, ручейки | удар по лицу, запутывание | короткая, малая амплитуда |
| Цветы | весна, поздравление | ломаются, колют, закрывают лицо | мягкие, ниже подбородка |
| Листья | осень | скользко на полу | не бросать / сразу убирать |

**Схема введения:**
```
танец без предмета
→ держание + «спит/работает»
→ предмет на 1–2 фразы
→ на всю композицию
→ уборка/финал с предметом
```

**Картинка:** четыре предмета на столе + иконка «стоп», если мешает шагу.  
**Крупно:** предмет не важнее музыки и шага.

### Слайд 10. Разучивание танца поэтапно
**Заголовок:** Порции вместо долбёжки

**Большая схема этапов:**
```
1. Слушание и образ
2. Разметка фраз (хлопки/шаги)
3. Ядро движений на месте
4. Рисунок пространства
5. Соединение A → B → A
6. Предмет
7. Начало и финал
8. Прогоны с правкой
9. Генеральный прогон + поддержка
```

**Таблица дозировки репетиции:**

| Делать | Не делать |
|---|---|
| коротко и часто | час бесконечных полных прогонов |
| чинить одну деталь | стыдить публично |
| чередовать кусок и целое | учить новый сложный танец за 2 дня |

**Картинка:** лестница из 9 ступеней; на каждой — маленькая иконка этапа.  
**Фраза детям:** «Сначала ушами — потом ногами.»

### Слайд 11. Подготовка к утренникам и праздникам
**Заголовок:** Праздник проверяет постановку на прочность

**Таблица отличий зал → сцена:**

| В группе | На утреннике |
|---|---|
| привычный зал | меньше/иначе площадка |
| обычная одежда | костюм мешает движению |
| свои | зрители и волнение |
| свой вход | свет, ведущий, микрофон сдвигают старт |

**Чек-лист к празднику:**

| № | Пункт | ✓ |
|---|---|---|
| 1 | выучен заранее (не за 2 дня) | |
| 2 | репетиция на площадке утренника | |
| 3 | костюмы и предметы проверены | |
| 4 | места выхода/ухода ясны | |
| 5 | план на случай болезни (без «дыр») | |
| 6 | дети знают финальную паузу и уход | |

**Картинка:** сцена с размеченными точками выхода; запасная схема перестроения «минус 1 ребёнок».  
**Крупно:** номер, где все уверены, лучше номера «для видео».

### Слайд 12. Как избежать чрезмерной сложности
**Заголовок:** Светофор сложности постановки

**Большая таблица:**

| 🟢 Можно | 🟡 Осторожно | 🔴 Убрать |
|---|---|---|
| 2–4 ясных рисунка | частая смена пар | акробатика, шпагаты «для красоты» |
| 1 новый элемент | быстрый галоп у края | 8 фигур без повторов |
| предмет после шага | два предмета сразу | трек 4+ минут |
| повтор фраз | сложный канон | стыд и «как в балете» |

**Правило-схема:**
```
путают > 30% детей → сложность завышена
→ упрощаем рисунок / убираем движение
→ НЕ «ещё раз громче объяснить»
```

**Картинка:** светофор + стопка вычеркнутых лишних фигур в корзине.  
**Фраза:** упрощение — признак мастерства постановщика.

### Слайд 13. Разбор готовой детской композиции
**Заголовок:** Учимся читать чужой танец как партитуру

**Таблица бланка разбора:**

| Поле | Что записать |
|---|---|
| Вступление / части / финал | границы по времени или счёту |
| Фразы 1…5 | движение на каждую |
| Рисунки | круг, колонна… |

| Упрощение | что убрать |
| Усиление образа | без усложнения техники |

**Пример эталонной карты:**
```

A — шаг + платочек вверх
A повтор — то же по кругу
B — притопы в центр
A' — шаг + кружение
Финал — точка + поклон
```

**Картинка:** заполненный бланк рядом с экраном/колонкой; цветные стикеры на фразах.  
**Задание на слайде:** предложи 1 упрощение и 1 усиление образа.

### Слайд 16. Репетиция и исправление ошибок
**Заголовок:** Одна правка — один повтор

**Рубрика ошибок:**

| Тип | Пример | Правка |
|---|---|---|
| Музыка | опоздали на смену части | прохлопать границу, якорь-слово |
| Пространство | сужение, столкновения | ориентиры, пройти шагом |
| Предмет | мешает шагу | упростить жест |
| Синхрон | разный финал | общая точка + «и — раз» |
| Сложность | путают порядок | убрать лишнюю фигуру |

**Схема репетиционного цикла:**
```
Прогон → 3 ошибки по рубрике → правка ОДНОЙ главной → повтор куска → короткий прогон
```

**Картинка:** наблюдатели с карточками-рубриками; постановщик правит одну деталь у зеркала.  
**Крупно:** не чинить всё сразу.
