# Музыкальный бот для Telegram

Бот принимает название песни или ссылку на YouTube или SoundCloud, скачивает полный трек и присылает MP3 с названием, исполнителем и длительностью. Сначала ищет на YouTube. Если там ничего нет, ролик недоступен или файл слишком большой, повторяет тот же запрос на SoundCloud. Из плейлиста берутся только первые 5 треков.

Бот работает только с публичными источниками. Он не обходит DRM и не скачивает платный или закрытый контент. Фрагменты и превью не отправляются.

## Требования

- Python 3.11 или новее
- ffmpeg в `PATH` (без ffmpeg конвертация в MP3 невозможна)
- Токен Telegram-бота

ffmpeg должен быть доступен в `PATH`: в новом окне терминала команда `ffmpeg -version` должна выполняться без указания полного пути.

## Установка ffmpeg

### Windows

1. Скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html) (раздел Windows).
2. Распакуйте архив.
3. Добавьте папку `bin` в переменную среды `PATH`.
4. Откройте новое окно терминала и выполните `ffmpeg -version`.

Через winget:

```bat
winget install --id Gyan.FFmpeg -e
```

После установки откройте новый терминал, чтобы подхватился обновлённый `PATH`.

### Linux

Debian и Ubuntu:

```bash
sudo apt update
sudo apt install -y ffmpeg
```

В других дистрибутивах установите пакет `ffmpeg` из репозитория системы и проверьте, что команда `ffmpeg` находится в `PATH`.

### macOS

Через Homebrew:

```bash
brew install ffmpeg
```

Если Homebrew не установлен, скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте её каталог `bin` в `PATH`.

Проверка на любой системе: `ffmpeg -version`.

## Токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте подсказкам.
3. BotFather пришлёт токен. Это значение `BOT_TOKEN`.

Не передавайте токен другим людям и не добавляйте файл `.env` в git.

## Запуск

```bash
cd music_bot
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
```

Linux и macOS:

```bash
source .venv/bin/activate
```

Дальше одинаково:

```bash
pip install -r requirements.txt
cp .env.example .env
```

Windows без `cp`:

```bat
copy .env.example .env
```

Откройте `.env` и вставьте токен:

```env
BOT_TOKEN=токен_от_BotFather
```

Запуск:

```bash
python main.py
```

В консоли пишется журнал уровня INFO. Остановка — Ctrl+C.

## Как пользоваться

- `/start` — приветствие и короткая инструкция
- `/help` — список возможностей
- Название песни — до 5 кнопок YouTube: название, длительность и источник (`ytsearch5`)
- Если YouTube пуст или скачивание не удалось — тот же запрос на SoundCloud
- Ссылка YouTube или SoundCloud — бот скачивает полный трек и присылает MP3 (192 kbps)
- Ссылка на плейлист — только первые 5 треков
- Ссылка на трек Spotify или Apple Music — только название и исполнитель. Аудио с этих сервисов не скачивается: бот ищет ту же запись на YouTube

Если файл больше 45 МБ, бот перекодирует его в 128 кбит/с, не обрезая трек. Если и после этого он больше 45 МБ, бот пишет: «Трек слишком большой для Telegram. Попробуйте другой результат.» и ничего не отправляет.

## Настройки

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен от @BotFather |
| `YT_COOKIES` | нет | Путь к `cookies.txt` в формате Netscape для публичных роликов YouTube. В `.env.example` строка закомментирована. Не используйте cookies для приватного или платного контента. |

## Ограничения

- Только публичные записи.
- Нет обхода DRM и других защит.
- Нет скачивания платного или закрытого контента.
- Региональная блокировка не обходится: бот сообщит, что запись недоступна.
- Файл больше 45 МБ перекодируется в 128 кбит/с. Обрезанный файл не отправляется.
- База данных не используется. Результаты поиска хранятся в памяти процесса и пропадают после перезапуска.
