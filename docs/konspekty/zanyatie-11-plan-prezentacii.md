**Заголовок:** Танцевальное развитие детей 6–7 лет

### Слайд 2. Возраст 6–7 лет
**Заголовок:** Подготовительная группа — танец как школа самоконтроля  
**Таблица сравнения:**

| 4–5 лет | 6–7 лет |
|---|---|
| короткая комбинация | комбинация из нескольких фраз |
| в основном с показом впереди | выход к более самостоятельному исполнению |
| круг и пара | круг, шеренга, колонна, диагональ |
| характер и образ | характер + точность + память + правило |

**Картинка:** ребёнок удерживает правило / ждёт свой вход  
**Крупно:**
```
Не взрослый номер,
а умение действовать по плану
```

### Слайд 3. Цель для воспитателя
**Заголовок:** Чему учимся мы  
**Схема-стрелка:**
```
Произвольность → Память → Точность → Согласованность →
Сложная последовательность → Самостоятельная композиция
```
**Список:**
- развивать самоконтроль в движении  
- учить запоминать фразы  
- добиваться точности и синхрона  
- собирать комбинацию со сменой рисунка  

**Картинка:** пиктограммы «правило → память → группа → план зала»

### Слайд 4. Карта темы
**Заголовок:** Содержание занятия  
**Схема:** центр «6–7 лет / к школе», вокруг 5 блоков теории:
1. Произвольность и самоконтроль

4. Сложные последовательности

**Картинка:** иконки шага, галопа, вальса, хлопка в синхрон, планов зала

### Слайд 5. Произвольность и самоконтроль
**Заголовок:** Действовать по правилу, а не по импульсу  
**Формула:**
```
Правило → Показ → Попытка → Самопроверка → Повтор
```
**Таблица:**

| Уже доступно | Пока вредно |
|---|---|
| ждать вход | длинный монолог до показа |
| удерживать темп | стыд за ошибку |
| исправлять себя | сравнение детей публично |
| заканчивать вместе | идеал с первого раза |

**Картинка:** жест «жди» / дети начинают вместе на долю  
**Тезис:** танец готовит волю через понятное правило

---

### Слайд 6. Музыкальная память
**Заголовок:** Память растёт от короткой точной структуры  
**Ступени снятия подсказки:**
```
Полный показ → Показ начала фразы → Жест сбоку → Только музыка
```
**Схема фраз:**
```
1–8 шаг | 9–16 галоп | 17–24 полька/вальс | 25–32 стоп / смена рисунка
```
**Картинка:** карточки фраз разными цветами в ряд  
**Признак перегруза:** путают порядок уже после 1–2 повторов

---

### Слайд 7. Точность и согласованность
**Заголовок:** Два качества — не путать  
**Двухколоночная схема:**

| Точность | Согласованность |
|---|---|
| качество одного движения | совпадение группы |
| направление, доля, амплитуда | общий старт и конец |
| ясное начало и стоп | один рисунок зала |

**Порядок обучения:**
```
Точный элемент → тот же элемент в группе → смена → скорость
```
**Картинка:** слева один ребёнок в ясном шаге; справа группа в общем хлопке  
**Тезис:** сначала качество, потом “эффект”

---

### Слайд 8. Сложные двигательные последовательности
**Заголовок:** Сложность = ясная структура  
**Схема доступной комбинации:**
```
1–8   переменный шаг
9–16  галоп / подскоки
17–24 элемент польки или вальса
25–32 остановка / поклон / смена рисунка
```
**Алгоритм:**
```
Элемент → 2 фразы → вся комбинация → пространство → самостоятельность
```
**Картинка:** 4 цветных блока-фразы  
**Крупно:**
```
Не больше движений,
а понятнее порядок
```

---

### Слайд 9. Композиция и самостоятельное исполнение
**Заголовок:** Короткий танец с планом в голове  
**Лестница самостоятельности:**
```
1. Вместе с педагогом
2. Педагог показывает только начало фразы
3. Педагог дирижирует жестом сбоку
4. Дети исполняют по музыке сами
5. Короткий разбор
```
**Что внутри композиции:** начало → развитие → смена рисунка → общий конец  
**Картинка:** педагог сбоку зала, дети идут по диагонали сами  
**Связь со школой:** удержать план, ориентироваться на сигнал, действовать в группе

---

### Слайд 10. Практика: переменный шаг с усложнением
**Заголовок:** Сначала точный шаг, потом усложнение  
**Ступени:**
```
Только ноги → руки → то же направление 1–2 фразы →
смена направления только по сигналу → стоп → короткая диагональ
```
**Команды:**
- «Шаг ясный, не бежим»  
- «Новая фраза — то же движение»  
- «Смена направления — теперь обратно» (только по сигналу)  
- «Фраза кончилась — ножки вместе»  

**Картинка:** схема следов переменного шага  
**Ошибки:** бег вместо шага, взгляд в пол, потеря доли; смена направления “сама собой” на каждую фразу

---

### Слайд 11. Практика: галоп и подскоки
**Заголовок:** Не путать два движения  
**Таблица:**

| | Подскок | Галоп |
|---|---|---|
| Ощущение | лёгкое поочерёдное продвижение | шаг ведущей ногой + приставление второй |
| Образ | поскакали | лошадки: «одна ведёт — вторая догоняет» |
| Рисунок | круг / продвижение | круг / диагональ |
| После | шаг | шаг и дыхание |

**Важно:** галоп — не прыжок двумя ногами сразу.  
**Схема фразы:**
```
8 подскоков → 8 галопа → шаг
```
**Картинка:** две пиктограммы движения + значок «не гонка»  
**Безопасность:** короткие серии, мягкое приземление, дистанция

---

### Слайд 12. Практика: элементы польки и вальса
**Заголовок:** Характер важнее “бальных фигур”  
**Контрастная таблица:**

| | Полька | Вальс |
|---|---|---|
| Характер | лёгкий, радостный, чёткий | мягкий, плавный |
| Тело | пружина, ясная доля | покачивание, спокойствие |
| Ошибка | торопливость | жёсткость плеч и ног |

**Схема:**
```
Полька → Вальс → СТОП
```
**Картинка:** две половины слайда разного настроения  
**Тезис:** учим характер и управляемость, не взрослый бальный курс

---

### Слайд 13. Практика: синхронные движения
**Заголовок:** Начинаем и заканчиваем вместе  
**Чек-лист:**
1. Общий вход на “раз”  
2. Одинаковый жест / шаг  
3. Слушать музыку, а не только соседа  
4. Общий стоп на конце фразы  
5. Повтор без педагога впереди  

**Картинка:** группа в одном жесте; стрелки “вместе”  
**Разбор-вопрос:** что сильнее ломает синхрон — разный темп или разные амплитуды?

---

### Слайд 14. Практика: построения
**Заголовок:** Круг · Шеренга · Колонна · Диагональ  
**Схема зала:**
```
КРУГ          ШЕРЕНГА         КОЛОННА         ДИАГОНАЛЬ
 ○ ○ ○ ○       ●●●●●●●●         ●                ●
○       ○                        ●                 \
○   ●   ○                        ●                  \
○       ○                        ●                   ●
 ○ ○ ○ ○
```
**Алгоритм смены:**
```
Назвать ориентир → собрать без музыки → смена под фразу → проверить интервал
```
**Картинка:** цветные маркеры углов и центра  
**Критерий:** смена рисунка за 1 фразу без толкотни

---

### Слайд 15. Комбинация с изменением рисунка
**Заголовок:** Собираем композицию  
**Партитура:**

| Счёт | Рисунок | Движение |
|---|---|---|
| 1–8 | круг | переменный шаг |
| 9–16 | круг | подскоки / галоп |
| 17–24 | ожидание / старт | 2–3 ребёнка у угла; остальные ждут |
| 25–40 | диагональ сменно | полька малыми группами по фразе 8 счётов |
| 41–48 | шеренга | общий финал после того, как все прошли |

**Правило диагонали:**
```
Не весь поток в одну фразу.
2–3 пошли → дошли → в шеренгу → следующая тройка.
Финал только когда все на местах.
```
**Алгоритм:**
```
По фразам без музыки → с музыкой → склейка круга →
отдельно сменная диагональ → вся композиция →
жест сбоку → самостоятельный повтор
```
**Картинка:** 5 цветных блоков + схема “очередь на диагональ”  
**Тезис:** если развалилось — вернуться на точную фразу

### Слайд 16. Безопасность
**Заголовок:** Точность не отменяет осторожность  
**Красный чек-лист:**
1. Дистанция в круге и на диагонали  
2. Короткие серии галопа/подскоков  
3. Шаг и дыхание после прыжковой работы  
4. Понятные ориентиры построений  
5. Без гонки “кто первый по диагонали”  
6. Мягкое приземление  
7. Снижать перевозбуждение  
8. Педагог видит всю смену рисунка  

**Картинка:** диагональ с интервалами + знак паузы  
**Крупно:**
```
Сложный рисунок безопасен
только при ясных правилах
```

### Слайд 17. Алгоритм разучивания
**Заголовок:** Рабочий шаблон подготовительной группы  
**Схема:**
```
Элемент → Фраза → Склейка → Рисунок зала →
Жест сбоку → Самостоятельный повтор → Разбор
```
**Таблица фраз педагога:**

| Момент | Фраза |
|---|---|
| правило | «Начинаем вместе на “раз”» |
| память | «Сначала шаг, потом галоп» |
| точность | «Шаг одинаковый, носок ясный» |
| рисунок | «Из этого угла по диагонали» |
| самостоятельность | «Я сбоку. Держите музыку сами» |
| стоп | «Фраза кончилась — ножки вместе» |

**Картинка:** горизонтальная лента из 7 шагов
