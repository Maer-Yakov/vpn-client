# Музыкальный бот для Telegram

Бот принимает название песни или публичную ссылку (YouTube, SoundCloud и другие открытые источники), скачивает аудио и присылает MP3 с названием и исполнителем. Из плейлиста или альбома берутся только первые 5 треков.

Бот работает только с публичными источниками. Он не обходит DRM и не скачивает платный или закрытый контент.

## Требования

- Python 3.11 или новее
- ffmpeg в `PATH` (без ffmpeg конвертация в MP3 невозможна)
- Токен Telegram-бота

ffmpeg должен быть доступен в `PATH`: в новом окне терминала команда `ffmpeg -version` должна выполняться без указания полного пути.

## Установка ffmpeg

### Windows

1. Скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html) (раздел Windows).
2. Распакуйте архив.
3. Добавьте папку `bin` в переменную среды `PATH`.
4. Откройте новое окно терминала и выполните `ffmpeg -version`.

Через winget:

```bat
winget install --id Gyan.FFmpeg -e
```

После установки откройте новый терминал, чтобы подхватился обновлённый `PATH`.

### Linux

Debian и Ubuntu:

```bash
sudo apt update
sudo apt install -y ffmpeg
```

В других дистрибутивах установите пакет `ffmpeg` из репозитория системы и проверьте, что команда `ffmpeg` находится в `PATH`.

### macOS

Через Homebrew:

```bash
brew install ffmpeg
```

Если Homebrew не установлен, скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте её каталог `bin` в `PATH`.

Проверка на любой системе: `ffmpeg -version`.

## Токен бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте подсказкам.
3. BotFather пришлёт токен. Это значение `BOT_TOKEN`.

Не передавайте токен другим людям и не добавляйте файл `.env` в git.

## Запуск

```bash
cd music_bot
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
```

Linux и macOS:

```bash
source .venv/bin/activate
```

Дальше одинаково:

```bash
pip install -r requirements.txt
cp .env.example .env
```

Windows без `cp`:

```bat
copy .env.example .env
```

Откройте `.env` и вставьте токен:

```env
BOT_TOKEN=токен_от_BotFather
```

Запуск:

```bash
python main.py
```

В консоли пишется журнал уровня INFO. Остановка — Ctrl+C.

## Как пользоваться

- `/start` — приветствие и короткая инструкция
- `/help` — список возможностей
- Название песни — до 5 вариантов кнопками, поиск через YouTube (`ytsearch5`)
- Публичная ссылка — бот сразу скачивает аудио и присылает MP3 (192 kbps) с названием и исполнителем
- Ссылка на плейлист или альбом — только первые 5 треков

Если готовый файл больше 50 МБ, бот его не отправляет и просит выбрать другой результат.

## Настройки

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен от @BotFather |
| `COOKIES_FILE` | нет | Путь к cookies в формате Netscape. В `.env.example` строка закомментирована. Нужна только если публичная страница просит подтвердить браузер. Не используйте cookies для приватного или платного контента. |

## Ограничения

- Только публичные записи.
- Нет обхода DRM и других защит.
- Нет скачивания платного или закрытого контента.
- Региональная блокировка не обходится: бот сообщит, что запись недоступна.
- Один файл не больше 50 МБ — это лимит Telegram Bot API.
- База данных не используется. Результаты поиска хранятся в памяти процесса и пропадают после перезапуска.
