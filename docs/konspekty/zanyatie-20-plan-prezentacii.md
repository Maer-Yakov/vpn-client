# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Пение с детьми от 5–7 лет в детском саду
**Тема:** выразительное организованное пение старших дошкольников при бережности к голосу  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Пение с детьми от 5–7 лет в детском саду  
**Подзаголовок:** Не сила голоса — мягкий эталон, фраза, унисон и пауза  

**На слайде:**
- старший дошкольный / подготовительный возраст  
- итог: мягкий показ + выразительность + унисон + пауза  

**Картинка:** воспитатель ведёт пение с детьми 5–7 лет в музыкальном зале; рядом иконки слух / фраза / унисон / платочек.  
**Схема-формула:**
```
мягкий показ → фраза → выразительность → унисон → пауза
```
**Мелко:** Ветлугина; Метлов; Радынова; «Ладушки»; Орлова / Бекина

---

### Слайд 2. Чем пение в 5–7 лет особенное
**Заголовок:** От подхвата — к выразительности и унисону

**Таблица:**

| 3–5 лет | 5–7 лет |
|---|---|
| больше подхват | больше самостоятельный повтор |
| короткая фраза | длиннее фраза, куплет–припев |
| характер намечается | характер и динамика — предмет работы |
| сильная опора на взрослого | педагог ведёт, дети держат увереннее |

**Картинка:** две двери — «Крик на празднике» (закрыта) и «Мягкое выразительное пение» (открыта).  
**Крупно:** увереннее — не значит громче любой ценой.

---

### Слайд 3. Цель для студента
**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Значение пения
→ Особенности 5–7 лет
→ Задачи обучения
→ Приёмы и этапы
→ Упражнения
→ Репертуар
```

**Мини-таблица:**

| Знает | Умеет |
|---|---|
| особенности голоса 5–7 лет | провести упражнение + 1–2 фразы |
| этапы разучивания | дать приём на характер / унисон |
| критерии репертуара | сказать «беру / не беру» |

**Картинка:** бланк «мини-пение 90–120 секунд».

---

### Слайд 4. Значение пения
**Заголовок:** Пение — развитие и готовность к школе

**Таблица:**

| Сфера | Что развивается |
|---|---|
| Слух | интонация, унисон, динамика |
| Голос | фраза, мягкость, выразительность |
| Речь | дикция, дыхание в слове |
| Эмоции | характер, настроение |
| Общение | петь вместе, слушать соседа |
| К школе | самоконтроль, слуховое внимание |

**Схема:**
```
слух + голос + речь + эмоция → культура пения к школе
```
**Картинка:** шесть сфер вокруг поющего ребёнка 6 лет.  
**Вывод:** пение — не только праздничный номер.

---

### Слайд 5. Возрастные особенности 5–7 лет
**Заголовок:** Что реально доступно голосу

**Таблица:**

| Особенность | Для педагога |
|---|---|
| Диапазон шире, но не «взрослый» | без крайних высоких пиков |
| Фраза длиннее | работа над целой фразой |
| Интонация точнее | мягкое уточнение через показ |
| Внимание устойчивее | куплет–припев возможен |
| Любят выразительность | характер, динамика |
| Риск форсирования | особенно на праздниках |

**Картинка:** лестница «фраза → характер → унисон».  
**Крупно:** это дошкольное пение, не школьный хор «на силу».

---

### Слайд 6. Можно / нельзя
**Заголовок:** Светофор бережного пения

**Таблица:**

| Можно | Нельзя |
|---|---|
| мягкий естественный звук | крик, давить горлом |
| фразы, характер, лёгкий унисон | сценическое соло «как у взрослых» |
| удобная поза, паузы | долгое пение без отдыха |
| посильная песня | шлягер с высоким пиком |
| повтор и мягкое уточнение | стыдить за интонацию |

**Картинка:** светофор — зелёный «мягко», жёлтый «пауза», красный «крик на празднике ✕».  
**Фраза:** стоп крику — тоже методика.

---

### Слайд 7. Задачи обучения пению
**Заголовок:** Восемь проверяемых задач

**Лестница:**
```
1. Желание петь вместе
2. Мягкое звукообразование
3. Точность интонации
4. Слушать начало / конец / вступление
5. Дикция и дыхание во фразе
6. Характер песни
7. Посильный репертуар
8. Беречь голос
```

**Мини-схема:**
```
желание → мягкий звук → фраза/унисон → характер → репертуар
```
**Картинка:** восемь ступенек; наверху мягкая нота, не кубок «громче всех».  
**Вывод:** меньше силы — больше слуха и мягкости.

---

### Слайд 8. Приёмы и этапы разучивания
**Заголовок:** Как вести песню в 5–7 лет

**Таблица приёмов:**

| Приём | Как |
|---|---|
| Выразительный показ | ясный мягкий эталон |
| Разучивание по фразам | показ → повтор → соединение |
| Характер / динамика | тихо / бодрее / ласковее |
| Слуховые задания | начало, конец, «одинаково ли» |
| Жест педагога | опора внимания |

**Этапы (схема-дорожка):**
```
интерес → показ → смысл/характер → фразы → соединение → выразительность → унисон → стоп
```

**Картинка:** дорожка из 8 станций в музыкальном зале.  
**Важно:** 7–12 минут с паузами, не марафон до «идеального номера».

---

### Слайд 9. Упражнения для певческих навыков
**Заголовок:** 20–40 секунд — одна задача

**Таблица:**

| Навык | Упражнение |
|---|---|
| Дыхание | платочек; фраза на одном выдохе |
| Мягкая атака | «мм», «ау», «ля» |
| Интонация | попевка / ступеньки |
| Унисон | «споём одинаково» |
| Дикция | потешка шёпотом → голосом |
| Динамика / характер | тихо — бодрее; ласково — бодро |

**Схема:**
```
одна задача → 20–40 сек → стоп
```
**Картинка:** шесть–семь карточек упражнений.  
**Правило:** игра, не вокальный станок.

---

### Слайд 10. Подбор репертуара
**Заголовок:** Беру / не беру для 5–7 лет

**Критерии:**

| Критерий | Вопрос |
|---|---|
| Диапазон | без крикливого пика? |
| Структура | куплет / припев понятны? |
| Текст | доступен и добр? |
| Характер | можно выразительно показать? |
| Цель | зачем песня группе? |

**Беру / не беру:**

| Беру | Не беру |
|---|---|
| песня старшей / подготовительной | взрослый шлягер |
| ясный образ | чуждый сложный текст |
| мягкая мелодия | крайний высокий пик |
| педагогическая цель | «просто из интернета» |

**Картинка:** полка «беру» / корзина «не беру».  
**Вывод:** репертуар — педагогическое решение.

---

### Слайд 11. Практика и чек-лист
**Заголовок:** Мини-фрагмент 90–120 секунд

**Структура:**
```
упражнение 20–30 сек
→ показ 1–2 фраз + повтор
→ характер или унисон
→ можно / нельзя
→ мягкий стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Голос мягкий? | |
| Фразы ясные? | |
| Есть характер / унисон? | |
| Есть пауза? | |
| Нет крика? | |
| Понятно, что это для 5–7 лет? | |

**Картинка:** студенты проводят мини-показ.  
**Фраза:** хороший фрагмент короткий, выразительный и без крика.

---

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула пения 5–7 лет

**Крупная схема:**
```
Мягкий эталон педагога
+ посильная песня
+ фраза и выразительность
+ унисон без крика
= правильное пение к школе
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | значение · 5–7 лет · задачи · этапы · упражнения · репертуар |
| 2. Разбор песни | этапы + дозировка + 2 риска форсирования |
| 3. Мини-эссе | почему нельзя готовить номер через крик и фонограмму |
| 4. Мини-сценарий | упражнение + фразы + характер/унисон + стоп |
| 5. Сравнение | 3 отличия 3–5 / 5–7 + 3 общих правила |

**Картинка:** воспитатель мягко ведёт фразу; дети поют вместе; платочек «отдыхает».  
**Футер:** Ветлугина; Метлов; Радынова; «Ладушки»; Орлова / Бекина  
**Финальная фраза:** берегите голос — и пение 5–7 лет начнётся с правильного эталона.
