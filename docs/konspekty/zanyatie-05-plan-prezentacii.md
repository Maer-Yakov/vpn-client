### Слайд 2. Зачем база двигательных навыков
**Заголовок:** Без базы танец и игра рассыпаются

**Таблица:**

| Если базы нет | Что видно в зале |
|---|---|
| Нет управляемой ходьбы | хаос темпа и столкновения |
| Нет пружины | жёсткие прыжки, шум, риск |
| Нет переноса веса | «завалы», потеря равновесия |
| Нет ориентировки | круг «ломается», диагональ путается |
| Нет дозировки | перевозбуждение, одышка |

**Картинка:** два кадра — «хаотичная активность» ✗ и «управляемый круг» ✓.  
**Крупно:** красиво только то движение, которое доступно, музыкально и безопасно.

### Слайд 5. Ходьба под музыку
**Заголовок:** Шаг — тоже музыкальный ответ

**Большая таблица видов ходьбы:**

| Вид | Задача | Образ / акцент |
|---|---|---|
| Спокойная | слушать без спешки | мягкая постановка ноги |
| Бодрая (марш) | пульс, энергия | не превращать в бег |
| На носках | лёгкость, равновесие | «как мышки» |
| На пятках | другая опора | коротко, дозированно |
| Высокий шаг | сила, чёткость | колено вверх, корпус вертикально |
| Топающая | сильная доля | активно, но не травмоопасно |
| Пружинящая | мост к прыжку | «пружинки в коленках» |

**Схема правила:**
```
начало с музыкой → качество шага → стоп с окончанием фразы / сигналом
```

**Картинка:** семь мини-силуэтов видов ходьбы по дуге круга.

### Слайд 6. Бег, прыжки, подскоки
**Заголовок:** Лёгкость важнее скорости

**Таблица бега:**

| Вид бега | Педагогический смысл |
|---|---|
| Лёгкий по кругу | контроль дистанции |
| С ускорением | реакция на темп |
| С замедлением | управляемость |
| Со сменой направления | внимание + пространство |
| Образный | «ветерок», «птички» |

**Таблица прыжков:**

| Форма | Ключ техники | Дозировка-ориентир |
|---|---|---|
| Прыжок на двух | мягкое приземление | 6–8, затем шаг/дыхание |
| Подскок | лёгкость, плясовой характер | короткие серии |
| С продвижением / через ориентир | направление + пружина | после пружины на месте |

**Картинка:** слева бег с «не гонка»; справа прыжок с мягкими коленями.  
**Правило до старта бега:** направление · дистанция · стоп · после бега всегда шаг.

### Слайд 7. Пружинящие движения
**Заголовок:** Сначала пружина — потом прыжок

**Определение:**
```
Пружина — ритмичное сгибание/разгибание ног
при вертикальном корпусе.
```

**Таблица зачем:**

| Зачем пружина | Что предотвращает |
|---|---|
| Готовит суставы | жёсткий удар о пол |
| Учит амортизации | шумное приземление |
| Связывает шаг и прыжок | «прыжок из ниоткуда» |
| Снижает риск | травмы коленей/стоп |

**Схема последовательности:**
```
пружина на месте → пружинящий шаг → прыжок короткой серией
```

**Картинка:** колено-пружина (сжата/разжата) + подпись «тихо, будто на песок».  
**Ошибка:** начинать занятие сразу с прыжков.

---

### Слайд 8. Перенос веса тела
**Заголовок:** Сначала тяжесть — потом шаг

**Таблица проб:**

| Упражнение | Что тренирует |
|---|---|
| Перекат с пятки на носок | ощущение опоры |
| Перенос на одну ногу на месте | устойчивость |
| «Через бревно» | осознанный шаг |
| Перенос + шаг вперёд | связь с ходьбой/танцем |

**Схема:**
```
почувствовать вес на опорной → мягко перенести → сделать шаг без завала
```

**Картинка:** силуэт с точкой «центр тяжести», стрелка переноса на другую ногу.  
**Где нужно постоянно:** шаг, «замри», смена круга на диагональ, плясовые элементы.

---

### Слайд 9. Равновесие и координация
**Заголовок:** Устойчивость без соревнования «кто дольше»

**Таблица равновесия:**

| Вид | Пример | Правило |
|---|---|---|
| Статическое | «цапля», поза стоп | короткие точные попытки |
| Динамическое | ходьба по линии, «замри» после бега | спокойная музыка / ясный сигнал |

**Таблица координации:**

| Уровень | Пример |
|---|---|
| Руки + ноги | шаг + хлопок |
| Ритм + пространство | бег по кругу + стоп |
| Смена качества | бодрая ходьба → на носках по фразе |

**Картинка:** «цапля» на линии-ленте; рядом запрет кубка «соревнование до падения».  
**Важно:** равновесие после нагрузки ещё и снижает возбуждение.

---

### Слайд 10. Ориентировка в пространстве
**Заголовок:** Круг → прямая → диагональ

**Таблица маршрутов:**

| Форма | Зачем | Сложность |
|---|---|---|
| Круг | хоровод, общий контакт | база |
| Прямая линия | направление + равновесие | средняя |
| Диагональ | взгляд на ориентир в углу | выше |

**Схема обучения маршруту:**
```
показать ориентиры → пройти вместе → назвать «куда смотрим» → повторить под музыку
```

**Картинка:** план зала: круг по периметру, прямая через центр, диагональ угол–угол.  
**Позиция педагога:** видно всех; не вести диагональ спиной к половине группы.

### Слайд 11. Безопасность двигательной нагрузки
**Заголовок:** Красота без безопасности не считается

**Чек-таблица правил:**

| № | Правило |
|---|---|
| 1 | Разминка / пружина до прыжков |
| 2 | Свободный пол, без сумок на пути |
| 3 | После бега — шаг и дыхание |
| 4 | Прыжки короткими сериями |
| 5 | Дистанция в кругу и врассыпную |
| 6 | Ясный стоп-сигнал |
| 7 | Контроль обуви/одежды |
| 8 | После болезни — снизить прыжковую нагрузку |

**Схема управления:**
```
нагрузка + музыка + безопасность = одновременно
```

**Картинка:** щит «стоп-сигнал / дистанция / дыхание».  
**Вывод теории:** воспитатель управляет не набором упражнений, а нагрузкой и безопасностью сразу.

### Слайд 13. Практика 2. Бег с изменением темпа
**Заголовок:** Не гонка — управляемый бег

**Таблица:**

| Шаг | Действие |
|---|---|
| 1 | Проговорить: направление, дистанция, стоп, после бега шаг |
| 2 | Лёгкий бег по кругу |
| 3 | Ускорение по музыке |
| 4 | Замедление до шага |
| 5 | Врассыпную + «замри» |
| 6 | Сбор в круг шагом + дыхание |

**Схема безопасности:**
```
правила до старта → бег короткий → шаг → дыхание
```

**Картинка:** круг со стрелками темпа (быстрее/медленнее) и позой «замри».

**Картинка:** лента-«ручеёк» + мягкое приземление.
