## Занятие 4. Формирование чувства ритма через движение и игру
**Тема:** пульс, речь, рисунки, телесные удары и ритмические игры  
**Для студентов-воспитателей · 18–22 минуты**  
В каждом слайде: текст + **картинка / схема / таблица**

### Слайд 1. Титульный
**Заголовок:** Формирование чувства ритма через движение и игру  
**Подзаголовок:** Занятие № 4 · От пульса — к танцевальному развитию  

**На слайде:**
- танец без ритма = постановка поз  
- итог: научить попадать в пульс через игру  

**Картинка:** дети хлопают в кругу; над ними иконки ладонь / нога / бубен / потешка.  
**Схема-формула:**
```
пульс → жест / слово → рисунок → игра → танец
```
**Мелко:** Буренина «Ритмическая мозаика»; «Ладушки»; Кононова

### Слайд 2. Зачем это занятие
**Заголовок:** Игра — не антракт, а способ вырастить ритм

**Таблица контрастов:**

| Без ритмических игр | С ритмическими играми |
|---|---|
| танец копированием поз | танец опирается на слышание |
| ошибка = стыд | ошибка = ещё одна проба |
| внимание приказом | внимание правилом игры |
| сложный рисунок сразу | сначала пульс, потом рисунок |

**Картинка:** фундамент «игра + пульс», этаж «танец»; стрелка вверх.  
**Крупно:** ритмическая игра сначала учит слышать и отвечать.

### Слайд 5. Развитие чувства музыкального пульса
**Заголовок:** Пульс — пол, на котором стоит весь ритм

**Определение крупно:**
```
Чувство пульса — умение ощущать ровную долю
и совпадать с ней движением, не обгоняя и не отставая.
```

**Таблица ступеней:**

| Ступень | Педагог | Ребёнок |
|---|---|---|
| Заражение | ярко показывает пульс | повторяет рядом |
| Совместность | ведёт группу | попадает «вместе» |
| Самостоятельность | убирает лишнюю подсказку | держит коротко сам |
| Гибкость | меняет темп/динамику | не теряет опору |

**Схема:**
```
явный пульс взрослого → вместе → коротко сам → пульс как опора рисунка
```

**Картинка:** ровная дорожка долей; ноги/ладони попадают точно в клетки.  
**Ошибка:** сложный рисунок раньше ровной доли.

### Слайд 6. Ритм, речь и стихотворные тексты
**Заголовок:** Слово — мост между слухом и движением

**Таблица приёмов:**

| Приём | Пример задачи |
|---|---|
| Слог = хлопок | «ла-ду-шки» — три коротких жеста |
| Ударение = сильная доля | ярче жест на ударном слоге |
| Повтор строки | закрепить один рисунок 2–3 раза |
| Пауза в тексте | «тишина» руками / инструментом |

**Схема:**
```
потешка → ударный слог → жест → повтор → устойчивый пульс
```

**Картинка:** раскрытая книга потешек + хлопающие ладони над ударными слогами.  
**Важно:** не ломать текст ради сложных синкоп; ясность важнее «оригинальности».

---

### Слайд 7. Ритмические рисунки и усложнение
**Заголовок:** Менять один параметр за раз

**Лестница-таблица:**

| Уровень | Содержание | Ориентир |
|---|---|---|
| 1 | ровные четверти | база для всех |
| 2 | четверть + две восьмые | средний/старший |
| 3 | рисунок с паузой | когда пульс держится |
| 4 | тот же рисунок другим жестом | внимание |
| 5 | цепочка из 2 мотивов | старшие, дозированно |

**Схема:**
```
пульс → простой рисунок → + пауза → + смена жеста → короткая цепочка
```

**Картинка:** пятиступенчатая лестница рисунков; на каждой ступени один новый «кирпичик».  
**Правило:** новый рисунок короткий (4 доли), сначала вместе, потом эхо.

---

### Слайд 8. Хлопки, притопы, щелчки, шаги
**Заголовок:** Палитра тела для одного рисунка

**Большая таблица:**

| Способ | Что даёт | Ограничения |
|---|---|---|
| Хлопки | точность, слышимость | не бить до боли |
| Притопы | связь с шагом и танцем | пол не скользкий |
| Щелчки | тонкий слух, тишина | дать альтернативу пальцами |
| Шаги | ритм в пространстве | дистанция; после быстрого успокоить |

**Схема «палитра»:**
```
один рисунок → хлопок → притоп → щелчок → шаг на месте
(рисунок тот же, тембр тела разный)
```

**Картинка:** четыре пиктограммы вокруг одной нотной строки.  
**Для малышей:** 1–2 способа за подход.

### Слайд 9. Ритмические игры → танцевальное развитие
**Заголовок:** Игра — учебный формат, не антракт

**Таблица состава игры:**

| Обязательный элемент | Зачем |
|---|---|
| Ритмическая задача | что тренируем слухом/телом |
| Правило | как «победить» понятно |
| Повтор | закрепление |
| Радость точного попадания | мотивация без стыда |

**Схема этажей:**
```
ритмическая игра
  → чувство пульса и рисунка
    → уверенный шаг / жест
      → танцевальное развитие
```

**Картинка:** пирамида «игра → ритм → танец»; опоры Буренина / Ладушки / Кононова мелко.  
**Вывод теории:** танец — следующий этаж, не замена фундаменту.

### Слайд 10. Практический вывод теории
**Заголовок:** Что уносим в зал

**Таблица «не так / так»:**

| Не так | Так |
|---|---|
| Сразу сложный рисунок | сначала пульс |
| Долго объяснять без жеста | короткое правило + показ |
| Грохот вместо точности | контроль громкости и паузы |
| Танец без игровой базы | игра → потом композиция |
| Стыдить за промах | ещё одна спокойная проба |

**Схема педагога:**
```
задать пульс → добавить слово/жест → короткий рисунок → сигнал/игра → повтор успеха
```

**Картинка:** педагог с бубном задаёт долю; дети отвечают хлопком.

### Слайд 12. Практика 1. Ритмические цепочки
**Заголовок:** А → Б без потери пульса

**Таблица:**

| Звено | Рисунок | Роль |
|---|---|---|
| А | та-та-та-та | устойчивость |
| Б | та — ти-ти — та | усложнение |
| А→А | повтор | закрепить |
| А→Б | смена | настоящая цепочка |

**Схема пары:**
```
один задаёт звено → второй эхо / продолжает → сверка входа во второе звено
```

**Картинка:** два звена-вагона цепочки; между ними маленькая точка-дыхание.  
**Ошибки:** ускорение, «съеденные» восьмые, потеря входа в Б.

---

### Слайд 13. Практика 2. Сигналы хлопок / притоп
**Заголовок:** Переключить способ звучания по правилу

**Таблица вариантов:**

| Сигнал | Действие |
|---|---|
| Музыка есть | хлопки в пульс |
| Стоп / удар бубна | 2 притопа + пауза |
| Тише | тихие хлопки / щелчки |
| Громче | ясные хлопки без крика |
| Сильная доля | притоп; слабые — тихие хлопки |

**Схема безопасности:**
```
без жёстких ударов → без толкотни → после серии сигналов спокойный пульс
```

**Картинка:** светофор сигнала + ладонь/нога.  
**Правило:** сигнал короткий и однозначный; два сигнала сразу — только для старших.

### Слайд 14. Практика 3. Потешки и стихотворения
**Заголовок:** Ритмизация текста без каши

**Таблица хода:**

| Шаг | Действие |
|---|---|
| 1 | проговорить выразительно |
| 2 | отметить ударные слоги жестом |
| 3 | добавить хлопки/притопы на опорах |
| 4 | повторить 2 раза вместе |
| 5 | эхо: педагог — строка, группа — жест |

**Таблица качества:**

| Хорошо | Плохо |
|---|---|
| текст слышен | текст заглушён грохотом |
| жест помогает доле | жест спорит с ударением |
| 2–3 повтора | долбить до усталости |
| пауза между строками | слияние в кашу |

**Картинка:** строка потешки с подчёркнутыми ударными слогами и пиктограммами жестов.

### Слайд 18. Итог + домашнее задание
**Заголовок:** Попадание в пульс должно быть радостным

**Крупно:**
```
Сначала пульс.
Потом рисунок.
Всегда — игра с понятным правилом.
Тогда танец будет честным.
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Полный конспект своей игры | бланк занятия на 1 странице |
| 2. Две потешки | ударные слоги, жесты, пауза, возраст |
| 3. Лестница из 4 рисунков | от четвертей к цепочке + где нужен инструмент |

**Картинка:** студент проводит игру с бубном; дети точно хлопают в долю.  
**Футер:** Буренина; Каплунова, Новоскольцева; Кононова  
**Финальная фраза:** сделайте игру точной — и танец потом станет честнее.
