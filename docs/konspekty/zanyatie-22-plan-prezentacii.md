# План презентации (12 слайдов) — РАЗВЁРНУТЫЙ
## Пение с музыкальными инструментами с детьми дошкольного возраста
**Тема:** голос главный; инструмент — опора и украшение при ясной организации  
**Для студентов-воспитателей · 12–15 минут**  
В каждом слайде: текст + **картинка / схема / таблица**

---

### Слайд 1. Титульный
**Заголовок:** Пение с музыкальными инструментами  
**Подзаголовок:** Не шум ради шума — мягкий голос, простой ритм, сигнал и стоп  

**На слайде:**
- дошкольный возраст  
- итог: знакомая песня + 1 вид сопровождения + сигнал  

**Картинка:** воспитатель поёт с детьми; у части детей бубен / колокольчик; иконки голос / ритм / сигнал / стоп.  
**Схема-формула:**
```
голос → 1 простой вид сопровождения → сигнал → мало инструментов → стоп
```
**Мелко:** Ветлугина · Метлов · Радынова · «Ладушки» · элементарное музицирование

---

### Слайд 2. Возможности и трудности
**Заголовок:** Инструмент помогает — или мешает?

**Таблица:**

| Возможности | Трудности |
|---|---|
| ритмическая опора | инструмент громче голоса |
| интерес к песне | забывают петь |
| ансамбль / слух | хаос без сигнала |
| роль «я помогаю» | сложная партия |
| тембр | крик «перекричать» |

**Картинка:** две двери — «Шум без песни» (закрыта) и «Песня + мягкое сопровождение» (открыта).  
**Крупно:** если не слышно песни — тише и меньше инструментов.

---

### Слайд 3. Цель для студента
**Заголовок:** Чему учимся сегодня

**Схема-стрелка:**
```
Возможности / риски
→ Инструменты и виды сопровождения
→ Принципы организации
→ Разминка
→ Подбор к песне
→ Микропреподавание
```

**Мини-таблица:**

| Знает | Умеет |
|---|---|
| виды сопровождения | выбрать 1 вид к песне |
| принципы организации | дать сигнал играй / стой |
| риски громкости | провести фрагмент 90–120 сек |

**Картинка:** бланк «мини-фрагмент песня + инструмент».

---

### Слайд 4. Инструменты
**Заголовок:** Что берём для пения дошкольников

**Таблица:**

| Группа | Примеры | Обычно для |
|---|---|---|
| Ударные / шумовые | бубен, ложки, погремушка | ритм, припев |
| Звенящие | колокольчик, треугольник | конец фразы |
| Мелодические | металлофон | 1–2 звука (старшие) |

**Схема возраста:**
```
младшие — меньше инструментов
старшие — до 2 простых партий
```
**Картинка:** полка детских инструментов в музыкальном зале.  
**Вывод:** чем младше — тем проще и тише.

---

### Слайд 5. Виды сопровождения
**Заголовок:** Шесть рабочих вариантов

**Таблица:**

| Вид | Суть |
|---|---|
| Пульс | ровные удары |
| Сильная доля | удар на «раз» |
| Припевное | только в припеве |
| Ответ фразы | короткий отыгрыш |
| Остинато | повторный рисунок |
| Звукоизображение | «кап», «динь» |

**Схема:**
```
сначала голос и текст → затем 1 вид → потом (если нужно) 2-я партия
```
**Картинка:** шесть карточек видов сопровождения.  
**Крупно:** сопровождение ≠ отдельный оркестр.

---

### Слайд 6. Принципы организации
**Заголовок:** Как не превратить песню в хаос

**Таблица:**

| Принцип | Практика |
|---|---|
| Голос главный | слышна песня |
| Один новый навык | песня или партия |
| Показ педагога | голос + инструмент |
| Сигнал | играй / стой / тише |
| Места и роли | кто где |
| Дозировка | 1–2 куплета + пауза |

**Схема-дорожка:**
```
место → показ → сигнал → проба → песня → инструмент → стоп
```
**Картинка:** дети по местам; педагог даёт жест «стой».  
**Фраза:** организация важнее громкости.

---

### Слайд 7. Можно / нельзя
**Заголовок:** Светофор ансамбля

**Таблица:**

| Можно | Нельзя |
|---|---|
| мягкий удар | бить изо всех сил |
| 1–2 инструмента сразу | оркестр «всем всё» |
| припев / конец фразы | перекрывать куплет |
| сигнал и стоп | играть без правила |
| сначала выучить песню | начинать с бренчания |

**Картинка:** светофор — зелёный «мягко», жёлтый «пауза», красный «громче голоса ✕».  
**Фраза:** стоп — тоже методика.

---

### Слайд 8. Разминка к ансамблю
**Заголовок:** 20–40 секунд — одна задача

**Таблица:**

| Упражнение | Задача |
|---|---|
| Эхо-ритм | повтор тихо |
| Сильная доля | удар на «раз» |
| Играй / стой | реакция на сигнал |
| Тише — ещё тише | динамика |
| Голос + один удар | не потерять пение |

**Схема:**
```
тихо → вместе → по сигналу → голос не исчезает
```
**Картинка:** круг с погремушками / бубнами, педагог показывает сигнал.  
**Правило:** разминка — не соревнование «кто громче».

---

### Слайд 9. Подбор сопровождения к песне
**Заголовок:** Алгоритм из семи шагов

**Таблица-алгоритм:**

| Шаг | Вопрос |
|---|---|
| 1 | Какой возраст? |
| 2 | Песня знакома голосом? |
| 3 | Где опора: куплет / припев / конец? |
| 4 | Какой 1 вид? |
| 5 | Какой инструмент и сколько? |
| 6 | Какой сигнал? |
| 7 | Где стоп? |

**Мини-примеры:**

| Образ | Сопровождение |
|---|---|
| колыбельная | колокольчик в конце |
| бодрая | сильная доля в припеве |
| дождик | тихое звукоизображение |

**Картинка:** бланк подбора рядом с текстом песни и 2–3 инструментами.

---

### Слайд 10. Примерный репертуар
**Заголовок:** Логика «песня → сопровождение»

**Таблица:**

| Возраст | Идея | Инструмент |
|---|---|---|
| 3–5 | припев погремушками | погремушка / бубен |
| 3–5 | «динь» в конце | колокольчик |
| 4–5 | сильная доля | ложки / бубен |
| 5–7 | припев + редкий ответ | бубен + колокольчик |
| 5–7 | 1–2 звука остинато | металлофон |

**Схема:**
```
знакомая песня программы + 1 простой вид + мало инструментов
```
**Картинка:** картотека / полка с песнями и инструментами.  
**Вывод:** конкретные названия — из программы группы.

---

### Слайд 11. Микропреподавание и рубрика
**Заголовок:** Фрагмент 90–120 секунд

**Структура:**
```
возраст и цель
→ сигнал 15–20 сек
→ показ песни
→ проба инструмента
→ песня + сопровождение
→ стоп
```

**Рубрика:**

| Вопрос | Да / Нет |
|---|---|
| Голос слышен? | |
| Инструмент не перекрывает? | |
| Есть сигнал? | |
| Партия посильна? | |
| Места понятны? | |
| Есть стоп без крика? | |

**Картинка:** студенты проводят мини-показ; наблюдатели с бланком.  
**Фраза:** хороший фрагмент короткий, тихий достаточно и ясный.

### Слайд 12. Итог и творческие задания
**Заголовок:** Формула пения с инструментами

**Крупная схема:**
```
Знакомая песня
+ 1 простой вид сопровождения
+ сигнал
+ мало инструментов
+ стоп
= доступный ансамбль
```

**Таблица ДЗ:**

| Задание | Содержание |
|---|---|
| 1. Таблица | возможности · виды · принципы · сигналы |
| 2. Разбор песни | алгоритм подбора + риски |
| 3. Мини-эссе | почему нельзя «кто громче» |
| 4. Сценарий | разминка → песня → сопровождение → стоп |
| 5. Картотека | 6 позиций репертуара |

**Картинка:** мягкий ансамбль: дети поют, 1–2 инструмента тихо; педагог даёт стоп.  
**Футер:** Ветлугина · Метлов · Радынова · «Ладушки» · элементарное музицирование  
**Финальная фраза:** первым всегда остаётся мягкий голос.
