# КОНСПЕКТ ЗАНЯТИЯ № 17  
## Игровой подход в обучении детей музыкально-ритмическим движениям  
### («Альбом путешествий в Страну движений»)

**Модуль IV. Методика преподавания и практическая работа**  
**Для студентов** — будущих воспитателей дошкольников  
**Продолжительность:** 90 минут  
**Форма:** комбинированное занятие (лекция-обоснование + путешествие по возрастным «страницам» + проектирование)

**Опора материала занятия:** авторская методическая идея игрового обучения движениям через героев **Пружинка, Шажок, Прыжок**, разметку зала, фланелеграф-схемы движений, систему поощрений («Волшебная туфелька») и «Альбом путешествий в Страну движений».

**Литература / опора:**  
1. Ветлугина Н. А., Кенеман А. В. «Теория и методика музыкального воспитания в детском саду».  
2. Буренина А. И. «Ритмическая мозаика».  
3. Фирилева Ж. Е., Сайкина Е. Г. «Са-Фи-Дансе».  
4. Практический материал занятия: «Альбом путешествий в Страну движений» (младшая → подготовительная группа).

**Оборудование:** музыкальный центр; куклы/символы героев (Пружинка, Шажок, Прыжок) или их карточки; фланелеграф / магнитная доска; «звёздочки»/домики для разметки пола; яркие ленточки на правую ногу; платочек; картинки-страницы альбома по возрастам (или их схема на экране); бланки «схема движения = герои»; значки-образцы поощрения; таймер.

# ЦЕЛЬ И ЗАДАЧИ

**Цель:** сформировать у студентов понимание и практическое умение обучать дошкольников музыкально-ритмическим движениям через игру: от диагностики «сухого повтора» до работы с героями-помощниками, возрастными страницами «Альбома путешествий» и мотивацией достижений.

**Образовательные задачи:**  
показать, почему движения часто «выпадают» из игрового ряда музыкального занятия; раскрыть принцип «что понятно — то выполнимо»; представить героев Пружинка–Шажок–Прыжок как способ осознать состав движения; дать логику возрастных путешествий альбома; показать игровые приёмы пространства, правой/левой стороны и поощрения.

**Развивающие задачи:**  
развивать умение переводить техническое название движения в игровой сюжет; составлять схему движения через героев; проводить фрагмент «страницы альбома» без машинального «повтори за мной».

**Воспитательные задачи:**  
воспитывать бережное отношение к ребёнку, который боится ошибиться при всех; формировать вкус к живому, понятному обучению вместо монотонной долбёжки.

## I. Организационный момент и актуализация  
### (0–10 минута)

Преподаватель ставит на стол кукол/карточки героев и открывает «первую страницу» альбома.

**Текст преподавателя:**

«Сегодня занятие № 17. Тема — игровой подход в обучении детей музыкально-ритмическим движениям.  
На музыкальном занятии слушание, пение, дидактика давно живут в игре и наглядности. А движения часто остаются островом сухих команд: “повтори за мной”, “поставь ногу сюда”.  
Итог известен: кто-то комплексует после публичной ошибки, интерес гаснет, танец ставится долго и безрадостно.  
Сегодня разберём, как вернуть движениям игру: через понятный образ, героев-помощников, разметку зала, альбом путешествий по возрастам и радость достижения — “Волшебную туфельку”.»

**Эпиграф занятия (можно прочитать вслух):**
```
Мир музыкальный входит в наш дом.
Всех обогреет чудесным теплом.
Звуки волшебные мы соберём
И осторожно положим в альбом.
```

**Актуализация. Вопросы:**

1. Почему ребёнку легче спеть «в игре», чем выучить «пружинку» по команде?  
2. Что опаснее для дальнейшего танца: неидеальная техника или страх ошибиться при всех?  
3. Чем игровой сюжет отличается от простого развлечения без обучения?

**Вывод:**  
«Детство — это прежде всего игра. Если движение понятно через образ и сюжет, гарантия успеха резко растёт. Формула занятия: *что понятно — то выполнимо*.»

## II. Теоретическая часть  
### (10–40 минута)

---

### 1. Почему движения «выпадают» из игрового ряда  
### (10–15 минута)

На музыкальном занятии игровые приёмы обычно сильны в:
- распевании (образ, театральный этюд);
- пении (мотивация, значки за чистоту, дикцию, выразительность);
- слушании (иллюстрации, рассказ, эмоция);
- дидактике (фланелеграф, яркий раздаточный материал).

**Проблема раздела «музыкально-ритмические движения»**
- у многих детей ещё слабо чувство ритма, координация, пространственное воображение;
- обучение по принципу «повтори / поставь ногу так» часто не срабатывает;
- неудача при сверстниках → комплекс → страх следующей ошибки;
- неоднократный машинальный повтор гасит интерес;
- постановка танца растягивается, исполнение остаётся невыразительным.

**Таблица Contrasts:**

| Сухой повтор | Игровое обучение движению |
|---|---|
| «Поставь ногу сюда» | «Зайчик научил — Прыжок помогает» |
| ошибка = замечание при всех | ошибка внутри сюжета, без стыда |
| абстрактная «пружинка» | кукла Пружинка, которую можно потрогать |
| круг «держится словами» | звёздочки-домики на полу |
| результат далёкий | туфелька/значок за конкретный успех |

**Ключевой вывод автора методики, который берём в работу:**  
не пускать раздел на самотёк и не продолжать монотонную работу «как всегда», а дать навыки движений в игре так, чтобы дети видели результат в композиции и творчестве.

---

### 2. Принцип игрового обучения движениям  
### (15–19 минута)

**Принцип:** движение осваивается в занимательной игровой ситуации — легко, непринуждённо, с интересом к процессу.

**Педагогические опоры**
1. Образ делает абстрактное конкретным.  
2. Сюжет снимает страх ошибки.  
3. Поисковый вопрос сильнее команды.  
4. Наглядность экономит время занятия.  
5. Достижение должно быть видимым (копилка побед).

**Схема:**
```
Интерес → понимание образа → проба без страха → осознание состава движения → перенос в танец → радость достижения
```

Связь с курсом: это продолжение идей занятий 13–15 (игра, структура, постановка), но с особым акцентом — **как именно учить само движение**, а не только собирать номер.

---

### 3. Герои-помощники: Пружинка, Шажок, Прыжок  
### (19–25 минута)

Логика автора: почти все танцевальные движения дошкольников складываются из **шагов** и **прыжков** на мягкой **«пружинке»**.

Для малыша слово «пружинка» абстрактно: почему полуприседание взрослого так называется?  
Отсюда кукла **Девочка Пружинка** — её спиральные ножки можно потрогать и привести в движение.  
Рядом друзья: **мальчик Шажок** и **мальчик Прыжок**.

**Зачем герои**
- помогают осознать движение;
- дают предмет для подражания;
- позволяют составлять схему движения на фланелеграфе;
- задают поисковые вопросы вместо сухой команды.

**Таблица «движение = герои»**

| Движение | Схема героев |
|---|---|
| Пружинка | Пружинка |
| Приставной шаг | Шажок + Пружинка |
| Боковой галоп | Шажок + Пружинка + Прыжок |
| Поскок | Шажок + Прыжок (+ Пружинка) |
| Ковырялочка без поскока | Пружинка + Шажок |
| Ковырялочка на поскоке | + Прыжок |

**Методический приём:**  
дети не только повторяют, а отвечают: «Кто помогает выполнить это движение?» и выставляют кукол/символы.  
Старшие могут работать уже не куклами, а условными знаками.

**Важно студентам:**  
герои — не декорация, а инструмент анализа движения.

---

### 4. Пространство, мотивация, «Альбом путешествий»  
### (25–32 минута)

#### Разметка зала
Разноцветная разметка («танцевальная карусель», звёздочки, «домики» пар):
- улучшает построения;
- помогает сохранять круг;
- экономит время занятия;
- снижает хаос «кто куда».

#### Система достижений
За успехи — «Волшебная туфелька» / значки в копилку побед (по аналогии со значками в пении: чистота, дикция, выразительность, «Знайка»).  
Мотив: ребёнок осознанно старается и видит свой рост.

#### Альбом путешествий по возрастам

| Группа | Куда путешествуем | Смысл страницы |
|---|---|---|
| Младшая | Сказочная поляна | первые шаги, прыжки, пружинка через образы |
| Средняя | Бабушкина деревня | мягкий шаг, поскоки, народные элементы, платочек |
| Старшая | Школа / Танцевальный класс Магистра | усложнение шагов, народный класс, осознание |
| Подготовительная | Город / Замок Танцев, Королева Танцев | соединение движений в польку, вальс и др. |

Картины альбома — крупный формат, яркие, с текстом ведущего и перечнем движений.  
Путешествие ведут те же герои, постепенно усложняя материал.

---

### 5. Возрастная логика усложнения (обзор страниц)  
### (32–40 минута)

#### Младшая
Образы: тропинка, бабочки, зайчик, машина, лошадка, солнышко, дождик, цветочки, жучки.  
Движения: спокойный/бодрый шаг, пружинка, прыжки на двух, притоп, топотушки, галопчик, носок/пятка, лёгкий бег, три притопа, «фонарики», кружение, хлопки тихо–громко.  
Приём: если забыли Пружинку на пятке — кукла «обижается/отворачивается», затем возвращается.

#### Средняя
Образы: кошечка, дорожка, лошадка, берёзка, платочек.  
Движения: мягкий и бодрый шаг, лёгкие поскоки, прямой галоп, хороводный шаг, передача платочка, кружения, носок–пятка, притопы, «тарелочки».  
Особый методический акцент: **правая/левая в паре** через ленточки и «волшебство перестановки».

#### Старшая
Образ: Магистр Танцевальных движений, школа, сад, балетный и народный класс.  
Движения: стремительный шаг, лёгкий/сильный поскок, «всадники», дыхательно-образные руки, приставной шаг, «весёлые ножки», пружинящий шаг, шаг с притопом, ковырялочка без поскока, кружение, ритмические хлопки.  
Финал страницы — приглашение в Город Танцев.

#### Подготовительная
Образ: Королева Танцев, жители города (Полька, Вальс, далее менуэт/полонез).  
Движения: приставной → боковой галоп; усложнение хороводного и переменного шага; припадание; ковырялочка на поскоке; «метелочка», «козлик», «большие крылья»; синкопированные хлопки; затем сборка в парную польку и вальс.  
Логика: сначала движения, потом соединение в танец «на балу».

**Вывод теории:**  
игровой подход не отменяет обучение. Он делает обучение прозрачным: ребёнок понимает, зачем движение, из чего оно состоит и куда ведёт.

## III. Практическая часть  
### (40–80 минута)

«Сегодня вы — и дети, и будущие ведущие страниц альбома. Идём по возрастам, но дозируем: не весь альбом целиком, а ключевые методические узлы.»

---

### 1. Разметка зала и знакомство с героями  
### (40–46 минута)

1. Разложить звёздочки/домики.  
2. Пройти круг по ориентирам — сравнить с кругом «на словах».  
3. Представить героев: потрогать/показать Пружинку, Шажка, Прыжка.  
4. На фланелеграфе собрать 2 схемы:  
   - приставной шаг = Шажок + Пружинка;  
   - боковой галоп = + Прыжок.

**Разбор:**  
что дала разметка? что дала схема героев по сравнению с командой «делай галоп»?

---

### 2. Страница «Младшая группа» — фрагмент путешествия  
### (46–56 минута)

Преподаватель (или сильный студент) ведёт по сокращённому сценарию альбома. Студенты исполняют как дети.

**Мини-маршрут (обязательный каркас)**
1. Спокойный шаг по тропинке (Шажок).  
2. Бодрый шаг.  
3. Пружинка с бабочками (Пружинка).  
4. Прыжки-зайчики (Прыжок).  
5. Притоп / топотушки (машина).  
6. Галопчик (лошадка).  
7. Носок → пятка; приём «Пружинка обиделась», затем пятка с пружинкой.  
8. Лёгкий бег от дождя → три притопа → фонарики → кружение на цветочке.

**Методические акценты для студентов**
- каждый переход держится образом, а не списком терминов;
- герой вызывается до движения;
- коррекция через сюжет («Пружинка отвернулась»), не через стыд;
- не тащить все образы, если группа устала: выбрать 5–6 опорных.

**После фрагмента — 2 минуты анализа:**  
где был поисковый вопрос? где снят страх ошибки? какое движение стало понятнее благодаря герою?

---

### 3. Страница «Средняя группа» + правая/левая в паре  
### (56–66 минута)

**Короткий маршрут**
1. Мягкий шаг кошечки.  
2. Бодрый шаг.  
3. Лёгкие поскоки (добавляется Прыжок).  
4. Прямой галоп.  
5. Хороводный шаг у «берёзки».  
6. Передача платочка + кружение.  
7. Связка: носок–пятка / притопы / «пятка–носок–3 притопа».

**Особый практикум: правая и левая в парном танце**
1. Мальчик и девочка рядом — яркая лента на правой ноге у обоих; видно: правые с одной стороны.  
2. «Волшебная палочка»: мальчик встаёт лицом к девочке — ленты оказываются с разных сторон.  
3. Игровые сравнения:  
   - если начать с одной стороны лицом друг к другу — «как барашки на бревне» / «машинки, которые не разъедутся»;  
   - чтобы было удобно и красиво — начинать с разных сторон.

**Вывод студентам:**  
пространственное правило объясняется игрой и зрелищем, а не абстрактной схемой «это твоя правая».

---

### 4. Старшая и подготовительная — мост от движения к танцу  
### (66–76 минута)

Не разыгрываем весь балл целиком — берём методический мост.

**Блок А. Старшая (Магистр)** — 5 минут  
- приставной шаг (Шажок + Пружинка);  
- «весёлые ножки» / элемент с Прыжком;  
- ковырялочка без поскока;  
- ритмические хлопки как «браво» за старание.

**Блок Б. Подготовительная (Королева Танцев)** — 5 минут  
1. Приставной → добавить Прыжка → боковой галоп.  
2. Ковырялочка без поскока → на поскоке.  
3. Сборка идеи польки: «Прыжок + Пружинка + два шага Шажка».  
4. Наметить вальсовый принцип: лёгкое кружение и счёт до трёх (без перегруза полной композицией, если времени мало).

**Разбор:**  
как страница старших готовит к городу танцев? где заканчивается обучение элементу и начинается соединение в танец?

### (76–80 минута)

Мини-группы (по возрастам) за 4 минуты заполняют бланк:

| Поле | Содержание |
|---|---|
| Возраст | |
| Движение | |
| Герои на схеме | |
| Игровой сюжет / образ | |
| Текст ведущего (2–4 фразы) | |
| Как снять страх ошибки | |
| Как показать успех (туфелька/значок) | |
| Мостик в танец/композицию | |

Пример: «Приставной шаг» для средней — кошечка на крылечке; схема Шажок+Пружинка; без публичного “не так”; туфелька за мягкость шага.

## IV. Методический тренинг  
### (80–87 минута)

Каждая мини-группа за 1 минуту показывает **не весь танец**, а витрину:
1. называет возраст и движение;  
2. выставляет схему героев;  
3. произносит 2 фразы ведущего из сюжета;  
4. показывает само движение 8–16 счётов.

**Критерии**
1. Есть игра, а не только термин.  
2. Герои реально объясняют состав движения.  
3. Текст короткий и возрастной.  
4. Есть защита от стыда за ошибку.  
5. Виден путь в танец/достижение.

Преподаватель отмечает лучшие переводы «технического» в «понятное детям».

## V. Рефлексия и домашнее задание  
### (87–90 минута)

**Рефлексия**
1. Какой приём сегодня сильнее всего меняет отношение ребёнка к движению?  
2. Где опасность «уйти в чистый спектакль» и потерять обучение?  
3. Чем «Альбом путешествий» удобнее случайного набора образов?

**Домашнее задание**

Составить одну полную «страницу альбома» на 8–10 минут для выбранной группы (младшая / средняя / старшая / подготовительная):

1. название страницы и маршрут образов;  
2. список движений по порядку;  
3. схема героев к каждому новому движению;  
4. полный текст ведущего;  
5. разметка пространства;  
6. приём коррекции без стыда;  
7. момент награждения/фиксации успеха;  
8. как эта страница готовит к танцевальной композиции;  
9. безопасность и дозировка;  
10. связь с литературой курса.

Дополнительно: изготовить (или нарисовать) карточки героев и одну схему «движение = герои».

**Заключительные слова:**  
«Не движение должно уговаривать ребёнка через страх и повтор. Движение должно стать понятной игрой, в которой можно ошибиться, попробовать снова и увидеть свою туфельку успеха. Тогда танец перестаёт быть муштрой и становится путешествием, в которое хочется возвращаться.»

# ПРИЛОЖЕНИЕ А  
## Карта движений по страницам альбома (для студента)

### Младшая
спокойный шаг → бодрый шаг → пружинка → прыжки на двух → притоп → топотушки → галопчик → носок → пятка (+ пружинка) → лёгкий бег → три притопа → фонарики → кружение → хлопки тихо/громко

### Средняя
мягкий шаг → бодрый шаг → лёгкие поскоки → прямой галоп → хороводный шаг → передача платочка → кружение на беге/поскоках → носок/пятка → притопы → пятка–носок–3 притопа → «тарелочки» → кружение на топающем шаге

### Старшая
ветер-ветерок → стремительный шаг → лёгкий/сильный поскок → всадники → образные руки/дыхание → приставной шаг → весёлые ножки → пружинящий шаг → шаг с притопом → ковырялочка без поскока → кружение на поскоках → ритмические хлопки

### Подготовительная
приставной → боковой галоп → усложнённый хороводный/переменный → пружинящий → припадание → ковырялочка на поскоке → метелочка → козлик → большие крылья → синкопированные хлопки → цирковые лошадки → полька → вальс (+ по возможности менуэт/полонез)

# ПРИЛОЖЕНИЕ Б  
## Краткий опорный конспект

**Проблема:** движения часто учат без игры → страх, скука, долгая постановка.  
**Принцип:** что понятно — то выполнимо.  
**Герои:** Пружинка, Шажок, Прыжок = анализ состава движения.  
**Пространство:** разметка экономит время и держит рисунок.  
**Мотив:** туфелька/значок в копилку достижений.  
**Альбом:** младшая поляна → средняя деревня → старшая школа Магистра → подготовительная Город Танцев.  
**Правая/левая:** ленточки + перестроение лицом друг к другу.  
**Роль педагога:** сюжет → вопрос → схема героев → проба → успех → мостик в танец.  
**Опасность:** не растворить обучение в чистом представлении; игра служит навыку.
