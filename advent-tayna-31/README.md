# Тайна 31-го огонька — карта и письма

Адвент-календарь для детей 4–7 лет: карта города Тихих Фонарей и 31 письмо в стиле русского декоративного искусства.

## Визуальный язык

- **Хохлома** — нечётные дни (чёрная рамка, красные ягоды, золото)
- **Гжель** — чётные дни (белый фон, кобальт)
- **Палех** — день 31 (рамка палех + Жар-птица / последний огонёк)

Вёрстка как на референсе: номер в медальоне → заголовок → обращение → сюжет → ★ Задание → подсказка родителям → подпись «Фонарщик Луми» → иллюстрация сцены.

## Файлы

| Путь | Содержание |
|------|------------|
| `cards/map-gorod-tihih-fonarey.jpg` | Карта города с локациями и огоньками |
| `cards/letter-01-…jpg` … `letter-31-…jpg` | 31 письмо-карточка |
| `assets/` | Исходники для пересборки (сцены, рамки, карта) |
| `letters_data.json` | **Канонический** копирайт писем |
| `LETTERS.md` | Человекочитаемая копия (генерируется из JSON) |
| `DESIGN.md` | Система стиля и локаций карты |

## Зависимости

```bash
pip install -r requirements.txt
```

Нужны системные шрифты с кириллицей: `fonts-liberation` или `fonts-dejavu` (пути ищутся автоматически).

Исходные картинки лежат в `assets/`. При необходимости путь можно переопределить:

```bash
export TAYNA31_ASSETS=/path/to/assets
```

## Пересборка

```bash
python3 compose_letters.py   # все 31 сцены обязательны; иначе ошибка
python3 compose_map.py
python3 sync_letters_md.py   # обновить LETTERS.md из JSON
python3 build_print_pdf.py
```

Сборка пишет атомарно в `.jpg` (те же пути, что в репозитории). Частичный набор сцен не допускается.

## Печать (PDF)

| Файл | Формат |
|------|--------|
| `tayna-31-ogonyka-print.pdf` / `Тайна_31_огонька_печатный.pdf` | Карта A4 альбом + 31 письмо A5 |
| `print/letters-a5.pdf` | Только письма, по одному на A5 |
| `print/letters-a4-2up.pdf` | 2 письма на лист A4 (с линией разреза) |
| `print/map-a4-landscape.pdf` | Только карта, A4 альбом |

Рекомендации: печать на плотной бумаге 160–200 г/м²; карта — цветная, можно ламинировать.
